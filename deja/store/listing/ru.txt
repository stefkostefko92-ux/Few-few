TITLE: Déjà — память твоего браузера
SHORT: Ищи по смыслу в прочитанных страницах на 50+ языках. Всё работает на устройстве — ничто не покидает браузер.

Где-то это уже было. Déjà найдёт.

История браузера помнит только заголовки и адреса. Déjà помнит
СОДЕРЖАНИЕ. Опиши своими словами, что помнишь, — «та статья про аккумуляторы
на основе натрия», — и Déjà найдёт страницу, даже если ты не помнишь ни
заголовок, ни сайт, ни точные слова. Déjà даже открывает её сразу на нужном
абзаце.

ЧТО ТЫ ПОЛУЧАЕШЬ
✓ Твои закладки — с поиском по смыслу с первой минуты. По желанию, в один клик.
  Déjà изучает их названия и папки (не открывая страницы) и синхронизирует их,
  когда ты добавляешь, перемещаешь или удаляешь закладки.
✓ Ответы из твоей памяти — на компьютерах с поддержкой встроенного ИИ Chrome
  (Gemini Nano) задай вопрос и получи короткий ответ, составленный на твоём
  устройстве по прочитанным страницам, с кликабельными источниками. (Ответы на
  английском, испанском, немецком, французском и японском.)
✓ Поиск по смыслу — спрашивай своими словами на 50+ языках; спроси на одном
  языке и найди страницы, прочитанные на другом.
✓ Боковая панель-компаньон — открой её рядом с любой страницей и увидишь
  прочитанное по её теме, а также недавние воспоминания.
✓ Введи «dj» в адресной строке — ищи в памяти прямо оттуда, с подсказками по
  мере ввода.
✓ Запомни фрагмент — щёлкни правой кнопкой по выделенному тексту: «Déjà:
  запомнить выделенный текст». Он станет отдельным воспоминанием для поиска.
✓ Переход к нужному абзацу — результаты открывают страницу с подсвеченным
  совпадающим фрагментом.
✓ Фильтры по дате, похожие воспоминания, недавние воспоминания на пустой
  странице поиска.
✓ Моя память — смотри всё, что помнит Déjà, забывай любую страницу в один клик,
  экспортируй и импортируй весь индекс файлом.

КОНФИДЕНЦИАЛЬНОСТЬ ИЗНАЧАЛЬНО
✓ 100% локальная обработка — ИИ-модель эмбеддингов работает внутри браузера,
  а твои данные хранятся в IndexedDB. Без серверов, без облака, без телеметрии,
  без аккаунта.
✓ Страницы почты, чатов, входа и банкинга пропускаются автоматически
  (встроенный список адресов; можно добавить свои шаблоны).
✓ Пауза в один клик. «Забыть эту страницу» и «Очистить память» всегда под рукой.
✓ Автоматическое забывание — по желанию удаляй страницы старше 3/6/12/24 месяцев.
✓ Светлая и тёмная темы следуют настройкам системы.

Единственный сетевой запрос, который делает расширение, — однократная загрузка
модели эмбеддингов с Hugging Face (затем она кешируется локально; вместо этого
можно указать своё зеркало).
