TITLE: Déjà — 你的浏览器记忆
SHORT: 按含义搜索你读过的网页，支持 50 多种语言。完全在你的设备上运行——任何数据都不会离开你的浏览器。

你见过的，Déjà 帮你找到。

浏览器历史记录只记得标题和网址，而 Déjà 记得的是“内容”。
用你自己的话描述你记得的东西——“那篇关于钠基电池的文章”——即使你不记得标题、
网站或确切的措辞，Déjà 也能把那个网页找出来，甚至直接跳到对应的段落。

你将获得
✓ 你的书签，从第一分钟起就能按含义搜索——可选功能，一键开启。
  Déjà 会学习书签的标题和文件夹（不打开网页），并在你添加、移动或删除书签时
  自动保持同步。
✓ 来自你记忆的回答——在支持 Chrome 内置 AI（Gemini Nano）的电脑上，提出问题，
  即可获得根据你读过的网页、在你的设备上撰写的简短回答，并附有可点击的来源。
  （回答支持英语、西班牙语、德语、法语和日语。）
✓ 按含义搜索——用你自己的话、以 50 多种语言提问；用一种语言提问，就能找到你用
  另一种语言读过的网页。
✓ 侧边栏伙伴——在任何网页旁打开它，查看你已经读过的同主题内容，以及最近的记忆。
✓ 在地址栏中输入“dj”——直接从地址栏搜索你的记忆，并提供实时建议。
✓ 记住一段文字——右键点击任意所选文字：“Déjà: 记住所选文字”。它会成为一条可单独
  搜索的记忆。
✓ 直达对应段落——打开结果时，网页中匹配的段落会被突出显示。
✓ 日期筛选、相关记忆，以及空白搜索页上的最近记忆。
✓ 我的记忆——查看 Déjà 记住的所有内容，一键忘记任意网页，将整个索引导出/导入为文件。

隐私源于设计
✓ 100% 本地处理——AI 嵌入模型在你的浏览器中运行，数据保存在 IndexedDB 中。
  没有服务器，没有云端，没有遥测，无需账号。
✓ 邮件、聊天、登录和网上银行页面会被自动跳过（内置网址列表；也可添加你自己的规则）。
✓ 一键暂停。“忘记此网页”和“清除记忆”随时可用。
✓ 自动遗忘——可选择删除超过 3/6/12/24 个月的网页。
✓ 浅色和深色主题跟随系统设置。

此扩展程序唯一会发出的网络请求，是从 Hugging Face 一次性下载嵌入模型
（之后会缓存在本地；你也可以改为指向你自己的镜像）。
