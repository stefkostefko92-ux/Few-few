TITLE: Déjà — તમારા બ્રાઉઝરની સ્મૃતિ
SHORT: વાંચેલાં પેજ અર્થ પ્રમાણે શોધો, 50+ ભાષાઓમાં. બધું તમારા ડિવાઇસ પર જ — કંઈ પણ ક્યારેય તમારા બ્રાઉઝરની બહાર જતું નથી.

તમે આ જોયું છે. Déjà તેને શોધી આપે છે.

તમારા બ્રાઉઝરનો ઇતિહાસ ફક્ત શીર્ષકો અને URL યાદ રાખે છે. Déjà ખરી સામગ્રી યાદ રાખે છે.
તમને જે યાદ છે તેનું તમારા પોતાના શબ્દોમાં વર્ણન કરો — “સોડિયમ આધારિત બૅટરી વિશેનો
પેલો લેખ” — અને Déjà તે પેજ સામે લાવી આપે છે, ભલે તમને શીર્ષક, સાઇટ કે ચોક્કસ શબ્દો
યાદ ન હોય. તે સીધું એ જ ફકરા પર પણ લઈ જાય છે.

તમને શું મળે છે
✓ તમારા બુકમાર્ક, પહેલી મિનિટથી અર્થ પ્રમાણે શોધી શકાય તેવા — વૈકલ્પિક, એક ક્લિકમાં.
  Déjà તેમનાં શીર્ષકો અને ફોલ્ડર શીખે છે (પેજ ખોલ્યા વિના) અને તમે બુકમાર્ક ઉમેરો,
  ખસેડો કે ડિલીટ કરો તેમ તેમને સિંકમાં રાખે છે.
✓ તમારી સ્મૃતિમાંથી જવાબો — Chrome ના બિલ્ટ-ઇન AI (Gemini Nano) ને સપોર્ટ કરતાં
  કમ્પ્યૂટર પર પ્રશ્ન પૂછો અને તમે વાંચેલાં પેજમાંથી તમારા ડિવાઇસ પર લખાયેલો ટૂંકો
  જવાબ મેળવો, ક્લિક કરી શકાય તેવા સ્રોતો સાથે. (જવાબો અંગ્રેજી, સ્પેનિશ, જર્મન, ફ્રેન્ચ
  અને જાપાનીઝમાં.)
✓ અર્થ પ્રમાણે શોધ — તમારા શબ્દોમાં પૂછો, 50+ ભાષાઓમાં; એક ભાષામાં પૂછો અને બીજી
  ભાષામાં વાંચેલાં પેજ શોધો.
✓ સાઇડ પૅનલ સાથી — કોઈ પણ પેજની બાજુમાં તેને ખોલો અને જુઓ કે તે પેજના વિષય પર તમે
  પહેલાં શું વાંચ્યું છે, સાથે તમારી તાજેતરની યાદો.
✓ ઍડ્રેસ બારમાં “dj” લખો — ઍડ્રેસ બારમાંથી જ સીધું તમારી સ્મૃતિમાં શોધો, લાઇવ સૂચનો
  સાથે.
✓ કોઈ અંશ યાદ રાખો — કોઈ પણ પસંદ કરેલા લખાણ પર રાઇટ-ક્લિક કરો: “Déjà: પસંદ કરેલું
  લખાણ યાદ રાખો”. તે પોતાની અલગ, શોધી શકાય તેવી યાદ બની જાય છે.
✓ સીધું એ જ ફકરા પર — પરિણામો મેળ ખાતા અંશને હાઇલાઇટ કરીને પેજ ખોલે છે.
✓ તારીખના ફિલ્ટર, સંબંધિત યાદો, ખાલી શોધ પેજ પર તાજેતરની યાદો.
✓ મારી સ્મૃતિ — Déjà ને જે યાદ છે તે બધું જુઓ, કોઈ પણ પેજ એક ક્લિકમાં ભૂલી જાઓ,
  તમારો આખો ઇન્ડેક્સ ફાઇલ તરીકે એક્સપોર્ટ/ઇમ્પોર્ટ કરો.

રચનાથી જ ખાનગી
✓ 100% સ્થાનિક પ્રોસેસિંગ — AI એમ્બેડિંગ મૉડલ તમારા બ્રાઉઝરની અંદર ચાલે છે અને તમારો
  ડેટા IndexedDB માં રહે છે. ન સર્વર, ન ક્લાઉડ, ન ટેલિમેટ્રી, ન એકાઉન્ટ.
✓ મેલ, ચૅટ, લૉગિન અને બૅન્કિંગનાં પેજ આપમેળે છોડી દેવાય છે (સરનામાંની બિલ્ટ-ઇન યાદી;
  તમારી પોતાની પૅટર્ન પણ ઉમેરો).
✓ એક ક્લિકમાં વિરામ. “આ પેજ ભૂલી જાઓ” અને “સ્મૃતિ સાફ કરો” હંમેશાં હાજર છે.
✓ આપમેળે ભૂલવું — તમે ઇચ્છો તો 3/6/12/24 મહિનાથી જૂનાં પેજ ડિલીટ કરો.
✓ લાઇટ અને ડાર્ક થીમ તમારી સિસ્ટમ પ્રમાણે.

એક્સ્ટેન્શન જે એકમાત્ર નેટવર્ક વિનંતી કરે છે તે Hugging Face પરથી એમ્બેડિંગ મૉડલનું એક
વખતનું ડાઉનલોડ છે (ત્યાર પછી તે સ્થાનિક રીતે કૅશ રહે છે; તેને બદલે તમે તમારો પોતાનો
મિરર પણ નક્કી કરી શકો છો).
