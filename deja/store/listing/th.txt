TITLE: Déjà — ความทรงจำของเบราว์เซอร์คุณ
SHORT: ค้นหาหน้าเว็บที่คุณเคยอ่านตามความหมาย ใน 50+ ภาษา ทำงานบนอุปกรณ์ของคุณทั้งหมด — ไม่มีข้อมูลใดออกจากเบราว์เซอร์ของคุณ

คุณเคยเห็นมันแล้ว Déjà จะหาให้เจอ

ประวัติการเข้าชมของเบราว์เซอร์จำได้แค่ชื่อหน้าและ URL แต่ Déjà จำ “เนื้อหา”
อธิบายสิ่งที่คุณนึกออกด้วยคำพูดของคุณเอง — “บทความเรื่องแบตเตอรี่ที่ใช้โซเดียม
อันนั้น” — แล้ว Déjà จะหาหน้านั้นมาให้ แม้คุณจะจำชื่อเรื่อง เว็บไซต์ หรือ
คำที่ใช้ไม่ได้ และยังพาไปยังย่อหน้าที่ตรงกันได้ทันที

สิ่งที่คุณจะได้รับ
✓ บุ๊กมาร์กของคุณ ค้นหาตามความหมายได้ตั้งแต่นาทีแรก — เลือกเปิดได้ในคลิกเดียว
  Déjà เรียนรู้ชื่อและโฟลเดอร์ของบุ๊กมาร์ก (โดยไม่เปิดหน้าเว็บ) และซิงค์ให้ตรงกัน
  เมื่อคุณเพิ่ม ย้าย หรือลบบุ๊กมาร์ก
✓ คำตอบจากความทรงจำของคุณ — บนคอมพิวเตอร์ที่รองรับ AI ในตัวของ Chrome
  (Gemini Nano) ถามคำถามแล้วรับคำตอบสั้นๆ ที่เขียนขึ้นบนอุปกรณ์ของคุณจากหน้าเว็บ
  ที่คุณเคยอ่าน พร้อมแหล่งที่มาที่คลิกได้ (คำตอบเป็นภาษาอังกฤษ สเปน เยอรมัน
  ฝรั่งเศส และญี่ปุ่น)
✓ ค้นหาตามความหมาย — ถามด้วยคำพูดของคุณเอง ใน 50+ ภาษา ถามเป็นภาษาหนึ่ง
  แล้วเจอหน้าที่คุณอ่านเป็นอีกภาษาหนึ่ง
✓ แผงด้านข้างคู่ใจ — เปิดข้างหน้าเว็บใดก็ได้ แล้วดูว่าคุณเคยอ่านอะไรในหัวข้อของ
  หน้านั้นแล้วบ้าง พร้อมความทรงจำล่าสุดของคุณ
✓ พิมพ์ “dj” ในแถบที่อยู่ — ค้นหาความทรงจำของคุณได้โดยตรงจากแถบที่อยู่
  พร้อมคำแนะนำแบบเรียลไทม์
✓ จดจำข้อความบางตอน — คลิกขวาที่ข้อความที่เลือก: “Déjà: จดจำข้อความที่เลือก”
  ข้อความนั้นจะกลายเป็นความทรงจำที่ค้นหาได้แยกต่างหาก
✓ ข้ามไปยังย่อหน้าที่ตรงกัน — ผลลัพธ์จะเปิดหน้าเว็บพร้อมไฮไลต์ข้อความที่ตรงกัน
✓ ตัวกรองวันที่ ความทรงจำที่เกี่ยวข้อง และความทรงจำล่าสุดในหน้าค้นหาที่ว่างอยู่
✓ ความทรงจำของฉัน — ดูทุกอย่างที่ Déjà จดจำไว้ ลืมหน้าใดก็ได้ในคลิกเดียว
  ส่งออก/นำเข้าดัชนีทั้งหมดเป็นไฟล์

ความเป็นส่วนตัวตั้งแต่การออกแบบ
✓ ประมวลผลบนเครื่อง 100% — โมเดล AI สำหรับฝังเวกเตอร์ทำงานภายในเบราว์เซอร์ของคุณ
  และข้อมูลอยู่ใน IndexedDB ไม่มีเซิร์ฟเวอร์ ไม่มีคลาวด์ ไม่มีการเก็บสถิติการใช้งาน
  ไม่ต้องมีบัญชี
✓ หน้าอีเมล แชท การเข้าสู่ระบบ และธนาคาร จะถูกข้ามโดยอัตโนมัติ (มีรายการที่อยู่ในตัว
  และเพิ่มรูปแบบของคุณเองได้)
✓ หยุดชั่วคราวได้ในคลิกเดียว “ลืมหน้านี้” และ “ล้างความทรงจำ” พร้อมใช้งานเสมอ
✓ ลืมโดยอัตโนมัติ — เลือกลบหน้าที่เก่ากว่า 3/6/12/24 เดือนได้
✓ ธีมสว่างและธีมมืดจะเปลี่ยนตามระบบของคุณ

คำขอเครือข่ายเพียงอย่างเดียวที่ส่วนขยายนี้ส่งออกไป คือการดาวน์โหลดโมเดลฝังเวกเตอร์
จาก Hugging Face ครั้งเดียว (หลังจากนั้นจะแคชไว้บนเครื่อง และคุณสามารถชี้ไปยัง
มิเรอร์ของคุณเองแทนได้)
