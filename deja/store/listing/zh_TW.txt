TITLE: Déjà — 你的瀏覽器記憶
SHORT: 依含義搜尋你讀過的網頁，支援 50 多種語言。完全在你的裝置上執行——任何資料都不會離開你的瀏覽器。

你看過的，Déjà 幫你找到。

瀏覽器的歷史記錄只記得標題和網址，而 Déjà 記得的是「內容」。
用你自己的話描述你記得的東西——「那篇關於鈉基電池的文章」——即使你不記得標題、
網站或確切的用字，Déjà 也能把那個網頁找出來，甚至直接跳到對應的段落。

你將獲得
✓ 你的書籤，從第一分鐘起就能依含義搜尋——選用功能，一鍵開啟。
  Déjà 會學習書籤的標題和資料夾（不開啟網頁），並在你新增、移動或刪除書籤時
  自動保持同步。
✓ 來自你記憶的回答——在支援 Chrome 內建 AI（Gemini Nano）的電腦上提出問題，
  即可獲得根據你讀過的網頁、在你的裝置上撰寫的簡短回答，並附上可點選的來源。
  （回答支援英文、西班牙文、德文、法文和日文。）
✓ 依含義搜尋——用你自己的話、以 50 多種語言提問；用一種語言提問，就能找到你用
  另一種語言讀過的網頁。
✓ 側邊面板夥伴——在任何網頁旁開啟它，查看你已經讀過的同主題內容，以及最近的記憶。
✓ 在網址列輸入「dj」——直接從網址列搜尋你的記憶，並提供即時建議。
✓ 記住一段文字——在任何選取的文字上按右鍵：「Déjà: 記住選取的文字」。它會成為一則
  可單獨搜尋的記憶。
✓ 直達對應段落——開啟結果時，網頁中相符的段落會以醒目方式標示。
✓ 日期篩選、相關記憶，以及空白搜尋頁上的最近記憶。
✓ 我的記憶——查看 Déjà 記住的所有內容，一鍵忘記任何網頁，將整個索引匯出/匯入為檔案。

隱私從設計開始
✓ 100% 本機處理——AI 嵌入模型在你的瀏覽器中執行，資料儲存在 IndexedDB 中。
  沒有伺服器，沒有雲端，沒有遙測，不需要帳戶。
✓ 郵件、聊天、登入和網路銀行頁面會自動略過（內建網址清單；也可以加入你自己的規則）。
✓ 一鍵暫停。「忘記這個網頁」和「清除記憶」隨時可用。
✓ 自動遺忘——可選擇刪除超過 3/6/12/24 個月的網頁。
✓ 淺色和深色主題會跟隨系統設定。

這個擴充功能唯一會發出的網路要求，是從 Hugging Face 一次性下載嵌入模型
（之後會快取在本機；你也可以改為指向你自己的鏡像站）。
