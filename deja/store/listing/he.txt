TITLE: Déjà — הזיכרון של הדפדפן שלך
SHORT: חיפוש לפי משמעות בדפים שקראת, ב-50+ שפות. פועל כולו במכשיר שלך — שום דבר לא יוצא מהדפדפן שלך, אף פעם.

ראית את זה. Déjà מוצא את זה.

היסטוריית הדפדפן זוכרת רק כותרות וכתובות URL. Déjà זוכר את התוכן עצמו.
מתארים במילים שלך את מה שזכור לך — "הכתבה ההיא על סוללות מבוססות נתרן" —
ו-Déjà מעלה את הדף, גם אם לא זכורים לך הכותרת, האתר או המילים המדויקות.
הוא אפילו קופץ ישר לפסקה המדויקת.

מה מקבלים
✓ הסימניות שלך, ניתנות לחיפוש לפי משמעות מהדקה הראשונה — לבחירתך, בלחיצה אחת.
  Déjà לומד את הכותרות והתיקיות שלהן (בלי לפתוח את הדפים) ומסנכרן אותן כשמוסיפים,
  מעבירים או מוחקים סימניות.
✓ תשובות מהזיכרון שלך — במחשבים שתומכים ב-AI המובנה של Chrome (Gemini Nano),
  שואלים שאלה ומקבלים תשובה קצרה שנכתבת במכשיר שלך מתוך הדפים שקראת, עם מקורות
  לחיצים. (תשובות באנגלית, ספרדית, גרמנית, צרפתית ויפנית.)
✓ חיפוש לפי משמעות — שואלים במילים שלך, ב-50+ שפות; שואלים בשפה אחת ומוצאים דפים
  שקראת בשפה אחרת.
✓ מלווה בחלונית הצדדית — פותחים אותה ליד כל דף ורואים מה כבר קראת בנושא של הדף,
  וגם את הזיכרונות האחרונים שלך.
✓ מקלידים "dj" בסרגל הכתובות — חיפוש בזיכרון ישירות מסרגל הכתובות, עם הצעות
  בזמן אמת.
✓ לזכור קטע — לחיצה ימנית על טקסט שנבחר: "Déjà: לזכור את הטקסט שנבחר". הוא הופך
  לזיכרון עצמאי שאפשר לחפש בו.
✓ קפיצה לפסקה המדויקת — התוצאות פותחות את הדף כשהקטע התואם מודגש.
✓ מסנני תאריך, זיכרונות קשורים, זיכרונות אחרונים בדף החיפוש הריק.
✓ הזיכרון שלי — רואים את כל מה ש-Déjà זוכר, שוכחים כל דף בלחיצה אחת, מייצאים/
  מייבאים את כל האינדקס כקובץ.

פרטיות מעצם התכנון
✓ עיבוד מקומי ב-100% — מודל ה-AI להטמעה רץ בתוך הדפדפן שלך והנתונים נשמרים
  ב-IndexedDB. בלי שרתים, בלי ענן, בלי טלמטריה, בלי חשבון.
✓ דפי דואר, צ'אטים, התחברות ובנקאות מדולגים אוטומטית (רשימת כתובות מובנית; אפשר
  להוסיף תבניות משלך).
✓ השהיה בלחיצה אחת. "לשכוח את הדף הזה" ו"ניקוי הזיכרון" זמינים תמיד.
✓ שכחה אוטומטית — לבחירתך, מחיקת דפים ישנים מ-3/6/12/24 חודשים.
✓ ערכות נושא בהירה וכהה לפי המערכת שלך.
