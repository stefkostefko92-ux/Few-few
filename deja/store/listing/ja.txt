TITLE: Déjà — ブラウザの記憶
SHORT: 読んだページを意味で検索。50 以上の言語に対応。すべてデバイス上で動作し、データがブラウザの外に出ることはありません。

見たことがあるなら、Déjà が見つけます。

ブラウザの履歴が覚えているのは、タイトルと URL だけ。Déjà は「内容」を覚えています。
覚えていることを自分の言葉で書くだけ —「ナトリウム系電池についてのあの記事」—
タイトルもサイト名も正確な言葉も覚えていなくても、Déjà がそのページを見つけ出します。
該当する段落まで直接ジャンプします。

主な機能
✓ ブックマークを最初の 1 分から意味で検索 — オプション、ワンクリックで有効化。
  Déjà はページを開かずにタイトルとフォルダを学習し、ブックマークの追加・移動・
  削除に合わせて同期を保ちます。
✓ 記憶からの回答 — Chrome の組み込み AI（Gemini Nano）に対応したパソコンでは、
  質問すると、読んだページをもとにデバイス上で書かれた短い回答が、クリックできる
  出典付きで返ってきます。（回答は英語、スペイン語、ドイツ語、フランス語、日本語に対応。）
✓ 意味で検索 — 自分の言葉で、50 以上の言語で尋ねられます。ある言語で尋ねて、
  別の言語で読んだページを見つけることもできます。
✓ サイドパネルのコンパニオン — どのページの横にも開けて、そのページのトピックに
  ついてすでに読んだものと、最近の記憶を表示します。
✓ アドレスバーに「dj」と入力 — アドレスバーから直接、リアルタイムの候補付きで
  記憶を検索できます。
✓ 文章を記憶 — 選択したテキストを右クリックして「Déjà: 選択したテキストを記憶」。
  それ自体が検索できる記憶になります。
✓ 該当する段落へジャンプ — 結果を開くと、一致した箇所がハイライトされた状態で
  ページが表示されます。
✓ 日付フィルタ、関連する記憶、空の検索ページには最近の記憶。
✓ 私の記憶 — Déjà が覚えているものをすべて確認し、どのページもワンクリックで
  忘れさせ、インデックス全体をファイルとしてエクスポート／インポートできます。

設計段階からプライベート
✓ 100% ローカル処理 — AI の埋め込みモデルはブラウザ内で動作し、データは
  IndexedDB に保存されます。サーバーなし、クラウドなし、テレメトリなし、アカウント不要。
✓ メール、チャット、ログイン、銀行のページは自動的にスキップされます（組み込みの
  アドレスリスト。独自のパターンも追加できます）。
✓ ワンクリックで一時停止。「このページを忘れる」と「記憶を消去」はいつでも使えます。
✓ 自動で忘れる — オプションで 3／6／12／24 か月より古いページを削除します。
✓ ライトテーマとダークテーマはシステムの設定に従います。

この拡張機能が行うネットワーク通信は、Hugging Face からの埋め込みモデルの
一回限りのダウンロードだけです（以降はローカルにキャッシュされます。代わりに
独自のミラーを指定することもできます）。
