TITLE: Déjà — 브라우저의 기억
SHORT: 읽은 페이지를 50개 이상의 언어로, 의미로 검색하세요. 모든 것이 기기에서 실행되며, 어떤 데이터도 브라우저 밖으로 나가지 않아요.

본 적 있다면, Déjà가 찾아 드려요.

브라우저 방문 기록은 제목과 URL만 기억해요. Déjà는 '내용'을 기억해요.
기억나는 것을 내 말로 설명해 보세요 — “나트륨 기반 배터리에 관한 그 기사” —
제목도, 사이트도, 정확한 단어도 기억나지 않아도 Déjà가 그 페이지를 찾아 줘요.
해당 문단으로 바로 이동하기까지 해요.

주요 기능
✓ 첫 1분부터 의미로 검색되는 북마크 — 선택 사항, 클릭 한 번이면 돼요.
  Déjà는 페이지를 열지 않고 북마크의 제목과 폴더를 학습하고, 북마크를 추가·이동·
  삭제할 때마다 동기화해요.
✓ 내 기억에서 찾은 답변 — Chrome 내장 AI(Gemini Nano)를 지원하는 컴퓨터에서
  질문하면, 읽은 페이지를 바탕으로 기기에서 작성된 짧은 답변을 클릭할 수 있는
  출처와 함께 받아요. (답변 언어: 영어, 스페인어, 독일어, 프랑스어, 일본어)
✓ 의미로 검색 — 내 말로, 50개 이상의 언어로 물어보세요. 한 언어로 물어보고
  다른 언어로 읽은 페이지를 찾을 수 있어요.
✓ 사이드 패널 컴패니언 — 어떤 페이지 옆에서든 열어 그 페이지의 주제에 관해
  이미 읽은 내용과 최근 기억을 확인하세요.
✓ 주소창에 “dj” 입력 — 주소창에서 바로 실시간 추천과 함께 기억을 검색해요.
✓ 구절 기억하기 — 선택한 텍스트를 마우스 오른쪽 버튼으로 클릭: “Déjà: 선택한
  텍스트 기억하기”. 별도로 검색할 수 있는 기억이 돼요.
✓ 정확한 문단으로 이동 — 결과를 열면 일치하는 구절이 강조 표시된 페이지가 열려요.
✓ 날짜 필터, 관련 기억, 빈 검색 페이지의 최근 기억.
✓ 내 기억 — Déjà가 기억하는 모든 것을 보고, 클릭 한 번으로 어떤 페이지든 잊게
  하고, 전체 색인을 파일로 내보내기/가져오기할 수 있어요.

설계부터 개인정보 보호
✓ 100% 로컬 처리 — AI 임베딩 모델은 브라우저 안에서 실행되고 데이터는
  IndexedDB에 저장돼요. 서버, 클라우드, 원격 분석, 계정 모두 없어요.
✓ 메일, 채팅, 로그인, 은행 페이지는 자동으로 건너뛰어요(기본 제공 주소 목록,
  나만의 패턴 추가 가능).
✓ 클릭 한 번으로 일시중지. “이 페이지 잊기”와 “기억 지우기”는 언제나 그 자리에 있어요.
✓ 자동으로 잊기 — 선택에 따라 3/6/12/24개월보다 오래된 페이지를 삭제해요.
✓ 라이트 테마와 다크 테마는 시스템 설정을 따라요.

확장 프로그램이 보내는 유일한 네트워크 요청은 Hugging Face에서 임베딩 모델을
한 번 다운로드하는 것뿐이에요(이후에는 로컬에 캐시되며, 대신 자체 미러를
지정할 수도 있어요).
