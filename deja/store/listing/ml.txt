TITLE: Déjà — നിങ്ങളുടെ ബ്രൗസറിന്റെ ഓർമ്മ
SHORT: നിങ്ങൾ വായിച്ച പേജുകൾ 50+ ഭാഷകളിൽ അർത്ഥം നോക്കി തിരയൂ. പൂർണ്ണമായും ഉപകരണത്തിൽ — ഒന്നും ബ്രൗസർ വിട്ടുപോകില്ല.

നിങ്ങൾ അത് കണ്ടിട്ടുണ്ട്. Déjà അത് കണ്ടെത്തും.

നിങ്ങളുടെ ബ്രൗസർ ചരിത്രം തലക്കെട്ടുകളും URL-കളും മാത്രമേ ഓർക്കൂ. Déjà ഉള്ളടക്കം
ഓർക്കുന്നു. ഓർമ്മയുള്ളത് നിങ്ങളുടെ സ്വന്തം വാക്കുകളിൽ വിവരിക്കൂ — “സോഡിയം
അടിസ്ഥാനമാക്കിയ ബാറ്ററികളെക്കുറിച്ചുള്ള ആ ലേഖനം” — തലക്കെട്ടോ സൈറ്റോ കൃത്യമായ വാക്കുകളോ
ഓർമ്മയില്ലെങ്കിലും Déjà ആ പേജ് മുന്നിലെത്തിക്കും. കൃത്യമായ ഖണ്ഡികയിലേക്ക് പോലും നേരിട്ട്
എത്തിക്കും.

നിങ്ങൾക്ക് ലഭിക്കുന്നത്
✓ നിങ്ങളുടെ ബുക്ക്‌മാർക്കുകൾ, ആദ്യ മിനിറ്റ് മുതൽ അർത്ഥം നോക്കി തിരയാവുന്നവ — ഓപ്ഷണൽ,
  ഒറ്റ ക്ലിക്ക്. Déjà അവയുടെ തലക്കെട്ടുകളും ഫോൾഡറുകളും (പേജുകൾ തുറക്കാതെ) പഠിക്കുന്നു,
  നിങ്ങൾ ബുക്ക്‌മാർക്കുകൾ ചേർക്കുമ്പോഴും നീക്കുമ്പോഴും ഇല്ലാതാക്കുമ്പോഴും അവ
  സമന്വയിപ്പിച്ചു നിർത്തുന്നു.
✓ നിങ്ങളുടെ ഓർമ്മയിൽ നിന്നുള്ള ഉത്തരങ്ങൾ — Chrome-ന്റെ ബിൽറ്റ്-ഇൻ AI (Gemini Nano)
  പിന്തുണയ്ക്കുന്ന കമ്പ്യൂട്ടറുകളിൽ, ഒരു ചോദ്യം ചോദിക്കൂ, നിങ്ങൾ വായിച്ച പേജുകളിൽ നിന്ന്
  നിങ്ങളുടെ ഉപകരണത്തിൽത്തന്നെ എഴുതിയ ചെറിയ ഉത്തരം, ക്ലിക്ക് ചെയ്യാവുന്ന ഉറവിടങ്ങൾ സഹിതം
  നേടൂ. (ഉത്തരങ്ങൾ ഇംഗ്ലീഷ്, സ്‌പാനിഷ്, ജർമ്മൻ, ഫ്രഞ്ച്, ജാപ്പനീസ് ഭാഷകളിൽ.)
✓ അർത്ഥം നോക്കിയുള്ള തിരയൽ — 50+ ഭാഷകളിൽ, നിങ്ങളുടെ സ്വന്തം വാക്കുകളിൽ ചോദിക്കൂ; ഒരു
  ഭാഷയിൽ ചോദിച്ച്, മറ്റൊരു ഭാഷയിൽ വായിച്ച പേജുകൾ കണ്ടെത്തൂ.
✓ സൈഡ് പാനൽ കൂട്ടുകാരൻ — ഏത് പേജിനരികിലും അത് തുറന്ന്, ആ പേജിന്റെ വിഷയത്തിൽ നിങ്ങൾ
  മുമ്പ് വായിച്ചതും സമീപകാല ഓർമ്മകളും കാണൂ.
✓ വിലാസ ബാറിൽ “dj” എന്ന് ടൈപ്പ് ചെയ്യൂ — തത്സമയ നിർദ്ദേശങ്ങളോടെ അവിടെ നിന്നുതന്നെ
  നിങ്ങളുടെ ഓർമ്മയിൽ തിരയൂ.
✓ ഒരു ഭാഗം ഓർത്തുവയ്ക്കൂ — തിരഞ്ഞെടുത്ത ഏത് ടെക്‌സ്റ്റിലും റൈറ്റ് ക്ലിക്ക് ചെയ്യൂ: “Déjà:
  തിരഞ്ഞെടുത്ത ടെക്‌സ്റ്റ് ഓർത്തുവയ്ക്കുക”. അത് പ്രത്യേകം തിരയാവുന്ന ഒരു ഓർമ്മയാകുന്നു.
✓ കൃത്യമായ ഖണ്ഡികയിലേക്ക് പോകൂ — പൊരുത്തപ്പെടുന്ന ഭാഗം ഹൈലൈറ്റ് ചെയ്‌ത് ഫലങ്ങൾ പേജ്
  തുറക്കുന്നു.
✓ തീയതി ഫിൽട്ടറുകൾ, ബന്ധപ്പെട്ട ഓർമ്മകൾ, ശൂന്യമായ തിരയൽ പേജിൽ സമീപകാല ഓർമ്മകൾ.
✓ എന്റെ ഓർമ്മ — Déjà ഓർക്കുന്നതെല്ലാം കാണൂ, ഏത് പേജും ഒറ്റ ക്ലിക്കിൽ മറക്കൂ, നിങ്ങളുടെ
  മുഴുവൻ സൂചികയും ഒരു ഫയലായി എക്‌സ്‌പോർട്ട്/ഇമ്പോർട്ട് ചെയ്യൂ.

രൂപകൽപ്പനയിൽത്തന്നെ സ്വകാര്യത
✓ 100% പ്രാദേശിക പ്രോസസ്സിംഗ് — AI എംബെഡിംഗ് മോഡൽ നിങ്ങളുടെ ബ്രൗസറിനുള്ളിൽ പ്രവർത്തിക്കുന്നു,
  നിങ്ങളുടെ ഡാറ്റ IndexedDB-യിൽ ഇരിക്കുന്നു. സെർവറുകളില്ല, ക്ലൗഡില്ല, ടെലിമെട്രിയില്ല,
  അക്കൗണ്ടില്ല.
✓ മെയിൽ, ചാറ്റുകൾ, ലോഗിൻ, ബാങ്കിംഗ് പേജുകൾ സ്വയമേവ ഒഴിവാക്കപ്പെടുന്നു (ബിൽറ്റ്-ഇൻ വിലാസ
  ലിസ്റ്റ്; നിങ്ങളുടെ സ്വന്തം പാറ്റേണുകളും ചേർക്കാം).
✓ ഒറ്റ ക്ലിക്കിൽ താൽക്കാലികമായി നിർത്താം. “ഈ പേജ് മറക്കുക”, “ഓർമ്മ മായ്ക്കുക” എപ്പോഴും
  കൈയെത്തും ദൂരത്ത്.
✓ സ്വയമേവ മറക്കൽ — വേണമെങ്കിൽ 3/6/12/24 മാസത്തിലധികം പഴയ പേജുകൾ ഇല്ലാതാക്കാം.
✓ ലൈറ്റ്, ഡാർക്ക് തീമുകൾ നിങ്ങളുടെ സിസ്റ്റത്തെ പിന്തുടരുന്നു.

എക്‌സ്‌റ്റൻഷൻ നടത്തുന്ന ഒരേയൊരു നെറ്റ്‌വർക്ക് അഭ്യർത്ഥന Hugging Face-ൽ നിന്ന് എംബെഡിംഗ്
മോഡലിന്റെ ഒറ്റത്തവണ ഡൗൺലോഡ് മാത്രമാണ് (പിന്നീട് പ്രാദേശികമായി കാഷെ ചെയ്യപ്പെടുന്നു;
പകരം നിങ്ങളുടെ സ്വന്തം മിറർ ചൂണ്ടിക്കാണിക്കാം).
