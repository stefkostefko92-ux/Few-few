# Déjà — паметта на браузъра ти

> Виждал си го. Déjà го намира.

Déjà е Chrome (MV3) разширение, което помни какво си **чел** — не само кои URL-и
си посещавал. Индексира съдържанието на страниците локално и после търсиш на
човешки език:

> „онази статия за батерии на натриева основа отпреди месец“

…и Déjà я изважда, дори да не помниш нито заглавието, нито сайта.

## Защо е различно

- **100% локално.** Embedding моделът (transformers.js + ONNX/WASM) върви в
  браузъра, векторите живеят в IndexedDB. Нищо не се праща никъде. Никога.
- **Семантично, не текстово.** Историята на Chrome търси по заглавие и URL.
  Déjà търси по смисъл — на 50+ езика, включително български.
- **Поверителност по подразбиране.** Поща, чатове, login и банкови страници
  никога не се индексират. Пауза с един клик. „Изчисти паметта“ трие всичко.

## Разработка

```bash
cd deja
npm ci
npm run build
```

После: `chrome://extensions` → Developer mode → **Load unpacked** → избери
`deja/dist`. Разгледай няколко страници, отвори търсенето от иконата (или
Alt+Shift+D) и питай. Първото търсене тегли модела (~120MB, еднократно) — дай
му 10–30 секунди.

Качествена порта преди комит: `npm run format:check && npm run build`.

## Как работи

1. Content script извлича четимия текст от `article`/`main` на страницата.
2. Service worker-ът го реже на парчета (~1100 знака) и ги праща на offscreen
   документ, където `Xenova/paraphrase-multilingual-MiniLM-L12-v2` (384d, q8)
   ги превръща във вектори.
3. Векторите се пазят в IndexedDB. Търсенето embed-ва заявката и подрежда
   парчетата по косинусова близост — най-доброто парче представя страницата.
