# Видео „Montaggio in undici passi“ — A 45 175 2 + B 45 320

Видео инструкция за монтажа на планката за етажна врата в 11 стъпки, по процедурата на собственика
(23.11.2026). Последната стъпка добави собственикът на 24.11.2026: ъглошлайфът отрязва всяка пластина A
наравно с предния ръб на прага. Пак на 24.11.2026 собственикът реши:
- вляво е A SX + B SX, вдясно A DX + B DX;
- в стъпка 10 бургията за средната планка удря армировка („ferro d’armatura“);
- B DX се сменя с B SX, а A DX остава. Така отворите се местят на 65 mm от пръта.

Клипът е 133 s, само на италиански, 16:9 за YouTube. Сцената се строи в Blender (Cycles) от същата геометрия
като 3D каталога. Надписите се рисуват с Pillow върху готовите кадри.

**Не е за сайта.** Папката е под `/3d/`, който `server.js` не сервира.

## Звук

Музиката и шумовете са написани тук, в код (собственикът, 24.11.2026), и затова са без лиценз и без Content ID
претенции. `py audio.py <wav>` пише микса, а `render.py` после пуска `tools/video/presets.mjs loudnorm` (−14 LUFS,
−1,5 dBTP). Звукът е един за двете версии и не иска нов рендер: `py render.py light --only audio,encode`.

- **Музиката** (`score.py`) е спокойна и техническа, на 90 BPM, в ре мажор, с акорди през два такта. При 90 BPM всяка
  цяла секунда пада на осмина, затова всяка карта със стъпка е върху ритъма. Музиката расте с работата: пиано и фон за
  стъпки 1–3, лек пулс от пробиването (30 s), пълен ритъм от тресчотката (48 s) и втора мелодия при нивелирането
  (67 s). При рязането (112 s) остава само пулс под ъглошлайфа, а финалът (127 s) се разрешава в Dmaj9. Всяка
  карта има въздух преди нея и камбанка върху нея.
- **Шумовете** (`sfx.py`) са синтезирани от физиката на звука: удар (затихващи модове), допир (филтриран шум) и
  мотори (хармониците им). Тресчотката щраква по веднъж на зъб (72 зъба, 5°) на всеки обратен ход. Ъглошлайфът
  тръгва, забавя се 11 % под разреза, пращи с искрите и спира за около 2,4 s. Отрязъците падат на дъното на шахтата.
  Моментите са тези от `pose.py` и `cut.py`. Ако преместиш действие там, премести и звука му тук.
- **Миксът** (`audio.py`): шумовете звучат в шахтата (бетон, около 0,9 s ехо). Музиката се снишава според това
  колко над нея са шумовете: около −8 dB под ъглошлайфа, −6 dB под бормашината и нищо под щракване. Лимитерът
  гледа истинския пик (4× пресемплиране, `dsp.py`).

## Субтитри за YouTube

`py captions.py` пише `out/Panev_montaggio-in-undici-passi.it.srt` с италианските субтитри. Текстът е дума по дума този
от надписите в кадъра (`texts.py`, интрото и финалът от `overlay.py`) и е във времето на картите. Ред е до 42 знака,
субтитър до два реда. В YouTube текстът става търсим и зрителят може да си го преведе автоматично. Качва се в
YouTube Studio → „Субтитри“. Ако смениш текст, пусни го пак.

## На компютъра на собственика (Windows + NVIDIA)

PowerShell. id-тата са от `tools/video/README.md`.

```powershell
winget install Git.Git
winget install OpenJS.NodeJS.LTS
winget install Gyan.FFmpeg
winget install BlenderFoundation.Blender
winget install Python.Python.3.12        # или най-новия Python.Python.3.x
# нов терминал (PATH се обновява), после:
py -m pip install numpy pillow
```

Драйверът е NVIDIA **Studio Driver** от nvidia.com. Без него няма OptiX (рендер) и NVENC (кодиране).

```powershell
git clone https://github.com/stefkostefko92-ux/Few-few.git
cd Few-few
node tools/video/doctor.mjs                # готово ли е студиото
cd panev/3d
npm ci
node video/export_mesh.mjs                 # геометрията на планката → video/mesh/ (само локално)
cd video
py fetch_assets.py                         # Poly Haven (CC0) + Inter → assets/, проверка по хеш
py render.py light --gpu                   # лекият клип (1080p) на видеокартата
py captions.py                             # италианските субтитри за YouTube
py render.py heavy --bench 26              # един кадър: колко време на кадър
py render.py heavy                         # всичко; при прекъсване просто го пусни пак
```

Пусни го отново и той продължава оттам, където е спрял. Сцена продължава след последния записан кадър, а
сглобяването прескача готовите кадри. Само една част: `--only stills|shots|assemble|audio|encode`, само няколко
сцени: `--shots asm,pos`. Blender не е в PATH → `$env:BLENDER = "C:\…\blender.exe"`. Без NVENC →
`$env:VIDEO_ENCODER = "libx264"`.

## Устройство

| Файл | Какво прави |
| --- | --- |
| `timeline.py` | сцените и стъпките в секунди; `VIDEO_FPS` |
| `build.py` · `materials.py` · `props.py` · `lib.py` | сцената: стената 5° извън отвеса, двойките A+B, инструментите, прагът, светлините |
| `pose.py` · `motion.py` | къде е всичко в секунда t и точките за надписите |
| `hands.py` | ляво и дясно: SX вляво, DX вдясно; SX частта е огледалният образ на DX мрежата, болтовете не се огледалят (дясна резба) |
| `middle.py` · `rebar.py` | стъпка 10: средната планка, армировката (дупка с кухина, стомана, искра), смяната B DX → B SX на същата A DX |
| `ratchet.py` | тресчотката 3/8" с дълбока вложка 17 и ходовете ѝ (напред с гайката, назад без нея) |
| `grinder.py` · `cut.py` | стъпка 11: ъглошлайфът (моделиран тук), искрите и светлината им, булевото рязане на A и падащият отрязък |
| `shot.py` | една сцена кадър по кадър. Цял се рендерира само първият кадър, после само участъкът, който се мени (същият seed) |
| `run.py` | отделни кадри (интро, финал, проба) |
| `texts.py` · `overlay.py` | италианският текст и рисуването му (дизайн в 1920×1080, изход `VIDEO_OUT`) |
| `assemble.py` · `postfx.py` | кадри + изрези → цели кадри, преливане, надписи, затъмняване, bloom и зърно |
| `score.py` · `sfx.py` · `audio.py` · `dsp.py` | музиката, шумовете на инструментите, миксът и общото DSP (само numpy) |
| `captions.py` | италианските субтитри (SRT) за YouTube от надписите в кадъра |
| `render.py` | целият поток с двете версии |
| `fetch_assets.py` | активите с фиксирани адреси и хешове, плюс `assets/LICENSES.txt` |
| `export_mesh.mjs` | геометрията на двойката от `src/` на 3D каталога |

## Права и правила

- **Poly Haven** (CC0 1.0): текстурите `concrete` и `dirty_concrete`, HDRI `interior_construction`,
  моделът `Drill_01`. **Inter 4.0** (SIL OFL 1.1). Логото е на собственика. Ъглошлайфът и
  тресчотката с вложка 17 са моделирани тук (`grinder.py`, `ratchet.py`), без чужд актив и без марка.
  Записът е в `assets/LICENSES.txt`. Музиката и шумовете са синтезирани тук (`score.py`, `sfx.py`), без чужд
  семпъл.
- **Не влизат в git** `assets/`, `mesh/`, `render/`, `frames/` и `out/` (`.gitignore`). Геометрията на
  планките не излиза никъде (правилото „без CAD за сваляне“ в `panev/CLAUDE.md`).
- **Текстовете** са в `texts.py`. Провери ги Преводачът, а отворените въпроси ги реши собственикът
  (23.11.2026). Смяна на текст не иска нов рендер: изтрий `frames/<версия>/` и пусни
  `py render.py <версия> --only assemble,encode`.
