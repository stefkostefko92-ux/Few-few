# CLAUDE.md — iplookup/

**Карбон IP** — публична справка за IP адрес: мрежа и регистър (RDAP), автономна
система, местоположение (само когато е честно), обратен DNS с потвърждение, тип
на адреса (облак/CDN/робот/релей) и репутация. BG.
Домейн: `iplookup.carbonstealth.eu`.

## Стек и команди

Next.js 15 App Router · React 19 · TS strict · Tailwind · Zod. Path alias `@/*`.
**Няма база данни и няма бисквитки** — умишлено. Няма акаунти, няма съхранени
заявки.

```bash
cd iplookup
npm run dev
npm run lint && npm run typecheck && npm test && npm run build   # гейтът
```

## Продуктовият закон: честност пред пълнота

Пазарът е пълен със сайтове, които показват точка на карта и „град“ с фалшива
увереност. Нашият коз е обратното — **всяко твърдение носи източника си и
границите си**. Не отслабвай това:

1. **Никаква точка на карта, никакви координати.** Точността по град е ~66% „в
   рамките на 50 км“. Един центроид по подразбиране навремето прати стотици
   милиони адреса към една ферма в Канзас. Показваме държава и казваме на какво
   основание.
2. **Geofeed бие всичко.** `bestCountry()` в `src/lib/lookup.ts` подрежда
   източниците по достоверност: geofeed на оператора → релей → регистър → RIR.
   Не разменяй реда.
3. **„Няма попадение“ ≠ „чисто“.** Липсата в репутационен списък се изписва като
   „тези списъци не го познават“. Липсата в диапазон на доставчик **никога** не
   се изписва като „жилищна връзка“.
4. **„Няма данни“ ≠ „източникът падна“.** Двете състояния се показват различно
   (`EmptyNote` в `src/components/DataCard.tsx`).
5. **Един източник никога не сваля справката.** Всеки минава през `runSource`
   (таймаут + изолация на грешката) в `src/lib/sources/base.ts`.

## Твърди правила

- **Страниците `/ip/*` са `noindex, nofollow`** — в метаданните, в `robots.ts` и
  като HTTP заглавие в `next.config.mjs`. Това е решение от правния преглед, не
  SEO предпочитание: индексирането превръща справката в постоянен, търсим
  указател за трети лица и обръща баланса по чл. 6(1)(е) от ОРЗД. **Не го
  премахвай.** Индексируемо е само `/`, `/kak-raboti` и правните страници.
- **Никакво активно сканиране.** Не отваряме връзки към търсения адрес (нито
  TLS сонда, нито портове, нито ICMP). Инструмент, който прави това от чуждо
  име, е скенер, а не справочник — и е DDoS усилвател.
- **Цветът никога не носи смисъл сам.** Всеки знак има икона + текст (`Badge`).
  Червено/зелено е точно двойката, която далтонизмът заличава.
- **Палитрата е в `src/lib/theme.ts` и е ГЕЙТНАТА.** `theme.test.ts` смята
  реалните контрасти по WCAG 2.1 за двете теми върху трите повърхности.
  `tailwind.config.ts` чете същите стойности — **не пиши HEX никъде другаде.**
- **Обещанието „без реклами, без проследяване, без бисквитки“ е обвързващо**
  (ЗЗП + политиката за поверителност). Добавиш ли аналитика, първо се пренаписват
  `/poveritelnost` и `SECURITY.md`, после кодът.

## Лицензи на източниците — какво е позволено

Проверено при проектирането; при добавяне на източник провери наново.

| Позволено | Забранено (не добавяй) |
|---|---|
| RDAP на всички RIR + IANA bootstrap | **RIPEstat** — иска писмено разрешение за търговска употреба |
| Team Cymru IP→ASN („Free. Forever.“) | **ip-api.com / ipapi.co** — само нетърговски |
| Geofeed на операторите (RFC 8805/9092) | **Spamhaus DNSBL** — публичните огледала са нетърговски |
| Публични диапазони на AWS/Google/Cloudflare/Fastly/Apple | **Shodan InternetDB** — нетърговски (иначе enterprise лиценз) |
| Tor exit list / Onionoo | **MaxMind GeoLite2** — EULA забранява локализиране на лице/домакинство и иска унищожаване на старата база до 30 дни |
| Spamhaus **DROP** — с изричен кредит | |

**Кредитите са задължителни** и живеят в `src/lib/site.ts` → `DATA_SOURCES`
(показват се във футъра и на `/kak-raboti`). Не махай реда за Spamhaus.

**RIPE AUP**: кеш по заявен адрес, никакво огледало, никакви масови заявки.
Затова `src/lib/sources/rdap.ts` кешира УСПЕШНИТЕ отговори по адрес (6 ч).

## Подредба

```
src/lib/ip.ts            ← чистата сърцевина: разбор, специални диапазони,
                            вграден IPv4 (6to4/Teredo/NAT64/ISATAP), EUI-64→MAC
src/lib/theme.ts         ← палитрата (гейтната за контраст)
src/lib/cidr-set.ts      ← бърз мач срещу хиляди префикси
src/lib/client-ip.ts     ← X-Forwarded-For се чете ОТДЯСНО (виж по-долу)
src/lib/lookup.ts        ← оркестраторът + подредбата на геоизточниците
src/lib/sources/         ← по един файл на източник, всеки изолиран
src/app/ip/[ip]/         ← резултатът (noindex, стриймва мрежовата част)
src/app/kak-raboti/      ← единственото индексируемо съдържание със стойност
```

## Капани

- **`X-Forwarded-For` се чете отдясно, не отляво.** Заглавието е потребителски
  вход; прокситата ДОПИСВАТ отдясно. „Първият отляво“ позволява на всеки да си
  избере IP. Броят наши прокси-та се задава с `IPLOOKUP_TRUSTED_HOPS` (по
  подразбиране 1). `IPLOOKUP_TRUST_CLOUDFLARE=1` само ако наистина сме зад CF.
- **Водещите нули в IPv4 се отхвърлят** (`010.0.0.1`). Осмичната двусмислица е
  класическа повърхност за заобикаляне на филтри.
- **Geofeed адресът идва от чужд регистър** — единственият URL в продукта, който
  не е константа. Минава през `safeUrl()`: само HTTPS, само порт 443, всички
  резолвнати адреси трябва да са публични, `redirect: "error"`.
- **Локалният анализ се рисува преди мрежовия.** `LocalAnalysis` е синхронен,
  `NetworkAnalysis` е в `Suspense`. Не ги слепвай — иначе първият екран чака
  най-бавния източник.
- **Един адрес — един URL.** `/ip/2001:0db8::1` прави 307 към компресираната
  форма. Проверката е `parsed.normalized !== raw`.
- **Тъмната тема е по подразбиране** (`:root`), светлата е клас `.light`. Затова
  Tailwind е БЕЗ `darkMode` — не го включвай „за ред“.
