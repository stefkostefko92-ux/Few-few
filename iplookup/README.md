# Карбон IP

Публична справка за IP адрес, която казва **и какво данните не могат да кажат**.

Продукт на [Carbon Stealth VCC](https://carbonstealth.eu).
Домейн: `iplookup.carbonstealth.eu`.

## Какво показва

| Раздел | Източник |
|---|---|
| Мрежа, регистър, контакт при злоупотреба | RDAP направо от RIPE/ARIN/APNIC/LACNIC/AFRINIC (през bootstrap на IANA) |
| Автономна система и обявен префикс | Team Cymru IP→ASN (през DNS) |
| Местоположение | Geofeed на оператора (RFC 8805) с предимство; иначе държава по регистрация |
| Облак / CDN / робот / релей | Публичните диапазони на AWS, Google, Cloudflare, Fastly, Googlebot, Apple Private Relay |
| Обратен DNS | PTR + потвърждение в двете посоки (FCrDNS) |
| Репутация | Tor exit list, Spamhaus DROP |
| Какво издава самият адрес | Специални диапазони, вграден IPv4 (6to4/Teredo/NAT64/ISATAP), EUI-64 → MAC адрес |
| Геолокация | Офлайн DB-IP City Lite — чете се от диск, не издава на никого кой адрес е проверен. Град само при доказана инфраструктура; мобилните пулове падат до държава |
| Карта и координати | Откроена държава върху карта на света + географски център на държавата (Natural Earth, обществено достояние; нула външни доставчици на плочки) |
| Активна проверка *(по избор)* | Осем познати порта, сертификат на 443 (полето SAN издава кой стои зад адреса), HTTP банер |

Редът „какво издава самият адрес“ не изисква нито една мрежова заявка — затова се
рисува моментално, докато останалото се стриймва. Активната проверка е
**единственото**, което се свързва с търсения адрес, и тръгва само по натискане
на бутон.

## С какво се различава

- **Карта на държава, не игличка върху град.** Точността по град е ~66% „в
  рамките на 50 км“. Координатите, които показваме, са на географския център на
  държавата — и са надписани точно така.
- **Всяко твърдение носи източника си** и времето, за което е получено.
- **„Няма попадение“ не се представя като „чисто“**, а „няма данни“ не се
  представя като „източникът падна“.
- **Без реклами, без проследяване, без бисквитки, без запис на търсенията.**
- **Активната проверка е по изрично действие**, на фиксирани осем порта, с
  лимит 5/минута — справочник, който може да провери, а не скенер за общо
  ползване. Никакъв ICMP.

## Разработка

```bash
cd iplookup
npm install
npm run dev                # http://localhost:3000

npm run lint && npm run typecheck && npm test && npm run build
```

Последният ред е качествената порта — минава ЦЯЛА, преди работа да се смята за
готова.

## Настройки на средата

| Променлива | По подразбиране | За какво |
|---|---|---|
| `IPLOOKUP_TRUSTED_HOPS` | `1` | Колко НАШИ обратни прокси-та стоят отпред. Всяко дописва по един запис в `X-Forwarded-For`. |
| `IPLOOKUP_TRUST_CLOUDFLARE` | изключено | `1` само ако сайтът наистина е зад Cloudflare. |
| `IPLOOKUP_GEOIP_DB` | няма | Път до DB-IP City Lite. Свали я с `node scripts/fetch-geoip.mjs`. Без нея справката работи без гео слой. |
| `IPLOOKUP_MODE` | `public` | `investigation` включва следствената справка и ИЗКЛЮЧВА издайническите източници. |
| `IPLOOKUP_ALLOW_GEOFEED` · `IPLOOKUP_ALLOW_PROBE` | изключени | Отключват съответно geofeed и активната проверка в следствен режим. И двете уведомяват външна страна. |
| `IPLOOKUP_SESSION_SECRET` | няма | Задължителна в следствен режим. Без нея входът връща 503. |
| `IPLOOKUP_USERS_FILE` · `IPLOOKUP_AUDIT_DIR` · `IPLOOKUP_EVIDENCE_DIR` | `data/…` | Служители, одиторски дневник, замразени артефакти. |

### Следствено издание — пускане

```bash
node scripts/add-user.mjs ivanov "Иван Иванов" "РПУ Дупница" operator

```

Пълните изисквания и какво още липсва: `SECURITY.md` → „Следствено издание“.

Няма API ключове. Продуктът работи изцяло с безплатни, публични източници,
разрешени за търговска употреба — списъкът и забраните са в `CLAUDE.md`.
