# Лаборатория на агентите (agents-dashboard)

Уеб средата, в която „живеят“ персонализираните Claude Code агенти на този монорепо.
Показва за всеки агент: способности, **времева линия на развитие** (версии) и **поток
на дейността**.

## Стартиране

```bash
# Най-просто: отвори index.html директно в браузъра (работи и през file://).
# Или го сервирай локално (за да чете живо agents.json):
python3 -m http.server -d agents-dashboard 8080
# после http://localhost:8080
```

## Файлове

- `index.html` — самостоятелна страница (без build стъпка). Чете `agents.json` през
  `fetch`; ако не успее (file://), ползва вграден снимков фалбек, така че винаги рендира.
- `agents.json` — **каноничният манифест**: източникът на истината за таблото.

## Как да добавиш/обновиш агент

1. Създай/редактирай дефиницията в `../.claude/agents/<id>.md` (YAML frontmatter +
   системен промпт на български).
2. Добави/обнови записа в `agents.json`: при промяна вдигни версията и добави нов запис
   в `evolution` (и при нужда в `activity`).
3. Пресинхронизирай вградения фалбек в `index.html` (замени обекта `FALLBACK` със
   съдържанието на `agents.json`).

## Важно за „учене“

Claude Code субагентите са **без постоянна памет** между извикванията — не „учат“
автоматично. Таблото показва честния еквивалент: как се **развива дефиницията** им
(версии) и за какво се **използват** (дейност). „Учене“ тук означава източниците на
знание, които сме вградили в системния им промпт.
