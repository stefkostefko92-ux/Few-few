# Бобов дол — Хроника на един град (второ, коригирано издание)

Генератор на книгата на Стефан Л. Костадинов за историята на град Бобов дол.
Второ издание — преработено след пълна фактическа, визуална и езикова проверка
на първото (април 2026). Всички корекции са описани в
[`docs/fakt-proverka.md`](docs/fakt-proverka.md).

## Структура

| Файл | Съдържание |
|------|------------|
| `build_book.py` | ReportLab генератор — оформление, корици, илюстрации (герб, карта, дефтер, разрез, времева линия) |
| `content_a.py` | Предговор + части I–III (глави I–IX) |
| `content_b.py` | Части IV–VI (глави X–XIX) |
| `content_c.py` | Части VII–VIII, епилог, за автора, източници |
| `docs/fakt-proverka.md` | Пълният доклад от проверката на първото издание (42 фактически точки с източници) |
| `photos/` | Реални фотографии от Уикимедия Общомедия (свободни лицензи — PD/CC0/CC BY/CC BY-SA, кредити в „Източници“ на книгата) |
| `out/Bobov-dol-Hronika.pdf` | Генерираната книга (A5, ~91 стр.) |

## Генериране

```bash
pip install reportlab
python3 build_book.py     # → out/Bobov-dol-Hronika.pdf
```

Шрифтове: Liberation Serif (`/usr/share/fonts/truetype/liberation`) — пълна
кирилица, наличен по подразбиране в Debian/Ubuntu.

## Какво е поправено спрямо първото издание (най-важното)

- връх Колош: **1314 м** (не 1210), първенец на Колошкия дял;
- съседствата и дължината на Конявска планина;
- изречението за Паисий/Берон/Габровското училище (3 фактически грешки);
- „боб“ е **праславянска** дума (не прабългарска);
- Указ № 788 е на **Президиума на Народното събрание** от 26.10.1967 (обн. 31.10);
- теснолинейката: **600 мм, 26 км**, строена 1916–1917 от Щаба на действащата армия;
- ТЕЦ: съветски турбини ЛМЗ + полски котли РАФАКО; СОИ в **милиграми**; продажбата юни 2008 – януари 2009;
- „Бобов дол днес“: закрит подземен добив (2018), реални числа по НСИ (преброяване 2021 / 31.12.2024), реални училища и банки;
- селата: „Голема Фуча“, коригирани населения (Долистово ~260, Локвата под 10 и др.);
- махнати: кандидатурата за общински съветник/кмет и мотивите за „връщане в България“;
- бейзболът на никарагуанците е обозначен като устно предание;
- добавени: затворът, краят на подземния добив 2018, фотоволтаичният парк на ТЕЦ, времева линия в правилен хронологичен ред (с 2018 г.);
- премахнати: счупеният надпис на герба (стр. 12→13), „петната“ по илюстрациите, плейсхолдър ISBN, анахронизмът „миньорско предназначение“ в дефтера от 1576 г.
