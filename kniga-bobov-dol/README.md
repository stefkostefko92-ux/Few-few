# Бобов дол — Хроника на един град (второ, коригирано издание)

Генератор на книгата на Стефан Л. Костадинов за историята на град Бобов дол.
Второ издание — преработено след пълна фактическа, визуална и езикова проверка
на първото (април 2026) и втори кръг на проверка (октомври 2026). Корекциите са в
[`docs/fakt-proverka.md`](docs/fakt-proverka.md); **какво още чака потвърждение от автора** —
в [`docs/za-proverka-ot-avtora.md`](docs/za-proverka-ot-avtora.md).

## Структура

| Файл | Съдържание |
|------|------------|
| `build_book.py` | Оркестратор: подредба на книгата, колонтитули, **автоматично подгонване на страниците** (избира най-добра позиция на илюстрациите и междуредие ±3 %) |
| `typo.py` | Типография: стилове, шрифтове, хифенация (pyphen, bg_BG), drop-cap, автоматично съдържание с номера и контури на PDF, `<draft>` маркери |
| `art.py` | Корица и задна корица, карта, времева линия, дефтер, разрез, етимология, герб, рамка за снимки |
| `geo_data.py` | Реални географски данни за картата (граница на общината, 18 места, връх Колош) — OpenStreetMap, ODbL |
| `content_a.py` / `content_b.py` / `content_c.py` | Текстът: предговор + части I–III / части IV–VI / части VII–VIII, епилог, „числа“, за автора, източници |
| `fonts/` | EB Garamond (SIL OFL) — Regular, Medium, Bold, Italic, Bold Italic; вж. `fonts/README.md` |
| `photos/` | Фотографии от Уикимедия Общомедия (свободни лицензи; кредитите са под всяка снимка и в „Източници“) |
| `docs/` | Доклад от проверката и файл „за проверка от автора“ |
| `out/Bobov-dol-Hronika.pdf` | **Чистото издание** (A5, четен брой страници) |
| `out/Bobov-dol-Hronika-ZA-PROVERKA.pdf` | Същата книга с **жълто маркирани** чернови, които авторът трябва да потвърди |

## Генериране

```bash
pip install reportlab pillow pyphen      # pyphen — по желание (хифенация)
python3 build_book.py                    # и двата PDF-а (~1–2 мин: подгонва страниците)
python3 build_book.py --clean            # само чистото издание
```

В текста `<draft>…</draft>` обгражда пасаж, написан като чернова от името на автора:
в чистото издание маркерът е невидим, в „ЗА-ПРОВЕРКА“ е жълт фон.

## Какво е поправено спрямо първото издание (най-важното)

- връх Колош: **1314 м** (не 1210), първенец на Колошкия дял; съседствата и дължината на Конявска планина;
- изречението за Паисий/Берон/Габровското училище (3 фактически грешки); „боб“ е **праславянска** дума;
- Указ № 788 е на **Президиума на Народното събрание** от 26.10.1967 (обн. 31.10);
- теснолинейката: **600 мм, 26 км**; ТЕЦ: съветски турбини ЛМЗ + полски котли РАФАКО; продажбата юни 2008 – януари 2009;
- „Бобов дол днес“: закрит подземен добив (2018), реални числа по НСИ (преброяване 2021 / 31.12.2024);
- населението по години (1956–2024, връх 1978 — 8 306) и язовир Дяково (1975, 35,0 млн. м³) — по bg.wikipedia;
- махнати: кандидатурата за общински съветник/кмет и мотивите за „връщане в България“;
- **карта по реални координати** (OpenStreetMap) вместо измислена схема; **истинският герб** на общината;
- реални фотографии, нова корица, оформление с EB Garamond, хифенация, drop-cap, съдържание с номера.
