# Герб на Бобов дол — изходен материал

- `Bobov.dol-coat-of-arms.png` — единственото достъпно онлайн изображение на герба
  (Wikimedia Commons, 132 × 190 px, маркирано като обществено достояние; официалният
  символ на общината). Оригиналният уебсайт на общината (bobovdol.egov.bg) не беше достъпен
  (HTTP 503), векторен файл няма и в хранилището „bulgarian-city-coat-of-arms“ (за Бобов дол
  всички формати са отбелязани като липсващи).
- `make_gerb_data.py` — трасира (potrace) орнаментите в долното поле → `../gerb_data.py`.
  Останалото (силует, полета, светкавици) е геометрия, измерена по пикселите на оригинала
  и записана в `../gerb.py`. Надписът е с шрифт Liberation Sans Bold (SIL OFL).

Растерът е твърде малък за печат, затова гербът в книгата е пресъздаден векторно и е остър
при всякакъв размер. **За перфектен резултат поискайте векторния файл (AI/SVG/PDF) директно
от Община Бобов дол** — тогава `gerb.py` се заменя с него.
