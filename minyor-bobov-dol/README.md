# ФК „Миньор“ Бобов дол — официален уебсайт

Професионален уебсайт на футболния клуб **ФК „Миньор“ Бобов дол** („миньорите“):
новини, програма и резултати, класиране, състав, история, галерия и контакти,
с административен панел за самостоятелно поддържане на съдържанието.

Сайтът е дарение от **[Carbon Stealth VCC](https://carbonstealth.eu)** в полза на
клуба и неговите привърженици.

## Възможности

- **Начало** — следващ мач, последни резултати и форма, актуални новини, спонсори.
- **Отбор** — състав по позиции и треньорски/ръководен щаб.
- **Програма и резултати** — предстоящи мачове и изиграни срещи по сезони.
- **Класиране** — таблица на групата с откроен собствен отбор.
- **Новини** — публикации със структурирани данни за търсачки (NewsArticle).
- **История и постижения**, **Стадион „Николай Кръстев – Шулц“**, **Галерия**.
- **Контакти** — форма за връзка (записва се в базата, по избор изпраща имейл).
- **Администрация** (`/admin`) — управление на всичко изброено, роли и одит лог.

## Съответствие с дигиталните директиви

- **Достъпност (WCAG 2.1 AA / EN 301 549, ЗЕУ):** семантичен HTML, прескачаща
  връзка, видим фокус, ARIA, лента за достъпност (размер на текста, висок
  контраст, тъмен режим, по-лесно докосване), декларация за достъпност.
- **GDPR / ЗЗЛД:** политика за поверителност и за бисквитки, банер за съгласие,
  без рекламно проследяване, минимизиране на събираните данни.
- **Сигурност:** строги HTTP заглавия (CSP, HSTS, X-Frame-Options,
  Referrer-Policy, Permissions-Policy), хеширани пароли (bcrypt), JWT сесии,
  ограничаване на опитите за вход, валидиране на въведените адреси, `security.txt`.
- **SEO / AEO:** Metadata API, canonical, Open Graph/Twitter, `sitemap.xml`,
  `robots.txt`, `llms.txt`, структурирани данни (SportsOrganization, SportsTeam,
  SportsEvent, NewsArticle).
- **PWA:** уеб манифест, икони, инсталируемост, минимален service worker.

## Технологии

Next.js 15 (App Router) · React 19 · TypeScript (strict) · Tailwind CSS 3 ·
Prisma ORM (PostgreSQL) · jose (JWT) · bcryptjs · Zod · Phosphor Icons.

## Локално стартиране

```bash
# 1. Зависимости
npm install

# 2. Настройки
cp .env.example .env   # попълнете DATABASE_URL, AUTH_SECRET, ADMIN_*

# 3. Схема и примерни данни (нужен е работещ PostgreSQL)
npx prisma db push
npm run db:seed

# 4. Разработка
npm run dev            # http://localhost:3000  ·  админ: /admin/login
```

### Полезни команди

| Команда             | Действие                                  |
| ------------------- | ----------------------------------------- |
| `npm run dev`       | Локален сървър за разработка               |
| `npm run build`     | Продукционен билд (`prisma generate` + Next) |
| `npm run start`     | Стартиране на продукционния билд           |
| `npm run lint`      | ESLint проверка                            |
| `npm run typecheck` | Проверка на типовете (TypeScript)          |
| `npm run db:seed`   | Първоначален администратор + примерни данни |
