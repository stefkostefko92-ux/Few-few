## Какво влиза — по ред

### 1. Лекота на страницата (голямо) — първо, защото е единственото, в което губим

- `picker.js`/`picker.css` — само когато потребителят натисне „Скрий елемент“ (`scripting.executeScript`,
  вече имаме правата), не на всяка страница.
- `cosmetic_generic.css`: разделяне на „горещи“ правила (тези, които реално хващат на популярните сайтове —
  мерено с `tools/perf_memory.mjs` + броене на попаденията) и „студени“, които се зареждат само ако
  страницата има рекламни признаци. Без голям `:is()` списък (инвариантът от `CLAUDE.md` остава).
- `scriptlets/ubo/entities.js` (161 KB във всяка рамка) → таблица по хост, регистрирана само за хостовете,
  за които има директиви (както вече правим с чънковете `ubo/cNN.js`).
- `content.js`: Smart Detection и процедурните селектори — само когато страницата има рамки/правила за
  хоста; `cookies.js` — в рамките само когато има признак за банер.
- Гейт преди релийз: `tools/perf_memory.mjs` и `tools/perf_speedtest.mjs` срещу 5.8.0.

**Готово, когато:** 5 тежки страници добавят **≤ 45 MB** (днес 95–125); fetch е в рамките на 3 % от
браузъра без блокер; Turtlecute ≥ 128/132 и adblock-tester ≥ 95; `npm test` и `npm run test:browser` —
зелени; числата са публикувани на `/how-we-measure`.

### 2. Режими на защита (средно)

Basic · Standard · Strict — за всички сайтове и поотделно за сайт (като Brave/uBOL; `docs/ROADMAP.md` т. 8).
- **Basic:** само мрежово блокиране (DNR) — най-леко, почти нищо не се чупи.
- **Standard (подразбиране):** днешното без „студения“ CSS.
- **Strict:** всичко + генеричното скриване навсякъде + Фокус.

Един превключвател в popup-а, запомнен за сайта. **Готово, когато:** превключването важи без презареждане
на разширението; тестове за трите режима; popup ≤ 600 px на 73 локала; axe чисто.

### 3. Отчет „Кой те следи“ (средно)

Страница в Настройки: компаниите, които сме спрели или видели през последните 30 дни (Google, Meta, Amazon…),
по брой заявки и по дни — от `popup/companies.js`, разширена от 75 на ~200 проверени домейна.
Пазим само брой по компания по ден (без адреси и сайтове), на устройството.

**Готово, когато:** нищо не излиза от устройството; паметта за отчета ≤ 50 KB; политиката за поверителност
го описва; новите низове са във всичките 73 локала (`tests/i18n.test.mjs`); axe чисто.

### 4. AI на устройството за скритите реклами (голямо, по избор, експериментално)

Разпознава „Sponsored“/„Promoted“ кутии и платено съдържание на всеки сайт с Gemini Nano в самия Chrome
(Prompt API, Chrome 138+, Windows/macOS/Linux; само en, ja, es, de, fr; нужни 16 GB RAM, над 4 GB VRAM и
22 GB свободно място — developer.chrome.com, 21.10.2026). Изключено по подразбиране; включва се в Настройки.

**Преди да започнем — проба на твоя компютър:** разархивираното разширение →
`chrome-extension://<id>/tools/ai_probe.html` → „Пусни пробата“. **Продължаваме само ако** е вярно ≥ 11 от 12
и средно ≤ 500 ms на текст; иначе отива за 6.1.

Дизайн: до 20 кандидата на страница (кутии с къс етикет до линк), кеш по текст, първо само очертаване
(както `metaDebug`), после скриване; „Върни“ за сайта; нищо по мрежата; само за реклами (единствената цел в
Chrome Web Store остава). **Готово, когато:** пробата мине; 0 заявки по мрежата; ≤ 2 s CPU на страница;
политиката за поверителност го описва.

### 5. YouTube и Twitch — надеждност (малко)

`tools/youtube_check.mjs` по график от твоя компютър (Task Scheduler / cron, всеки ден); същото за Twitch
(2 минути канал, без preroll). `/status` показва датата. **Готово, когато:** 14 поредни дни зелено преди 6.0.

### 6. Разпространение (малко — твоите акаунти)

Edge, Opera и Firefox (с теста на Android) — живи **преди** 6.0, по `supreme-adblock-5.8.0-stores.pdf`.
След това линкове на сайта и в README. Safari — на пауза (платено членство).

### 7. Доверие и поддръжка (малко)

- GitHub Releases за всяка версия: zip + SHA-256 (за проверка срещу магазина).
- Форма за счупен сайт в GitHub Issues (освен имейла).
- Седмичният PR с пресни листи — щом GitHub Actions на акаунта тръгне (Settings → Billing).
- 6.0.x на всеки две седмици с пресни листи.

## Не влиза в 6.0

Safari (платено) · защита от fingerprinting (чупи сайтове, извън единствената цел) · DNS/VPN/прокси ·
платени нива · „Acceptable Ads“.

## Как разбираме, че 6.0 е по-добра

- Страниците: ≤ 45 MB добавени (днес 95–125); fetch в рамките на 3 %.
- Блокиране: не по-малко от 5.8.0 (Turtlecute, adblock-tester, browser тестовете).
- YouTube: 14 дни зелена проверка.
- Магазини (`docs/METRICS.md`): седмични потребители, оценка, деинсталации спрямо инсталации — сравнени
  по периоди (под 300 потребители — абсолютни числа, корелация, не причина).

## Рискове

- **Олекотяването може да пропусне реклами** → гейт на лабораторните тестове и browser тестовете.
- **AI:** малко потребители имат нужния хардуер; грешно скрита органична публикация → първо очертаване,
  „Върни“ за сайта, изключено по подразбиране.
- **Нови низове в 73 локала** — машинно подпомогнати, без медицински/правни текстове; гейтът `i18n`.
- **Ревю в магазините:** без нови права (`executeScript` е в `scripting`, който имаме); политиката се
  обновява за отчета и AI.
