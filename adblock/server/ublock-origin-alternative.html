A uBlock Origin alternative for Chrome

Chrome no longer offers uBlock Origin in its store. The uBlock Origin README lists it for Firefox, Edge, Opera and Thunderbird, and links uBlock Origin Lite as a related project. Supreme AdBlock is a free Manifest V3 ad blocker for Chrome and Edge, made by Carbon Stealth. This page lists the differences, including where uBlock Origin Lite is ahead. Checked on 23 October 2026, extension version 5.5.1.

What happened to uBlock Origin in Chrome

  • The uBlock Origin README lists its Chrome Web Store entry as “Removed on 2026-08-31”. It quotes Google's timeline: “Aug 31st 2026: All remaining Manifest V2 extensions removed from the Chrome Web Store.” Source: github.com/gorhill/uBlock, read 23 October 2026.
  • The same README lists uBlock Origin on Firefox Add-ons, Microsoft Edge Add-ons, Opera Add-ons and Thunderbird Add-ons, and offers Firefox, Chromium MV2 and Thunderbird builds on GitHub. Those builds must be added by hand, and the Chromium one usually does not update itself.
  • Manifest V2 and V3 are the two rule books for Chrome extensions. V3 limits how an extension can change a page's traffic, and ad blockers had to be rewritten for it.

Whether an old install still runs depends on your browser version and settings. We did not test that, so this page does not say.

What uBlock Origin Lite is

uBlock Origin Lite (uBO Lite) is a separate extension from the uBlock Origin project, built on Manifest V3. Its author describes it as a “reliable and efficient MV3-compliant content blocker, leveraging the filter lists used by uBO”, and as “too different from uBO to be an automatic replacement”. Source: uBOL FAQ, read 23 October 2026.

The project lists installs for Chrome, Edge, Firefox and Safari. If you want to keep the uBlock Origin project's work in Chrome, uBO Lite is the first thing to try.

Where Supreme AdBlock differs

  • Filter data updates between releases. The extension fetches a signed, data-only filters.json about every 12 hours. It holds domains, CSS selectors and YouTube fields, and it is never run as code. The Ed25519 signature is checked where the browser supports it.
  • YouTube. It removes ad fields from YouTube's responses before the player reads them. If YouTube refuses to play, it steps aside for six hours so the video plays, with ads. How it works.
  • Cookie banners. It presses Reject when the banner offers it, and presses Accept only when there is no other way to close the banner. Details.
  • Focus mode. Optional switches that hide things that are not ads but get in the way. All are off until you turn them on.
  • A repair page. Site broken? Fix it or tell us offers fixes one at a time, for one site or for 30 minutes everywhere. Steps.
  • 70 languages in the interface, and an MIT licence.

What Supreme AdBlock does not do

  • It is not a copy of uBlock Origin and has no uBlock Origin dynamic filtering matrix (its “My rules”).
  • There is no Firefox or Safari release.
  • It cannot promise to block every ad. Sites change. A missed ad can be hidden with the element picker, or described to us by email from the popup’s “Site broken?” page.
  • It has no account, no paid tier, and no analytics. Privacy policy.

How to move from uBlock Origin

  1. Install Supreme AdBlock from the Chrome Web Store.
  2. In uBlock Origin, open the dashboard, then the Settings pane. In the bottom section, “Backup/restore”, choose the backup button. uBO saves a text file. uBO wiki: Settings, read 23 October 2026.
  3. In Supreme AdBlock, open Settings from the popup and find Import from another ad blocker.
  4. Choose the uBlock Origin file. The page shows Sites allowed and Filters added. Anything it could not apply is counted under Left out.

Nothing is replaced. The import only adds. It works the same way for AdGuard and Adblock Plus backups.

What is imported

  • Your trusted sites (a whole site, such as example.com or *.example.com).
  • The lines in your My filters: domain blocks and cosmetic filters (site##selector).

What is not imported

  • Your filter list subscriptions and your uBlock Origin settings. Turn on lists in Supreme AdBlock yourself.
  • My rules (dynamic filtering).
  • Trusted-site entries that are a path, a regular expression or a browser-page scheme.
  • Filter lines with scriptlets (+js(), cosmetic exceptions (#@#) and anything else that cannot be applied safely. Such lines are skipped and counted as “Left out”.

Sources: lib/foreign.js and parseImportedList in background.js, 23 October 2026. The file is read as text and never run.
