# CLAUDE.md — boy

„Двубой в Рейвънхолд" — кинематографичен средновековен двубой в реално време в браузъра (WebGPU с
автоматичен преход към WebGL 2, three.js r186, шейдъри на TSL). Доспехи, огън, дъжд и звук се
генерират от код; PBR текстурите се изпичат процедурно при билда (2–4K WebP); движението на тялото
идва от motion capture (CMU, subject 02). Единственият модел е 3D скан на глава (Lee Perry-Smith,
CC BY 3.0 в `assets/head/`), от който изпичането прави двете лица с мимика. Видео няма. Демо,
**не** продукт с деплой.

## Команди (гейтът)

```bash
cd boy
npm ci
npm run gate           # check.mjs (синтаксис · правила · договор) → node --test → пълен билд
npm run build          # изпича текстурите (кеш по хеш на изходниците) + dist/ravenhold.html
xvfb-run -a npm run smoke   # Chromium: WebGPU и WebGL 2, нула грешки, кадри в dist/smoke/
node bake/mocap.mjs    # само при промяна на конвертора: BVH → data/mocap/cmu-swordplay.json
```

`npm run gate` е гейтът в CI (първото изпичане е ~2–3 мин; после е кеширано). WebGPU платното се
показва само в браузър с прозорец, затова `smoke` иска дисплей (`xvfb-run`); без дисплей тества само
WebGL 2. Рендерът там е софтуерен — меродавни за fps са бутонът **Stats** и истинска GPU.

## Структура

| Файл | Отговорност |
|------|-------------|
| `src/main.js` | WebGPURenderer (`?webgl` форсира WebGL 2), часовник, камера, кадров цикъл |
| `src/world.js` | сглобява сцената; `animateWorld()` движи всичко в „story time" |
| `src/pipeline.js` · `post-*.js` | RenderPipeline: MRT → SSGI/GTAO · SSR · god rays → TRAA → RCAS → bokeh DOF (тънка леща) → motion blur (реконструкционен филтър) → bloom + анаморфни ивици → грейд |
| `src/tsl.js` · `fog.js` · `surface.js` · `materials.js` | TSL: общ часовник и шум, височинна мъгла, мокри повърхности, PBR материали |
| `src/baked.js` · `bake/` | изпечени PBR набори (albedo · normal+височина · ORM); `bake/sets/*` са генераторите |
| `src/mocap.js` · `mocap-body.js` · `data/mocap/` | motion capture слой за тялото, подравнен с DTW към хореографията |
| `src/choreo.js` · `timeline.js` | двубоят като каскадьорски сценарий; контактите се решават геометрично |
| `src/rig.js` · `feet.js` · `fighter.js` · `flight.js` | скелет, двукостно IK, стъпки, реакции, изтръгнатият меч |
| `src/armor.js` · `weapons.js` · `batcher.js` | процедурни доспехи и яки → `BatchedMesh` по материал; `helmets.js` само ако главите липсват |
| `bake/head*.mjs` · `assets/head/` | сканът → `tex/head.bin`: отворени очи около очни ябълки, разтваряне на устните, изрази, лицето на Надзирателя, маски за коса/брада/вежди/устни, кривина и дебелина на кожата |
| `src/head.js` · `skin.js` · `eyes.js` · `eye-shape.js` · `hair.js` · `teeth.js` | главите в сцената: кожа (предварително интегрирано SSS), очи с пречупване, коса и брада от черупки, зъби |
| `src/face.js` | мимиката в story time: мигане, напрежение, болка, дишане, поглед |
| `src/quality.js` | нива на качество и регулатор на резолюцията за 60 fps |
| `test/` | `node:test`, вкл. симулация на целия двубой без GPU (`fight.test.js`) и изпичането |

## Закони на пакета

1. **Файл ≤ 300 реда, нула `console.*` и `TODO` в `src/` и `bake/`.** Гейтнато от `check.mjs`.
2. **Версията на three.js в import map-а = `devDependencies.three`.** Тестовете вървят срещу същата
   версия, която зарежда страницата. Гейтнато.
3. **Само TSL.** `ShaderMaterial`, `onBeforeCompile` и `ShaderChunk` не съществуват за
   WebGPURenderer — мълчаливо се игнорират. Всеки шейдър е node материал на TSL (и върви на двата
   бекенда). Шумът се чете от общата текстура (`noise()` в `tsl.js`), не се смята fBm на пиксел.
4. **Бюджет за 60 fps.** Нов твърд обект минава през `RigidBatcher`. Нови частици са инстанции.
   Сцената пише най-много 4 MRT цели (32 байта на пиксел е преносимият лимит на WebGPU). Прозрачните
   ефекти не пишат G-buffer (`sceneMRT` в `tsl.js`). Скъпите ефекти вървят на половин резолюция.
5. **Хореографията е в координати `[дясно, горе, напред]` спрямо бойца.** Ключовете `aim`, `parry`
   и `block` се решават геометрично. Motion capture слоят мести само тялото и отстъпва, когато би
   отдалечил рамо от ръката. След промяна: `npm test` (`fight.test.js` хваща откачени ръце над 3 см,
   крака в земята и пропуснати удари).
6. **Достъпност:** без стробоскоп (мълнията е два импулса), `prefers-reduced-motion` маха трясъка и
   „ръчната" камера, интерфейсът е изцяло с клавиатура (Space · C · M · S).
7. **Кредит** „Created and Designed by Carbon Stealth VCC" и **ключови думи ≥5** с „Carbon Stealth" —
   гейтнато в `template.html` и `package.json`. Motion capture данните носят признанието на CMU.
   Лицата носят признанието на скана (Lee Perry-Smith, CC BY 3.0) на финалния надпис и на трите
   езика — лицензът го изисква, `check.mjs` го гейтва.
8. **Главите:** изходните файлове в `assets/head/` не се пипат (контролни суми в README-то там);
   всичко се прави в `bake/head*.mjs`. Изразите в `face.js` (`EXPRESSIONS`) трябва да съвпадат с
   изпечените (`MORPHS`). След промяна: `npm test` (`head.test.js` пази клепачите извън очните
   ябълки при мигане и присвиване, отворения ирис, затворените в покой устни и очите на
   Надзирателя на място). Последният удар (21.55 s) пада върху наплечника, не върху главата —
   `fight.test.js` пази и това. При близък план камерата фокусира в очите (`EYES_LOCAL`).
