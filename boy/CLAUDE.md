# CLAUDE.md — boy

„Двубой в Рейвънхолд" — кинематографичен средновековен двубой в реално време в браузъра (WebGL 2,
three.js r186). Всичко се генерира от код: доспехи, текстури, анимация, огън, дъжд, звук. Нула
изображения, видео или 3D модели. Демо, **не** продукт с деплой.

## Команди (гейтът)

```bash
cd boy
npm ci
npm run gate     # check.mjs (синтаксис · правила · договор на страницата) → node --test → билд
npm run smoke    # билд + headless Chromium: нула грешки на страницата, кадри в dist/smoke/
npm run build    # dist/ravenhold.html — един самостоятелен HTML; three.js идва от CDN с фиксирана версия
```

`npm run gate` е гейтът в CI. `smoke` иска Chromium на Playwright и не е в CI; рендерира
софтуерно, затова числата за fps там нищо не казват — меродавен е бутонът **Stats** в браузъра.

## Структура

| Файл | Отговорност |
|------|-------------|
| `src/main.js` | часовник, камера, кадров цикъл, връзка с интерфейса |
| `src/world.js` | сглобява сцената; `animateWorld()` движи всичко в „story time" |
| `src/choreo.js` | двубоят като каскадьорски сценарий: ключове, събития, надписи, забавяния |
| `src/timeline.js` | решава контактите геометрично и интерполира позите (Catmull-Rom) |
| `src/rig.js` · `feet.js` · `fighter.js` | скелет, двукостно IK, стъпки, реакции на пружини |
| `src/armor.js` · `helmets.js` · `weapons.js` · `batcher.js` | процедурни доспехи → `BatchedMesh` по материал |
| `src/post*.js` | AO, bokeh DOF, bloom, финален проход (изостряне, ACES, грейдинг) |
| `src/quality.js` | нива на качество и регулатор на резолюцията за 60 fps |
| `test/` | `node:test`, вкл. симулация на целия двубой без GPU (`fight.test.js`) |

## Закони на пакета

1. **Файл ≤ 300 реда, нула `console.*` и `TODO` в `src/`.** Гейтнато от `check.mjs`.
2. **Версията на three.js в import map-а = `devDependencies.three`.** Тестовете вървят срещу същата
   версия, която зарежда страницата. Гейтнато.
3. **Бюджет за 60 fps.** Нов твърд обект минава през `RigidBatcher`, не като отделен `Mesh`. Нови
   частици са инстанции. Шум в шейдър се чете от `tNoise`, не се смята като fBm на всеки пиксел.
   Скъпите ефекти вървят на половин резолюция. Всяка светлина струва на всеки пиксел от всеки
   материал: добавяй само с причина.
4. **Хореографията е в координати `[дясно, горе, напред]` спрямо бойца.** Ключовете `aim`, `parry`
   и `block` се решават геометрично — не пиши ръчно поза на блок. След промяна пусни `npm test`:
   `fight.test.js` хваща откачени ръце (IK разминаване над 3 см), крака в земята и пропуснати удари.
5. **Достъпност:** без стробоскоп (мълнията е два импулса), `prefers-reduced-motion` маха трясъка и
   „ръчната" камера, интерфейсът е изцяло с клавиатура (Space · C · M · S).
6. **Кредит** „Created and Designed by Carbon Stealth VCC" и **ключови думи ≥5** с „Carbon Stealth" —
   гейтнато в `template.html` и `package.json`.
