# Двубой в Рейвънхолд

Кинематографичен средновековен двубой в реално време в браузъра: двама рицари в пълни доспехи се
бият в мокър замъчен двор през нощта — с дъжд, огън, искри, отражения в локвите и звук. Всичко е
генерирано от код (three.js r186, WebGL 2), без 3D модели, изображения или видео.

## Пускане

```bash
cd boy
npm ci
npm run build          # → dist/ravenhold.html
```

Отвори `dist/ravenhold.html` през локален сървър (например `npx serve dist`), не директно от диска.

## Управление

`Space` пауза · `C` свободна камера · `M` звук · `S` статистика (fps, резолюция, draw calls).
Качество: Auto държи 60 fps, като мени вътрешната резолюция; Low · High · Ultra са фиксирани.

## Какво има вътре

- процедурни доспехи с канелюри, ризница, наметала със симулация на плат;
- двукостно IK, процедурни стъпки, геометрично решени сблъсъци на остриетата;
- височинна мъгла, дъжд с кръгове в локвите, огледални отражения, огън с жарава и дим;
- 13 кадъра с реални обективи, bokeh DOF, bullet-time, AO, bloom, ACES, филмово зърно;
- интерфейс на EN · BG · IT.
