# staffe/ — гестионале за склад (WMS) за асансьорни скоби

**Staffe** е складова система за малка фирма, която произвежда и продава
**скоби и крепежни аксесоари за асансьори**: наличности в реално време по
ubicazione, баркод/QR, поръчки за покупка и продажба, приемане, пикинг/пакинг,
инвентаризация, отчети.

**Езикът на продукта е ИТАЛИАНСКИ.** Целият потребителски текст, имената на
маршрутите (`/prodotti`, `/giacenze`, `/acquisti`), етикетите на enum-ите и
съобщенията за грешка са на италиански. Кодовите идентификатори (полета в
Prisma, типове, помощни функции) са на английски — коментарите в кода са на
италиански, защото стоят до италианския домейн. **Комитите остават на
български** (правило на репото).

_Stack: Next.js 15 (App Router) · React 19 · TypeScript strict · Prisma ·
PostgreSQL · Tailwind · JWT (jose) · PWA. Root правилата са в кореновия
`CLAUDE.md`._

## Команди (изпълнявай в `staffe/`)

```bash
npm install
npm run dev                  # http://localhost:3000

# Пълният гейт (задължителен, преди „готово“):
npm run lint
npm run typecheck
npm test                     # node:test през tsx — чисти функции, без БД
npm run build                # prisma generate + next build

npm run prisma:migrate:dev   # миграции (иска жив PostgreSQL)
npm run db:seed              # демо каталог + ubicazioni + потребители
```

Env → `.env.example`. **`AUTH_SECRET` е задължителен и ≥32 знака** — `auth.ts`
хвърля, ако липсва (fail closed: резервна стойност би направила токените
подправяеми).

## Непреодолими инварианти

Тези правила държат данните верни. Нарушаването им е дефект, не стилов избор.

1. **Пари = `Int` в евроцентове** (`...Cents`). Проценти = `Int` в базисни
   точки (`...Bp`, 2200 = 22%). Никакъв `float` по пътя на парите. Смятането е
   само в `src/lib/money.ts` (чисти, тествани функции).
2. **Наличността се променя САМО през `src/lib/stock.ts`.** Никой модул не
   пише `StockItem.qty` директно. Всяка промяна оставя ред в `StockMovement` —
   иначе инвентарната разлика е необяснима.
3. **Отрицателна наличност не съществува.** `decrease()` хвърля `StockError`
   (→ HTTP 409), не позволява минус.
4. **Документ = една транзакция.** Приемане/пикинг/инвентар пишат движения +
   редове + статус в `prisma.$transaction`. Номерът на документа се взима с
   `nextDocumentNumber(tx, …)` **вътре** в същата транзакция (атомичен
   `increment` → няма два еднакви номера).
5. **Правата се проверяват на сървъра**, през `requirePermission('...')` от
   `src/lib/auth.ts`. Скриването на бутон в UI не е защита.
6. **Не се трие — деактивира се** (`active = false`). Историята на поръчките и
   движенията трябва да остане четима.
7. **Всяка API рутина е обвита в `route()`** от `src/lib/api.ts`. Форматът е
   `{ data, meta? }` / `{ error: { message, code } }`; съобщението е на
   италиански и се показва на оператора както е. Вътрешни детайли (stack, SQL)
   не излизат от сървъра.

## Архитектура

```
prisma/schema.prisma   Домейнът. Наличността НЕ е поле на Product — тя е сумата
                       на StockItem.qty. StockItem има материализиран `stockKey`
                       ("prod:ubic:lotto"), защото в PostgreSQL два NULL не са
                       равни и съставният unique с nullable lotto не би пазил.
src/lib/stock.ts       Двигателят на наличностите: applyMovement / moveStock /
                       reserve / release / suggestPickLocations / checkLowStock.
src/lib/money.ts       Пари и проценти. Чисти функции, покрити с тестове.
src/lib/auth.ts        JWT (jose) в httpOnly бисквитка + ред `Session` за
                       РЕВОКАЦИЯ. JWT без revoke = фалшив logout.
src/lib/auth-shared.ts Константи, които ползва и middleware (edge runtime —
                       там Prisma/bcrypt не вървят, затова са отделно).
src/lib/rbac.ts        Матрицата на правата. Единствено място за „кой какво може“.
src/lib/api.ts         REST договорът: ok/created/fail/route/readBody/pagination.
src/lib/audit.ts       Одитна следа; чувствителните полета падат преди запис.
src/lib/sequence.ts    Номерация на документи по година (OA/OV/RIC/PRL/SPD/INV).
src/lib/labels.ts      Италианските етикети на ВСИЧКИ enum-и + дати/тонове.
src/components/ui/     Примитиви (еквивалент на shadcn/ui, ръчно на Tailwind,
                       нула runtime зависимости — върху нативни елементи).
src/middleware.ts      Първи филтър: проверява само ПОДПИСА на токена.
                       Окончателната дума е `getSessionUser()` на сървъра.
src/app/(app)/…        Защитените страници (layout-ът пази достъпа).
src/app/api/…          REST крайните точки.
```

### Роли (`Role`)

`AMMINISTRATORE` (всичко) · `MAGAZZINO` (приемане, пикинг, пакинг, сканиране,
инвентар) · `VENDITE` (оферти, поръчки, клиенти, наличности, отчети).
Магазинерът **не вижда себестойност/марж** (`costi:leggi`); търговецът **не
коригира наличности** (`giacenze:rettifica`).

## Стил

- Strict TS, `@/*` alias, Zod на всеки вход отвън. Без необоснован `any`.
- Тема през CSS променливи (`globals.css`) → едни и същи класове работят в
  светло и тъмно. Тъмното е `class`, не `media` (операторът си го избира).
- Достъпност е изискване (EAA/EN 301 549): видим фокус, цел ≥44px за
  „ръкавичния“ размер `lg`, цветът никога не е единственият носител на
  състояние (`StockIndicator` дава и текст за екранен четец).
- Скенерът е клавиатура: полето за търсене приема сканиране без нищо друго.
