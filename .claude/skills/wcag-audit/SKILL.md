# Одит на достъпност (WCAG 2.1/2.2 AA · EAA)

**EAA (European Accessibility Act) = закон** за много от продуктите ни; стандартът е **EN 301 549 = WCAG
2.1 AA**. `gdpr-launch` изисква AA — тук е процедурата зад него. Автоматиката хваща ~30-40%; останалото е ръчно.

## Автоматизиран слой (в CI)
- **axe-core през Playwright** — на критичните страници/потоци: `@axe-core/playwright`, `expect(await new
  AxeBuilder({ page }).analyze()).toHaveNoViolations()` (или assert `.violations.length === 0`). Собственик
  на e2e = **Изпитателят**; вкарване в CI required check = **Конвейерът**.
- **`eslint-plugin-jsx-a11y`** в Next апс — лови статичните грешки при писане.

## Ръчен слой (задължителен — axe не го хваща)
1. **Клавиатура** — целият поток само с Tab/Shift-Tab/Enter/Esc/стрелки; видим фокус навсякъде; логичен ред;
   нула клопки за фокус; „skip to content".
2. **Екранен четец** — заглавия в йерархия (h1→h2…), `alt` по смисъл (декоративно = `alt=""`), етикети на
   всяко поле (`<label for>`), съобщения за грешка свързани (`aria-describedby`), live региони за динамика.
3. **Контраст** — текст ≥ 4.5:1 (голям ≥ 3:1); не разчитай само на цвят за смисъл.
4. **Форми** — етикет + грешка + инструкция за всяко поле; фокус върху първата грешка; не автоматично сабмитване.
5. **Движение** — reduced-motion + нула строб (виж skill **motion-a11y**).
6. **Zoom/reflow** — 200% зум без загуба; 320px ширина без хоризонтален скрол.

## Специфики за нас
- **medqr спешен изглед** — ясен език, крупни цели, звук+хаптик+визуал заедно (глухи/нямащи говор); 112/спешните
   инструкции достъпни; локализацията им → **Преводач** (без machine-translate на safety-critical).
- Правната рамка (EAA/декларация за достъпност) → агентът **Правният Разбирач**.

## Договор за „готово"
axe чист в CI на критичните страници · клавиатурен поток пълен · четец чете смислено · контраст AA ·
форми с етикети+грешки · reduced-motion · 200% зум ок. Автоматиката е под, не таван — ръчният слой е задължителен.
