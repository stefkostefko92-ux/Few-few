# Достъпност на движение (визуални ефекти)

## Универсално (винаги, всеки сайт)
- **Никога >3 проблясъка/сек** (WCAG 2.3.1 — епилепсия). Континуален бавен noise е ок; резки светлинни
   промени — не.
- **`prefers-reduced-motion: reduce`** → НЕ инициализирай тежката анимация/WebGL изобщо; покажи статичен
   fallback (poster/градиент). Гейт **преди** init, не след. Проверявай и през `matchMedia`, и през CSS.
- **Progressive enhancement** — съдържанието/CTA работят на нула JS; canvas/ефектът е слой отгоре,
   `aria-hidden`, `pointer-events:none`.

## Контекст (важно)
- **Сериозни сайтове** (граждански/медицински/корпоративни — zabobovdol, medqr, Minyor, scuola): пълна
   reduced-motion дисциплина, ефектът е сдържан, спектакълът е слуга на доверието.
- **medqr спешен изглед `/e/<token>`** = **забранена зона** за декоративна анимация.
- **Творчески/бранд сайтове**: повече спектакъл по подразбиране — но горните универсални правила пак важат.

## Производителност (не регресирай)
- Hero текст/CTA = чист HTML/CSS → LCP незасегнат; WebGL init е lazy (IntersectionObserver), извън критичния path.
- FPS watchdog: падне ли под праг (mobile/слаба GPU) → `loseContext()` + fallback. Слушай `webglcontextlost`.
- Нула layout shift (CLS): canvas `position:absolute` с фиксиран контейнер.

## Проверка
```bash
node tools/design/motion-a11y.mjs <папка>     # хваща строб/липсващ reduced-motion/липсващ fallback
```
+ визуален оглед и FPS/LCP в браузър (не се доказват със софтуер тук). a11y/правна рамка → **Правният Разбирач**;
CWV → **SEO**. Готово = `motion-a11y` чист · reduced-motion → чиста статика · работи без JS · нула строб · LCP/INP без регресия.
