# Предпусков GDPR / съответствие (ЕС)

Собственик = агентът **Правният Разбирач** (само чете + докладва; поправя при изрична молба). Води с
**правен риск**, не с козметика. Всеки извод: **„не е правен съвет".**

## Чеклист
1. **Съгласие ПРЕДИ проследяване** — никакъв analytics/pixel/nonessential cookie преди активен избор.
   Consent-mode за reCAPTCHA/вградени. Runtime cookie одит иска **headless браузър** — не обявявай находка
   за потвърдена без него.
2. **Разкрития чл. 13/14** — политика за поверителност: контролер, цели, основания, срокове, права,
   получатели/трансфери. Не измисляй членове/глоби.
3. **Импресум** (Дир. 2000/31 чл. 5 + GDPR чл. 13) — име (Carbon Stealth VCC), ЕИК, адрес, имейл, в тялото
   на Terms/Privacy.
4. **Бисквитки/ePrivacy** — банер с реален отказ (не само „ОК"), категории, без pre-checked.
5. **Достъпност (EAA/EN 301 549 = WCAG 2.1 AA)** — клавиатура, контраст, alt, форми с етикети, фокус,
   reduced-motion (виж skill motion-a11y), спешните низове ясни (medqr).
6. **Специална категория (чл. 9)** — мед. данни (medqr): криптиране в покой, минимизация, одит; никога PII
   в логове/traces/аналитика.
7. **Технически артефакти** — `robots.txt`, `sitemap.xml`, `llms.txt`, JSON-LD, canonical/hreflang коректни.
8. **Трансфери извън ЕС** — има ли US SaaS/под-обработчик? SCC/Schrems II. Данните ни са EU-hosted; дръж ги така.
9. **Задържане/минимизация (конкретно)** — дефинирай срок за всеки вид данни (напр. логове с IP: пълен
   IP ≤ дни, после **скъсен/анонимизиран**; псевдонимизация с **HMAC**, не суров идентификатор). `X-Forwarded-For`
   се доверявай само на своя reverse proxy (последния hop), не на целия ринг. Одит-логът: кой/кога/какво,
   без съдържанието на чувствителните полета.

## Инструменти / екип
- Одит на живо (WebFetch за политики/страници) → **Правният Разбирач**.
- Съгласие vs откриваемост → координирай със **SEO**.
- a11y на визуални ефекти → **Дизайнера** + skill **motion-a11y**.
- Локализация на правни низове → **Преводач** (без machine-translate на safety-critical).

## Дефиниция на „готово"
Нула проследяване преди съгласие · чл. 13/14 + импресум налични · банер с реален отказ · a11y AA ·
нула PII в логове · трансфери документирани. Съмнение → човек/юрист, не гадаене. „Не е правен съвет".
