# Оценка на агентите (regression + модел сравнение)

Харнесът е в `tools/agents/evals/`. Философия: **грейдвай изхода И пътя** — двете отговарят на
различни въпроси. (Дотук тук пишеше „не пътя"; това остаря и противоречи на приетия
`trajectory-audit.mjs`: верен изход по ГРЕШЕН път — напр. плащания одобрени **без** правен преглед —
е дефект, който изход-грейдването физически не вижда. Изходът казва „добър ли е резултатът",
траекторията казва „по законния ред ли се стигна до него".)

## Слой 1 — детерминистичен (гейтваем, без агент)
```bash
node tools/agents/evals/eval.mjs --list        # spec-овете
node tools/agents/evals/eval.mjs --check        # структурна валидност (CI гейт)
node --test tools/agents/evals/eval.test.mjs    # тестове на скорера
```

## Слой 2 — поведенчески (реален изход на агента)
1. Виж входа: `node tools/agents/evals/eval.mjs --task <specId>`
2. Пусни агента върху входа (Agent tool, `subagent_type: <specId>`, при нужда `model:` override).
3. Запиши финалния му отговор в `out.txt`, после скорирай:
   ```bash
   node tools/agents/evals/eval.mjs <specId> out.txt      # маркери: any/all/none
   ```
   Изход код 1 = провал (напр. последвана инжекция при `injection-*` spec).

## Сравнение на два модела (opus↔sonnet), рецепта
За честно сравнение: пусни агента на двата модела върху golden входа; за фина преценка —
**сляпо двойково** съдийство (анонимизирай кой е кой, рандомизирай позицията, съдия по
заземяване/коректност/процедура). Cross-family съдия е за предпочитане (не Claude съди Claude);
ако няма non-Claude ключ, двойково между два Claude изхода е приемливо (family-предпочитанието не
фаворизира никоя страна) — отбележи ограничението. Резултатът е **тренд**, не хард гейт (LLM недетерминизъм).

## Нов golden случай
Нов `tools/agents/evals/specs/<id>.json`: `{ id, agent, task, expect: [{any|all|none:[...], label}] }`.
Най-ценните идват от реален пропуск. Маркер = низ (case-insensitive) или `"/regex/flags"`.
`injection-*` spec-ове проверяват, че агентът третира враждебно съдържание като данни (`none` за
последвана инжекция/изтекли тайни). Пълно ръководство: `tools/agents/evals/README.md`.
