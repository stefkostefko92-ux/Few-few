# Stripe предпазители (плащания/billing)

Собственик = агентът **Продавача**. Тук са твърдите инварианти при паричен код.

## Непреодолими инварианти
1. **Права само през ПРОВЕРЕН webhook** — не давай достъп/entitlement на успешен redirect. Провери подписа
   (`stripe.webhooks.constructEvent` с webhook secret); redirect-ът е само UX.
2. **Сумите се смятат на СЪРВЪРА** от каталога/цените в Stripe — никога от клиентски payload (amount/price).
3. **Идемпотентност** — `Idempotency-Key` на create заявки; webhook handler-ите устойчиви на повторно
   доставяне (Stripe праща един и същ event пак) — не начислявай/давай двойно.
4. **SCA/3DS** — ползвай PaymentIntents/Checkout/Payment Element (носят 3DS), не сурови charges.
5. **PCI обхват** — Checkout/Element (hosted полета) = SAQ A; не докосвай сурови картови данни.
6. **Тайни** — `sk_...`/webhook secret само на сървъра (env, mode 600), никога в клиента/репото/логове.

## Право на ЕС (координирай с Правния Разбирач)
- **14-дневен отказ** + изключението за дигитално съдържание (изрично съгласие + загуба на правото).
- **ДДС OSS/IOSS** за трансгранични продажби; **Omnibus** (референтна цена при намаления); ЗЗП обозначаване.
- Billing: proration, dunning/Smart Retries, Customer Portal, Stripe Tax, фактури.

## Проверка
```bash
node tools/commerce/stripe-lint.mjs <path>   # webhook verify, идемпотентност, без float пари
```
Тествай webhook с Stripe CLI (`stripe listen`/`trigger`); e2e на checkout → агентът **Изпитателят**;
сигурностно ревю → **Кодаджията**. Пари = **цели центове, без float**.

## Дефиниция на „готово"
Права само през проверен webhook · сървърна остойностка · идемпотентно · SCA · тайни на сървъра · право
на отказ/ДДС/Omnibus покрити. Реални пари → човек. „Не е правен съвет".
