# Локализация BG → EN → IT (паритет + безопасност)

**Българският е източникът на истината.** Поправи **източника първо**, после синхронизирай надолу — кръпка
само на огледалото (EN/IT) се разсинхронизира и следващ sync я трие.

## Процес
1. Намери къде живеят преводите (zabobovdol: `src/lib` превключвател; medqr: `src/i18n.js`, разширяван за IT).
   Никога твърдо кодиран низ в шаблон.
2. Добави/обнови ключа на **трите** езика наведнъж; **паритет** — нито един език без стойност. Пази
   плейсхолдъри/интерполация идентични.
3. **Типография/регистър по език:** BG кавички „ … "; EN "…", Title Case където е прието; IT caporali « »,
   формален **Lei**, малки букви за дни/месеци, дата ДД/ММ/ГГГГ, десетична запетая, € след сумата.
4. **Safety-critical (medqr):** клиничните термини (алергии, състояния, медикаменти, кръвна група) — от
   контролираните преводи/глосара, **не** машинно сляпо. Несигурен термин → маркирай за човек, не гадай.
5. Без реални вътрешни данни в примери — неутрални плейсхолдъри (`example.com`, `YOUR_API_KEY`).

## Проверка преди „готово"
```bash
node tools/i18n/check-parity.mjs bg.json en.json it.json    # липсващи/непреведени ключове
node tools/i18n/glossary-check.mjs <en|it> <locale.json>    # налага одобрените клинични термини
# по избор: node tools/i18n/pseudo.mjs en.json  → хваща отрязан текст/твърдо кодирани низове (IT ~+20%)
```
Глосар: `.claude/agents/_shared/glossary.md`. Готово = пълен паритет bg/en/it · нула изпуснати/добавени
числа/единици · клиничните термини проверени или маркирани за човек. Хвани трите режима на халюцинация:
добавено, **изпуснато (най-опасно — обръща смисъл)**, пренаписан смисъл.
