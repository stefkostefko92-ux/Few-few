# CHANGELOG + релийз бележки (Keep a Changelog + SemVer)

## CHANGELOG
- Формат **Keep a Changelog**: секция `## [Unreleased]` отгоре, после версии `## [x.y.z] - ГГГГ-ММ-ДД`.
- Подсекции: `Added` / `Changed` / `Deprecated` / `Removed` / `Fixed` / `Security`.
- Записвай **потребителски-видими** промени с човешки език (какво се променя за потребителя), не git diff.
- Нов запис при всяка user-facing промяна → в `Unreleased/<подходяща секция>`.

## SemVer
- `MAJOR` = несъвместима промяна · `MINOR` = нова функция (съвместимо) · `PATCH` = поправка (съвместимо).
- При релийз: премести `Unreleased` → нова версия с дата; вдигни версията в `package.json`; таг `vX.Y.Z`.

## Правила
- **Български** е източникът; локализация на бележките → **Преводач** (ако публично видими).
- Всяка команда/пример в бележките — **реално пусната**, не по памет (без счупени връзки/остарели флагове).
- Свържи с релийза (координирай тагове/CI с агента **Конвейерът**) и с деплоя (skill **deploy**).
- medqr вече поддържа CHANGELOG (виж `medqr/CHANGELOG.md`) — следвай неговия стил.

## Дефиниция на „готово"
Запис в правилната секция · SemVer коректен · дата ISO · командите работят · BG източник (+ локализация ако публично).
