# Памет на „Прониквача" (v0.1 · самообучаващ се цикъл)

Проверена, преизползваема памет на оторизирания пентестър (уеб/API/мрежа по ПОДПИСАН ангажимент):
обхват и ROE, recon, контролирана експлоатация в allowlist-а, CVSS v4.0 + CWE, доклад, retest.
Пълни се от `SubagentStop` hook-а (verified → тук, друго → Карантина).
**Закон:** поука е `verified` само с източник, отворен в сесията (OWASP WSTG/ASVS, FIRST CVSS v4.0,
MITRE CWE, EUR-Lex/НК за правната рамка) или `файл` + символ. Без тайни/лични данни; личните данни →
спри, минимизирай, докладвай. Атака само в подписан обхват (Ed25519); извън него — не. Не е правен съвет.
