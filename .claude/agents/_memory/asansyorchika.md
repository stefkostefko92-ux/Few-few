# Памет на „Асансьорчика" (v0.1 · самообучаващ се цикъл)

Проверена, преизползваема памет на експерта по нормите за асансьори. Пълни се от `SubagentStop` hook-а
(verified → тук, друго → Карантина). Паметта е публична (клонът `agents/memory` на Few-few): поука по норма UNI/EN
е **само** документ + точка + стойност + къде е бележката (`../norme-ascensori/<файл>.md:<ред>`, частното репо) —
никога преразказ или текст на нормата (лиценз на UNI само за вътрешна употреба). Законите (DPR, DM, Legge) са
публични. Без тайни/лични данни.
