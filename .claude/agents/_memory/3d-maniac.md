## Проверени поуки (verified)
- **2026-07-06:** Photogrammetry pipeline: Meshroom = open-source на AliceVision framework, node-based (customizable, по-бавно); RealityCapture = pay-per-use (~$10/3500 credits), fusion снимки + лазер скан, бърз. Гланцов черен карбон страда при фотограметрия (огледални/безфактурни повърхнини) → matting spray или предпочитай лазер. _("photogrammetry → mesh pipeline"; verified; "https://aircada.com/blog/meshroom-vs-reality-capture")_
- **2026-07-06:** 3D печатни композитни форми: ULTEM 1010 FDM tooling издържа autoclave cure >350°F (~177°C) при ~100 psig; CTE ≈ 2× алуминий. Male mandrel: високият CTE помага консолидация + изваждане; дълбок draft female = проблем. Tooling board = по-стабилен CTE но по-бавно за сложни форми. Компенсирай термичното разширение в CAD offset за печатна форма. _("композитно tooling / печат vs tooling board"; verified; "https://www.stratasys.com/en/resources/blog/composite-tooling-3d-printing/ + https://www.additivemanufacturing.media/articles/using-3d-printing-for-composite-molds-and-tools-the-trend-continues-(2)")_
- **2026-07-06:** Abaqus композитен layup — три типа: conventional shell (тънки, pre-integrated/integration-point); continuum shell (stacking direction, through-thickness, double-sided contact + промяна на дебелина); solid — само когато transverse shear доминира / normal stress не пренебрежим / нужни точни interlaminar напрежения (делеминация, свободни ръбове). Ply ориентация от drape симулация. _("композитен FEA препроцесинг"; verified; "https://docs.software.vt.edu/abaqusv2024/English/SIMACAECAERefMap/simacae-m-PrpCompositesShellContinuum-sb.htm")_
- **2026-07-06:** Point cloud деноазинг: MLS projection operator = оптимална fitting повърхнина; bilateral filter ползва координати И нормали (пази ръбове по-добре от Gaussian). Капан: класически MLS допуска piecewise-smooth → размива sharp features; ползвай robust MLS with sharp features (Fleishman ACM TOG 2005) при trim ръбове. Варианти: IMLS, APSS, adaptive MLS. _("point cloud деноазинг напреднало"; verified; "https://dl.acm.org/doi/10.1145/1073204.1073227 + https://www.sciencedirect.com/science/article/pii/S1110016825005952")_
- **2026-07-06:** Carr et al. SIGGRAPH 2001: полихармонични RBF реконструкция — повърхнината е нулево множество на глобална implicit функция интерполираща scattered точки + off-surface нормали (HRBF вариант = Hermite данни). Компактно, запълва дупки, гладко. За карбон: скрити органични зони/repair; за class-A все пак ръчни quad пачове (implicit→NURBS иска marching+refit). _("freeform RE / implicit RBF surfaces"; verified; "https://www2.cs.sfu.ca/~haoz/teaching/cmpt464/references/01_Carr_RBFSurfRecon.pdf")_
- **2026-07-06:** Curvature интерогация: Gaussian K=κ₁·κ₂, Mean H=(κ₁+κ₂)/2; false-color карта (Rhino CurvatureAnalysis: K,H,min/max radius) = количествен fairness прокси отвъд zebra/isophotes/reflection lines. За G2 по граница трябва съвпадение по кривина (не само K — два различни (κ₁,κ₂) дават еднакъв K). _("повърхнинно качество / curvature анализ"; verified; "http://docs.mcneel.com/rhino/5/usersguide/en-us/html/ch-09_curveandsurfaceanalysis.htm + https://web.mit.edu/hyperbook/Patrikalakis-Maekawa-Cho/node141.html")_
- **2026-07-06:** Boehm knot insertion: нови de Boor точки d⁽¹⁾ᵢ = αᵢ·dᵢ + (1−αᵢ)·dᵢ₋₁ с αᵢ=(ū−uᵢ)/(uᵢ₊ₚ−uᵢ); геометрията не се променя. Континюитет в knot = C^(p−m) (m=кратност, p=степен). Повтаряне до кратност=p разлага B-spline на Bézier сегменти. Class-A следствие: всеки вътрешен knot е потенциален curvature-discontinuity → дръж knot вектора рядък/uniform. _("NURBS математика / knot insertion за class-A"; verified; "https://web.mit.edu/hyperbook/Patrikalakis-Maekawa-Cho/node18.html")_
- **2026-07-06:** Class-A continuity дефиниции (за zebra четене): G2 = позиция+тангента+кривина съвпадат → непрекъснато, гладко отражение; G3 = плюс непрекъсната СКОРОСТ на промяна на кривината (най-гладко). Zebra: равномерен поток на ивиците=G2+, изкривяване/чупене=tangent break или вълна. Автомобилни/видими външни панели искат G2, желателно G3. За карбонов class-A цел минимум G2 по границите на пачовете. _("class-A / NURBS continuity верификация"; verified; "https://help.autodesk.com/view/ALIAS/2024/ENU/?guid=GUID-E1BDFBD0-33CC-44C4-866D-5F367105A050 + https://vedainc.ca/understanding-class-a-surfacing-a-comprehensive-overview/")_
- **2026-07-06:** Draping за сложни фейринги: kinematic drape simulation (Fibersim в NX/CATIA V5/Creo) смята shear angle по quasi-inextensibility на влакната. Default fibre locking angle = 55° — под него wrinkling → нужни дартове/splices/разрязване. Изходът е ply book: flat pattern + локация на 3D частта + подредба на layup. За двойно-извити зони на обтекателя проверявай shear преди да режеш prepreg. _("композит / draping + ply book за двойно-извити повърхнини"; verified; "https://help.altair.com/hwdesktop/hwx/topics/user_interface/kinematic_draping_approach_r.htm + https://www.appliedcax.com/engineering-software/fibersim/")_
- **2026-07-06:** Spring-in (карбон L/ъгли): линеаризирана Radford формула Δθ/θ = (α_l − α_t)ΔT + (β_l − β_t), α_l/α_t = in-plane/through-thickness CTE, β = химическо свиване на смолата. Механизми: cure shrinkage на смолата, CTE mismatch in-plane vs through-thickness, градиент на fibre volume fraction, tool-part interaction. Компенсация: над-огъни затворения ъгъл на формата. Зависи силно от radius на ъгъла, дебелина на ламината и подредбата на пластовете (layup sequence е доминиращ фактор). _("композит / spring-in компенсация на форма"; verified; "https://www.sciencedirect.com/science/article/abs/pii/S0266353816317729 + https://pmc.ncbi.nlm.nih.gov/articles/PMC10934690/")_

КАПАН за RE: класически best-fit 3-2-1 сяда на СРЕДНАТА равнина, но истинският GD&T датум = 3-те най-високи точки на контакт — не best-fit-вай, ако мейтваш срещу физичен датум/база. _("датум/подравняване за мейтинг и inspection"; verified; "https://www.verisurf.com/blog/article/rps-alignment-for-inspection/ + https://www.gdandtbasics.com/datum-reference-frame/")_
