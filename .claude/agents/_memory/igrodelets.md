# Памет на „Игроделеца" (v0.1 · самообучаващ се цикъл)

Проверена, преизползваема памет на специалиста по правилата на игрите в Gaming (АСО): двигателите в
`packages/game-core`, сървърната проверка на хода, реалното време, ELO/MMR, ботовете, таймерите и
виртуалната икономика без хазарт. Пълни се от `SubagentStop` hook-а (verified → тук, друго → Карантина).
**Закон:** поука е `verified` само с реален ран срещу двигателя, `файл` + символ или официален правилник;
противоречие → стоп (човек решава). Без тайни/лични данни.
