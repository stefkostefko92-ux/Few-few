## Проверени поуки (verified)
- **2026-07-12:** Google Ads API: класическите VIDEO кампании са READ-ONLY (нито create, нито update — само отчети). YouTube реклама през API върви през DEMAND_GEN (in-stream/in-feed/Shorts; DemandGenVideoResponsiveAdInfo; non-shared бюджет) или PMax. Видео активът е YoutubeVideoAsset (youtube_video_id); от v23.1 има YouTubeVideoUploadService за качване през API. _(google/video-readonly; verified; https://developers.google.com/google-ads/api/docs/video/overview)_
- **2026-07-12:** Google Ads API v24 актуална (22.04.2026); major живее ~1 г. (v21 sunset авг. 2026). Официален Node SDK няма; REST е поддържан път. Бюджетът е ОТДЕЛЕН ресурс (CampaignBudget, amount_micros); официална препоръка: създавай кампании PAUSED; atomic Mutate с временни негативни ID. Ново задължително поле contains_eu_political_advertising. _(google/api-basics; verified; https://developers.google.com/google-ads/api/docs/campaigns/create-campaigns + /docs/sunset-dates)_
- **2026-07-12:** Meta Marketing API: Graph v25.0 актуална (18.02.2026); npm SDK facebook-nodejs-business-sdk изостава (24.0.1, 7+ мес. без publish) → директни Graph заявки. Campaign create: ODAX objectives само (OUTCOME_*), special_ad_categories задължително (7 стойности вкл. NONE и ONLINE_GAMBLING_AND_GAMING), status NE е PAUSED по подразбиране — подавай изрично. Бюджети в minor units, НО account spend_cap в стандартна деноминация. _(meta/api-basics; verified; https://developers.facebook.com/docs/marketing-api/reference/ad-campaign-group + /docs/graph-api/changelog)_
- **2026-07-12:** Meta placements: publisher_platforms приема threads (threads_positions: [threads_stream]) — изисква instagram в списъка + IG stream позиция. Threads ads глобални от 26.01.2026. CTWA: adset destination_type=WHATSAPP + Page със свързан WhatsApp номер; creative CTA type=WHATSAPP_MESSAGE + value.app_destination=WHATSAPP, link=https://api.whatsapp.com/send. WhatsApp Status ads: Marketing API поддръжка непотвърдена (2026-07). _(meta/placements; verified; https://developers.facebook.com/docs/marketing-api/audiences/reference/placement-targeting + /docs/marketing-api/ad-creative/messaging-ads/click-to-whatsapp/)_
- **2026-07-12:** Meta EU/DSA: dsa_payor + dsa_beneficiary задължителни на adset за реклами таргетиращи ЕС (от 16.08.2023; липса → request fail). Advantage+ audience: targeting_automation{advantage_audience:0|1} задължително ИЗРИЧНО при adset create от v23. Тийн таргетиране: само възраст+локация (DSA чл. 28). instagram_actor_id мъртво от 09.09.2025 → instagram_user_id в object_story_spec. _(meta/eu-dsa-fields; verified; https://developers.facebook.com/blog/post/2023/05/16/new-marketing-mpa-api-requirements-for-facebook-and-instagram-ads-targeting-eu/ + /blog/post/2025/06/13/marketing-api-changes-to-advantage-plus-audience-behaviors/)_
- **2026-07-12:** Meta learning phase: ~50 optimization events/седмица на adset (~7 дни); мин. дневен бюджет за conversions = (target CPA × 50)/7. Значими edits (бюджет >20%, opt. event, targeting, ad-set creative) рестартират learning → консолидация 2-3 broad adsets по креативен ъгъл. Скалиране +20% на 2-3 дни. Микробюджет €5-20/ден: студени конверсии недостижими → само retargeting на органично изградени аудитории (3-5× по-евтино). _(paid/learning-budget; verified; https://www.pigeondigital.com/insight/facebook-ads-learning-phase-50-conversions-rule-2026 + adadvisor.ai малки бюджети 2026)_
- **2026-07-12:** ePrivacy/GDPR: server-side CAPI НЕ заобикаля съгласието — чл. 5(3) ePrivacy покрива обработката на данни от терминала; блокиран пиксел → CAPI мълчи за същия потребител; единен consent gate за client+server (OLG Dresden 02.2026: обезщетения за Pixel/CAPI без основание). Google Consent Mode v2 задължителен от 03.2024 за EEA (ad_storage, analytics_storage, ad_user_data, ad_personalization); Google Ads API: обект Consent{ad_user_data, ad_personalization} във всеки conversion/Customer Match upload. Хеширане (SHA-256 на имейли) = псевдонимизация, НЕ анонимизация. _(legal/consent; verified; https://support.google.com/google-ads/answer/14310715 + flexyconsent.com CAPI consent guide)_
- **2026-07-12:** Meta rate limits (BUC, header X-Business-Use-Case-Usage): ads_management standard = 300 + 40×активни реклами (rolling 1h); ads_insights = 600 + 400×активни. Кодове 4 (app), 17 (user), 613 (custom), 80004/80000 (BUC) → спри и чакай estimated_time_to_regain_access. CAPI дедуп: event_name + event_id, 48ч прозорец, пази се първото. _(meta/rate-limits; verified; https://developers.facebook.com/docs/graph-api/overview/rate-limiting + /docs/marketing-api/conversions-api/deduplicate-pixel-and-server-events)_
- **2026-07-12:** Auto-rules прагове (работещи евристики от проучването): pause при CPA>1.5-3× target (мин. €100 spend / 20+ конверсии, извън learning); scale +20% при ROAS>target 3+ дни; fatigue при frequency>3.5 или CTR −20% от baseline; спирачка при разход днес >1.5× бюджета (платформите харчат легално до 2× дневния). Без CAPI+dedup Meta губи 20-30% конверсии (iOS 14.5+) → ROAS правила върху Meta-only числа убиват печеливши кампании. _(paid/auto-rules; verified; reklamchik/RESEARCH.md §3 + anytrack.io/get-ryze 2026; вградени в reklamchik/src/rules.js RECOMMENDED_RULES)_
