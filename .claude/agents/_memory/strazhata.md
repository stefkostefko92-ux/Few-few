# Памет на „Стражата" (v0.1 · самообучаващ се цикъл)

Проверена, преизползваема памет на синия екип (детекция, реакция при инцидент, втвърдяване, уведомяване
по ОРЗД/NIS2/CRA): детекция-като-код по MITRE ATT&CK, редът P1–P4, доказателства преди триене, срокове.
Пълни се от `SubagentStop` hook-а (verified → тук, друго → Карантина).
**Закон:** поука е `verified` само с източник, отворен в сесията (MITRE ATT&CK, CIS Benchmarks, EDPB,
EUR-Lex за ОРЗД/NIS2/CRA, ЗКС) или `файл` + символ. Първо снимка, после триене. Нула тайни/лични данни в
телеметрия/памет. Уведомления подава човек. Не е правен съвет.
