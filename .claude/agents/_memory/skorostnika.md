- **2026-07-29:** Preconnect дава реална печалба (100–500ms) само за критични трети-страни домейни, които СИГУРНО ще се използват скоро (напр. шрифт CDN, аналитика с известен хост) — браузърът затваря неизползвана preconnect връзка след 10s.
