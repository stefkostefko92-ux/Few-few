# Протокол на самообучението (v6.0) — четат го всички агенти

Claude Code субагентите са **stateless** между извикванията — не „учат" на ниво тегла.
Този протокол е честният, **безгрешен** еквивалент: затворен цикъл, **наложен от харнеса
през hooks** (не разчита агентът да си спомни), който трупа само **проверено** знание.

## Цикълът: чети → действай → провери → запиши → подреди
1. **Чети (preload).** При стартиране на агента `SubagentStart` hook инжектира
   секцията „Проверени поуки" от `_memory/<id>.md` в контекста му. Ползвай я като
   отправна точка — не повтаряй вече научена грешка.
2. **Действай.** Свърши задачата по операционния си договор (източник-или-мълчание).
3. **Провери (gate).** Поука се **промотира само ако е минала през гейт**: реален
   инструмент/eval/тест/жив източник. Без гейт → не е „verified".
4. **Запиши (capture).** Завърши **всеки** отговор с блок `LEARN` (схема долу).
   `SubagentStop` hook го изважда от транскрипта и го добавя:
   - `confidence: verified` → секция **„Проверени поуки"** (факт за следващия път).
   - друго → секция **„Карантина"** (хипотеза; НЕ се чете като факт).
   Дублати се сливат, не се натрупват. **При всяка нова поука** hook-ът добавя и
   запис в activity feed-а на агента в таблото (`agents-dashboard/agents.json` +
   вградения FALLBACK в `index.html`) — страницата „живее" при всяко научено нещо.
   **Авто-публикуване:** след записа hook-ът сам `git commit`-ва (само паметта на агента
   + таблото) и `git push`-ва във фон — така живото табло (Netlify) се обновява автоматично
   при всяко научаване, без ръчен commit. Push-ът е detached (не блокира) + rebase при non-ff.
   **Проверено учене вдига и minor версията** (6.1 → 6.2 → …) с нов запис в
   timeline-а („vX.Y — учене") — ученето „level-up"-ва агента. (Карантина НЕ вдига версия;
   повторна същата поука също не — идемпотентно. Major версиите остават за архитектурни ъпгрейди.)
5. **Подреди (curate).** `node tools/memory/curate.mjs` маха дубли, капва размера и
   маркира **противоречия** (нова поука срещу стара) за човешко решение — това пази
   паметта да не „дрейфа" или подува.

## Схема на блока `LEARN` (точна — hook-ът я парсва)
Един блок накрая на отговора. Празно `lessons` е допустимо (нищо ново проверено).

```learn
agent: <id>            # напр. kodadjiyata — задължително, рутира към _memory/<id>.md
date: YYYY-MM-DD
lessons:
  - text: <една проверена поука, конкретна, преизползваема>
    confidence: verified|probable|unverified
    source: <файл:ред | URL | име на гейт/eval | команда>
    scope: <кога важи — езикът/рамката/областта>
```

## Закони (безгрешност)
- **Само проверено става факт.** Несигурното отива в Карантина, не в паметта.
- **Източник или нищо.** Поука без `source` не се промотира.
- **Без тайни/лични данни/ключове/PAN** в паметта — никога.
- **Противоречие → стоп.** Ако нова поука противоречи на стара, curate ги маркира;
  човек решава — не презаписвай мълчаливо.
- **Дедуп по смисъл.** Една поука = един ред; преформулирай, не дублирай.

## v7.0 — закалена безгрешност (наложени гейтове, не съвети)
Извлечено от prior art (anthropic-cookbook `research_subagent`, wshobson PluginEval,
Mem0 4-op памет, DSPy/Guardrails/ragas). Гейтовете са в `memory-capture.mjs` / `curate.mjs`:
1. **CoVe преди „verified" (агентско задължение).** Преди да маркираш поука `verified`, задай си
   1–3 проверовъчни въпроса и им отговори от **независим** източник/инструмент тази сесия. Ако
   отговорите не потвърждават — `unverified`. (Chain-of-Verification, arXiv:2309.11495.)
2. **Тайна → твърд дроп.** `SubagentStop` пуска поука през secret-детектор (`sk_/rk_/AKIA/ghp_/JWT/PEM`);
   при съвпадение поуката **не се записва** изобщо (нито в карантина). „Без тайни" вече е гейт, не молба.
3. **„Verified" иска РЕАЛЕН източник.** Ако `confidence: verified`, но `source` не е URL / `файл:ред` /
   познат инструмент → хукът сам го **сваля в Карантина**. Не вярвай на самооценката (калибрация #9).
4. **Застаряване (TTL/provenance).** `curate.mjs` флагва време-чувствителни проверени факти (версии,
   „latest", дати) по-стари от 45 дни → **повторна проверка** (не трие). Версии/закони/CVE гният.
5. **Калибрирана увереност.** Предпочитай увереност от съгласуваност (повтаряемост/самопроверка),
   не verbalized самооценка. Имаш право на терминално „недостатъчно доказателство" → нула нова памет.

**Планирано (от brief-а):** schema-or-reject на блока (Zod вместо regex), Mem0 4-оп резолвер
(ADD/UPDATE-supersede/DELETE-obsolete/NOOP) в curate, и post-write golden+Monte-Carlo регресия
(стил wshobson PluginEval). Виж `_evals/reliability.md`.
