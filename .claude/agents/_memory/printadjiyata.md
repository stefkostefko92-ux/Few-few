## Проверени поуки (verified)

- **2026-06-26:** Annealing на найлон при 80-100C за 6-16h дава пълна кристализация → макс якост/коравина/топлоустойчивост/размерна стабилност; планирай размерна промяна защото кристализацията свива частта _(nylon annealing якост; verified; https://wiki.polymaker.com/polymaker-products/polymaker-filaments/prime-materials/nylon-pa)_
- **2026-06-26:** Филамент сушене (Prusa таблица): PLA 45C/6h, PETG 55C/6h, TPU 60C/4-6h, ASA 80C/4h, PC Blend 85C/5h, PA11-CF 90C/6h — PLA трябва доста под ~60-65C glass transition или се слепва; ползвай външен термометър _(филамент сушене температури; verified; https://help.prusa3d.com/article/drying-filament_332086)_
- **2026-06-26:** No-cooling-for-first-X-layers вдига bed adhesion и реже ранен warp; OrcaSlicer рампва fan линейно от този слой до макс; overhang/bridge cooling е отделно (overhang threshold = % неподдържана линия, 0% форсира fan на всички външни стени) _(cooling първи слоеве overhang; verified; https://www.orcaslicer.com/wiki/material_settings/cooling/material_cooling)_
- **2026-06-26:** Fuzzy skin thickness трябва под/около outer-wall line width (около 70-125% от дюзата); Displacement mode тресе toolhead-а (отслабва черупката), Extrusion mode варира само flow (пази стена/скорост); винаги влошава размерната точност → само декоративно/grip _(fuzzy skin режими; verified; https://www.orcaslicer.com/wiki/print_settings/others/others_settings_fuzzy_skin)_
- **2026-06-26:** Support interface контролира финиш vs премахване: support_top/bottom_z_distance е пролуката до частта (по-голяма = по-лесно махане, по-груба долна повърхност), support_interface_spacing=0 значи плътен interface (най-добра повърхност, най-трудно белене) _(support interface Z-distance; verified; https://www.orcaslicer.com/wiki/print_settings/support/support_settings_support)_
- **2026-06-26:** Tree support компромис: по-висока branch density дава по-добри надвеси но по-трудно се маха — wiki препоръчва top support interface вместо висока branch density; по-нисък branch angle = по-вертикални/стабилни клони _(tree supports interface; verified; https://www.orcaslicer.com/wiki/print_settings/support/support_settings_tree)_
- **2026-06-26:** Ironing претрасира топ повърхностите втори път на същия Z с много нисък flow; spacing трябва под/равно на диаметъра на дюзата за пълно покритие; режими Top Surfaces / Topmost / All Solid; риск: много бавен flow → heat creep/запушване _(ironing топ покритие; verified; https://www.orcaslicer.com/wiki/print_settings/quality/quality_settings_ironing)_
- **2026-06-26:** Scarf joint seam рампва екструзията постепенно по хоризонтална дължина (default около 20mm) вместо твърд старт/стоп, и OrcaSlicer го прилага само на гладки извити периметри (острите ъгли пазят стандартен шев за точност) — за скриване на Z-шев на извити повърхнини _(scarf joint seam; verified; https://www.orcaslicer.com/wiki/print_settings/quality/quality_settings_seam)_
- **2026-06-26:** Adaptive Pressure Advance: единичен PA е компромис защото оптималният PA пада при по-висока скорост/ускорение/височина на слой; adaptive PA строи PA-vs-(flow,accel) модел и подава най-добрия PA на feature — поправя и пролуки на бавни външни, и издуване на бързи вътрешни _(adaptive pressure advance; verified; https://www.orcaslicer.com/wiki/calibration/adaptive_pressure_advance_calib)_
- **2026-06-26:** Максималната volumetric speed (mm3/s) е истинският таван, не mm/s: същата mm/s с по-голяма дюза/по-дебел слой иска повече flow отколкото hotend-ът топи; калибрирай с tower и дръж 10-20% запас _(volumetric flow лимит; verified; https://www.orcaslicer.com/wiki/calibration/volumetric_speed_calib)_
- **2026-06-26:** Retraction tower (OrcaSlicer): direct drive 0-2mm стъпка 0.1; Bowden 1-6mm стъпка 0.2 — Bowden иска по-дълги pull-ове защото дългият PTFE път буферира налягане; K2 Plus е direct-drive → ползвай 0-2mm диапазона _(retraction direct vs bowden; verified; https://www.orcaslicer.com/wiki/calibration/retraction_calib)_
- **2026-06-26:** OrcaSlicer brim типове: Auto (капва на 20mm), Outer, Inner, Outer and Inner, Painted, Mouse Ears (локални уши срещу warp с по-малко материал); Brim width = разстояние модел-най-външна линия (повече = по-добра адхезия), Brim-Object Gap = хлабина към обекта (повече = лесно махане но по-слаба адхезия) _(brim first layer adhesion; verified; https://www.orcaslicer.com/wiki/print_settings/others/others_settings_brim)_
- **2026-06-26:** OrcaSlicer bridging: bridge flow ratio управлява дебелината — под 1.0 намалява материала и коригира спейсинга → по-малко увисване (външни мостове), над 1.0 добавя материал → по-силен контакт (вътрешни); по-ниска плътност дава по-добро охлаждане; thick bridges подобрява надеждността за дълги участъци _(bridging настройки; verified; https://www.orcaslicer.com/wiki/print_settings/quality/quality_settings_bridging)_
- **2026-06-26:** OrcaSlicer seam позиции: Aligned (скрит вътрешен фасет), Nearest (бързо), Back (Min Y отзад), Random (разпределя шевовете → повече якост), Aligned Back; Staggered inner seams разминава вътрешните шевове по Z → по-силно и watertight; Scarf joint маха видим z-шев по криви _(OrcaSlicer seam; verified; https://www.orcaslicer.com/wiki/print_settings/quality/quality_settings_seam)_
- **2026-06-26:** OrcaSlicer elephant foot compensation: негативно отстояние върху първите N слоя, намаляващо линейно (1-ви слой 100%, после 80%, 60%...); слоевете над N не се пипат; preview може да покаже накъсан brim но крайните размери са верни _(elephant foot компенсация; verified; https://www.orcaslicer.com/wiki/print_settings/quality/quality_settings_precision)_
- **2026-06-26:** OrcaSlicer infill: Grid и Triangles се завъртат всеки слой за изотропна якост; Grid е non-crossing multiline, Gyroid са затворени бримки без застъпване; не всички sparse шарки поддържат завъртане и реалният разход варира; повече плътност → повече якост/материал/време _(infill типове свойства; verified; https://www.orcaslicer.com/wiki/print_settings/strength/strength_settings_infill)_
- **2026-06-26:** OrcaSlicer top/bottom shells: поне 3 shell слоя за повечето печати; shell thickness е предпазител — броят solid слоеве се вдига при слайс ако дебелината от слоевете е по-тънка; повече shell → по-голяма якост, качество, watertightness _(top/bottom за здравина; verified; https://www.orcaslicer.com/wiki/print_settings/strength/strength_settings_top_bottom_shells)_
- **2026-06-26:** OrcaSlicer line width: отправна точка = 100% от диаметъра на дюзата, работен диапазон 100-150% (под 100% лоша адхезия, над 150% преекструзия); външна стена 105-120%, вътрешна ≥120% (здравина), top 100-105%, infill ~115%, bridge ~100% _(line width vs nozzle; verified; https://www.orcaslicer.com/wiki/print_settings/quality/quality_settings_line_width)_
