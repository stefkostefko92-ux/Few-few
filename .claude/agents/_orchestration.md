# Оркестрация на екипа (v3.0)

Седемнадесетте агента не са солови — подават си работа по дефинирани потоци. Викай ги по име;
няколко могат да текат паралелно. Роли: **lead** (води потока), **contributor** (върши част),
**reviewer** (проверява преди следващата стъпка).

## Чести потоци
- **Пускане в продукция (zabobovdol):**
  Правен Разбирач (consent-scan + a11y гейт) → Кодаджията (`scan.sh all` + ревю) →
  SEO (CWV/JSON-LD) → **VPS-аджията** (blue/green деплой). VPS е lead на самия деплой.
- **Ново съдържание:** Сийдъра (seed + check-dups/integrity) → Преводач (bg/en/it + parity/glossary) →
  SEO (hreflang/мета). 
- **Кампания/видео:** Социалджията (clip/repurpose → C2PA → draft) — човек одобрява публикуване.
- **Платена реклама (Google/Meta):** Социалджията (креативи/hooks, органиката пълни аудиториите) +
  Дизайнера (визуални активи) → **Рекламчика** (структура, learning-математика, auto-rules,
  публикация ПАУЗИРАНА през SupremeAdManager/ + `ads-lint.mjs`) → Правния Разбирач (consent/DSA/AI Act
  одит) → Кодаджията (ревю на промени по SupremeAdManager/) → VPS-аджията (деплой/секрети).
  Рекламчика е lead на кампанията; **кампания активира само човекът** (бюджетът е свещен);
  e-commerce конверсии (Stripe) → с Продавача.
- **FiveM ресурс:** Геймъра (lint/busted/fuzz) — самостоятелно; общ код-ревю при нужда → Кодаджията.
- **Карбон част:** 3D Maniac (scan→CAD→deviation) — самостоятелно; изход към реалния свят.
- **3D печат (K2 Plus):** Принтаджията (DfAM + `printability.mjs` + слайс) — самостоятелно; ако моделът
  идва от скан/повърхностно RE → първо **3D Maniac**, после Принтаджията за печат; визуализация/клип → **Социалджията**.
- **Визуален WOW ефект:** Дизайнера (ефект + `motion-a11y.mjs` + fallback) → Правния Разбирач/Кодаджията
  (reduced-motion + EAA/WCAG одит) → SEO (CWV/LCP ефект) → Преводач (текст) → Социалджията (промо клип на ефекта).
  Дизайнера е lead на ефекта; **спешният изглед на medqr е забранена зона за декоративна анимация**.
- **Плащане/checkout/billing:** Продавача (stripe-lint + проверени идемпотентни webhook-и) →
  Кодаджията (сигурностно ревю) → Правния Разбирач (14-дневен отказ, ДДС, Omnibus, импресум) →
  Преводач (BG/EN/IT текстове) → VPS-аджията (secret-и + Stripe webhook endpoint). Продавача е lead на интеграцията.
- **Мобилно приложение/магазин:** Мобилджията (store-readiness + нативни функции) → Кодаджията
  (backend за push/deep-link/API ревю) → Правния Разбирач (privacy/EAA/бисквитки в webview) →
  SEO (web частта: manifest, service worker, Lighthouse за TWA) → Преводач (UI BG/EN/IT) →
  VPS-аджията (`.well-known/assetlinks.json` + AASA хостинг, TLS). Мобилджията е lead на пакетирането.
- **Трейдинг бот (treydar):** Трейдъра (`trader-lint` + `backtest-check` + `npm test` + walk-forward
  бектест) → Кодаджията (общо ревю за бъгове/сигурност) → VPS-аджията (ключове/секрети, systemd,
  IP allowlist) → при Discord известия/панел → Дискорджията. Трейдъра е lead; **реални поръчки пуска
  само човекът** (тройната спирачка), финансово-регулаторното (чужди пари, MiFID II) → човек/юрист.

## Принцип
Всеки преход е през **гейт** (зелен инструмент/ревю), не през „изглежда добре".
Безопасно-критичното (медицина, право, структурни части) не минава нататък без човешка проверка.
