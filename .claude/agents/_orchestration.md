# Оркестрация на екипа (v4.0)

Двадесет и петте агента не са солови — **навързват се** по дефинирани потоци. Викай ги по име;
няколко могат да текат паралелно. Роли: **lead** (води потока и е отговорен за изхода),
**contributor** (върши част), **reviewer** (гейтва преди следващата стъпка).

## Как се навързваме (типизиран handoff)
Всеки агент следва **общата процедура** (`_memory/PROCEDURE.md`, инжектира се при старт): единен
5-фазов цикъл (Ориентирай → Провери на живо → Действай → Самопровери → **Предай**) + глобални red
lines. Предаването между агенти е **един и същ блок** всеки път:

```
## ПРЕДАВАНЕ
От: <агент> → Към: <агент/човек>
Статус: наред | има бележки | блокер
Находки: <всяка с файл:ред + увереност>
Изход/артефакт: <какво произведох>
Следваща стъпка: <какво прави следващият и защо>
```

Така следващата стъпка винаги получава ЕДНА структура (находки с `файл:ред`, не свободен текст).
Всеки поток има **правило за ескалация**: излезе ли задачата от домейна ти → Статус=блокер, Към=
правилния специалист. **Оркестрацията (кой кога) е на AI-джията (президента).**

## Формат на потока
Всеки поток по-долу дава: **lead** · **pipeline** (реда на стъпките) · **ескалация** (кога спираш/
предаваш встрани). Гейт между стъпките = зелен инструмент/ревю, не „изглежда добре".

## Чести потоци

- **Пускане в продукция (zabobovdol).** Lead: **VPS-аджията** (за самия деплой).
  Pipeline: Правният Разбирач (consent-scan + a11y гейт) → Кодаджията (`scan.sh all` + ревю) →
  SEO (CWV/JSON-LD) → Изпитателят (e2e на критичните потоци) → VPS-аджията (blue/green деплой) →
  Наблюдателят (SLO/аларми след пускане). Ескалация: правен/медицински блокер → спри, човек решава.

- **Contact-form / транзакционен имейл (SMTP).** Lead: **VPS-аджията** (инфра) + **Кодаджията** (код).
  Pipeline: VPS-аджията (Gmail App Password/2FA, тайна mode 600, порт 587/465, DNS SPF/DKIM/DMARC,
  CLI тест) → Кодаджията (handler: fallback верига, header-injection guard, honeypot/rate-limit, anti-spoof) →
  Правният Разбирач (GDPR: consent-gate на reCAPTCHA, чл.13 разкритие, IP retention, чл.28 DPA —
  личен Gmail няма DPA). Ескалация: реални лични данни/трансфер → Правният; тайна в репо → блокер.

- **CI/CD пайплайн.** Lead: **Конвейерът** (конвейера в GitHub).
  Pipeline: Конвейерът (workflow/path-филтри/гейтове/supply-chain/SHA-пинове) → Кодаджията (кои гейтове
  са required) → VPS-аджията (деплой стъпката на машината). Ескалация: секрет в CI → блокер; сървърна
  промяна извън GitHub → VPS-аджията.

- **Наблюдаемост/инцидент (прод).** Lead: **Наблюдателят**.
  Pipeline: Наблюдателят (SLI/SLO/error budget, аларми по симптом, диагноза през traces/логове) →
  при поправка → Кодаджията (бъг) или VPS-аджията (инфра) → Летописецът (blameless postmortem/runbook).
  Ескалация: разграничи здраве на СИСТЕМАТА (твое) от поведение на потребителя (Анализаторът).

- **Продуктова аналитика.** Lead: **Анализаторът**.
  Pipeline: Анализаторът (tracking plan/фунии/retention/A-B) → Правният Разбирач (съгласие/минимизация/
  нула PII) → SEO (откриваемост vs поведение) → Продавача (при приход-метрики). Ескалация: съгласие/
  трансфер → Правният; корелация ≠ причинност → искай A/B преди причинно твърдение.

- **Плащане/checkout/billing.** Lead: **Продавача**.
  Pipeline: Продавача (stripe-lint + идемпотентни проверени webhook-и) → Кодаджията (сигурностно ревю) →
  Правният Разбирач (14-дневен отказ, ДДС/OSS, Omnibus, импресум) → Изпитателят (e2e на checkout) →
  Преводач (BG/EN/IT) → VPS-аджията (secret-и + webhook endpoint). Ескалация: реални пари → човек;
  сумата от клиента = недоверена (права само през проверен webhook).

- **Мобилно приложение/магазин.** Lead: **Мобилджията** (пакетиране).
  Pipeline: Мобилджията (store-readiness + нативни функции) → Кодаджията (backend push/deep-link/API) →
  Тайният агент (App Store/Play ревю: App Privacy labels, Data Safety, target API) → Правният Разбирач
  (privacy/EAA/бисквитки в webview) → SEO (manifest/SW/Lighthouse за TWA) → Преводач (UI) →
  VPS-аджията (`.well-known/assetlinks.json` + AASA, TLS). Ескалация: стор-отказ/бан риск → Тайният агент.

- **Платформено одобрение (Apple/Google/Meta).** Lead: **Тайният агент**.
  Pipeline: Тайният агент (чете политиките + подготвя изрядността) → Мобилджията (билда) / Хромаджията
  (MV3 разширение) → Правният Разбирач (privacy декларации). Ескалация: cloaking/заобикаляне на ревю =
  перманентен бан → забранено; при отказ → разчети причината и поправи, не крий.

- **Каса/фискал (CSPos).** Lead: **Касаджията**.
  Pipeline: Касаджията (Н-18/СУПТО/евро/ФУ/ПОС) → Кодаджията (сигурностно ревю на паричния код — int
  евроценти, без float) → Правният Разбирач (нормативна изрядност) → Изпитателят (e2e на касовия поток) →
  VPS-аджията/пакетиране (Electron .exe). Ескалация: продажба без успешен фискален бон НЕ се записва;
  правната материя завършва с „не е правен съвет".

- **Ново съдържание (zabobovdol).** Lead: **Сийдъра**.
  Pipeline: Сийдъра (seed + check-dups/integrity) → Преводач (bg/en/it + parity/glossary) →
  SEO (hreflang/мета/llms.txt). Ескалация: факт без източник → спри (закон източник-или-нищо).

- **Документация.** Lead: **Летописецът**.
  Pipeline: Летописецът (README/ADR/CHANGELOG/runbook/llms.txt, docs-as-code) → Преводач (локализация) →
  SEO (откриваемост). Ескалация: правни документи → Правният; всяка команда/пример реално се пуска.

- **Тестове.** Lead: **Изпитателят** (пише и притежава тестовете).
  Pipeline: Изпитателят (unit/компонентни/e2e, детерминизъм) → Качествения (качество на тестовете:
  мутация, поддръжаемост) → Кодаджията (бъгове, разкрити от тестовете). Ескалация: flaky тест → изолирай/
  поправи, не крий с infinite retry.

- **Визуален WOW ефект.** Lead: **Дизайнера** (за ефекта).
  Pipeline: Дизайнера (ефект + `motion-a11y.mjs` + fallback) → Правният Разбирач/Кодаджията (reduced-motion
  + EAA/WCAG) → SEO (CWV/LCP) → Преводач (текст) → Социалджията (промо клип). Ескалация: **спешният изглед
  на medqr е забранена зона за декоративна анимация**; никога >3 проблясъка/сек (епилепсия).

- **Кампания/видео.** Lead: **Социалджията**. Clip/repurpose → C2PA → draft — **човек одобрява публикуване**.
- **FiveM ресурс.** Lead: **Геймъра** (lint/busted/fuzz) — самостоятелно; общ код-ревю при нужда → Кодаджията.
- **Карбон част (RE).** Lead: **3D Maniac** (scan→CAD→deviation) — самостоятелно; изход към реалния свят.
- **3D печат (K2 Plus).** Lead: **Принтаджията** (DfAM + `printability.mjs` + слайс). Ескалация: моделът идва
  от скан/повърхностно RE → първо **3D Maniac**, после Принтаджията; визуализация/клип → Социалджията.
- **Chrome разширение.** Lead: **Хромаджията** (MV3 + Web Store ревю). Ескалация: стор-съответствие → Тайният агент.
- **Discord бот.** Lead: **Дискорджията** (interactions/gateway/webhooks). Ескалация: backend/секрети → Кодаджията/VPS.
- **Трейдинг бот (treydar).** Lead: **Трейдъра** (`trader-lint` + `backtest-check` + walk-forward) →
  Кодаджията (ревю) → VPS-аджията (ключове/systemd/IP allowlist) → при Discord → Дискорджията. Ескалация:
  **реални поръчки пуска само човекът** (тройната спирачка); MiFID II/чужди пари → човек/юрист.

- **AI/LLM интеграция.** Lead: **AI-джията** (той е и президентът). Провери живите докове → ключ само на
  сървъра → бюджетен таван + идемпотентност → разкрий трансфера (Правният). Ескалация: вход с лични данни
  към доставчик → Правният; стор-етикети → Тайният/Мобилджията.

## Президентът (AI-джията) оркестрира
Избира правилния поток и специалист по канона на Anthropic (workflow vs agent, routing, parallelization,
orchestrator-workers); мащабира усилието (прост факт = 1 агент; сложно = няколко паралелно); следи екипа
с `tools/agents/oversee.mjs` (fail-closed) и синхронизира таблото. Дава на всеки делегат **явна цел,
формат (HANDOFF) и граници**. Хард таван **10** генерични агента (CLAUDE.md) — нашите custom агенти са освободени.

## Принцип
Всеки преход е през **гейт** (зелен инструмент/ревю), не през „изглежда добре". Безопасно-критичното
(медицина, право, пари, фискал, структурни части) не минава нататък без човешка проверка.
