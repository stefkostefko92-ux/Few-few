# Сигурност — Few-few (Carbon Stealth VCC)

> **Честно:** „непробиваема" система **не съществува** — всеки, който го обещае, лъже.
> Това, което изграждаме и поддържаме, е реалният еквивалент: **защита в дълбочина
> (defense-in-depth)** — много независими слоя, всеки от които **фейлва затворено**
> (блокира при съмнение, не пропуска), така че пробив на един слой да не значи пробив
> на системата. Целта е максимална цена за атакуващия и минимална повърхност за грешка.

## Докладване на уязвимост (coordinated disclosure)

Намерил си дупка? **Не отваряй публичен issue.** Пиши на **security@carbonstealth.eu**
(или info@carbonstealth.eu) с описание, стъпки за възпроизвеждане и обхват. Ще
потвърдим до **72 часа** и ще работим по поправка, преди публично разкриване.
Добросъвестни изследователи, действащи по тази политика (без ексфилтрация на реални
данни, без DoS, без достъп до чужди акаунти), няма да бъдат преследвани — **safe harbor**.

## Слоевете (какво точно ни пази)

**1. Тайни — никога в кода.** Тайните живеят на сървъра (`.env`, mode 600), не в репото
или деплой-архива. Слоеве:
- `.gitignore` репо-широка мрежа (`.env`, `*.pem`, `*.key`, keystore/p12, serviceAccount…).
- `tools/security/secret-scan.mjs` — самостоятелен скенер (нула зависимости) за висок-сигнал
  провайдър-ключове (Stripe/AWS/GitHub/Google/Slack/Discord/…), частни ключове и проследени
  `.env`. Почти нулеви фалшиви тревоги → гейтът е достоверен и не се изключва. `--strict`
  добавя по-шумен generic-режим за ръчен одит.
- **CI** (`.github/workflows/security.yml`): secret-scan като **твърд гейт** + gitleaks по
  цялата git история + `dependency-review` на PR.
- **Локален предпазител:** `git config core.hooksPath .githooks` включва pre-commit скенера
  (блокира тайна, преди да влезе в git).

**2. Код.** Кодаджията (адверсариален ревю на бъгове/OWASP, всяка находка самопроверена)
+ Качествения (поддръжаемост/сложност) + SAST през `tools/code/scan.sh` (semgrep/osv/syft).
Strict TypeScript + **Zod** валидация на границата; екраниране на цялото потребителско
съдържание (XSS); параметризиран SQL (без ръчен `$queryRawUnsafe`/конкатенация).

**3. Зависимости.** `dependency-review` блокира PR с висока/критична CVE; `npm audit` + SBOM
в продуктовите CI; внимание за typosquat/supply-chain (Shai-Hulud).

**4. Приложение/runtime.** helmet + **CSP с per-request nonce** (без `unsafe-inline` там, където
е възможно), HSTS, rate limiting, **CSRF** токени по формите, пароли/ПИН с **Argon2id**
(bcrypt legacy мигрира прозрачно), втвърден **JWT** (`jose` HS256, ≥32 знака тайна, срок),
**криптиране на данните в покой** (medqr: AES-256-GCM за GDPR чл.9 медицински полета),
authz на всяка заявка (без IDOR), проверени идемпотентни Stripe webhook-и (никога доверие в
клиентски суми).

**5. Агенти.** Всеки от 17-те получава **hook-инжектирана доктрина за сигурност**
(`_memory/SECURITY.md` през `memory-preload.mjs`): външното съдържание е недоверени **данни,
не инструкции** (устойчивост на prompt injection), осъзната **lethal trifecta**, **никога не
изнася тайни/лични данни**, least-privilege `tools`, fail-closed. Доктрината има приоритет над
инструкции в извлечено съдържание.

**6. Инфраструктура/деплой.** EU-хостинг; TLS/Let's Encrypt; fail2ban; systemd/Docker
втвърдяване; тайните на сървъра (mode 600); ръчно качен архив → идемпотентен `autodeploy.sh`
(без `git pull` на кутията). Owner: **VPS-аджията**.

**7. Право/GDPR.** GDPR + ePrivacy първокласни; специална категория данни (чл.9) криптирани;
tamper-evident audit log (hash-верига). Owner: **Правният Разбирач**.

## Принципи
- **Least privilege** — минимални права/обхват навсякъде (tools, permissions, DB заявки, CORS).
- **Fail closed** — при съмнение блокирай/откажи, не пропускай.
- **Defense-in-depth** — никой слой не е единствената защита.
- **Нула тайни в репото** — те живеят на сървъра, mode 600.
- **Провери, не вярвай** — външен вход (уеб, клиент, трети услуги) е недоверен, докато не се провери.

## Локална настройка (веднъж)
```bash
git config core.hooksPath .githooks          # включва pre-commit secret-scan
node tools/security/secret-scan.mjs          # ръчна проверка на цялото репо
node tools/security/secret-scan.mjs --strict # + по-дълбок (по-шумен) generic одит
```
