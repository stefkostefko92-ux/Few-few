# Linketto

**Всичките ти линкове, нанизани на едно място — на всеки език.**

Linketto е многоезичната „link in bio“ платформа на Carbon Stealth VCC:
публична страница `/u/<slug>`, която автоматично говори езика на всеки
посетител. Името е италианското умалително на „link“ — малкото линкче, което побира всичко.

## Защо (срещу Linktree)

| | Linktree | Linketto |
|---|---|---|
| Език на админа | само английски | 6 езика на старта, инфраструктура за N |
| Език на профила | един | версии на всички езици + авто-детекция + hreflang |
| Комисиона върху продажби | 12% Free / 9% Starter+Pro / 0% Premium | **8% Free / 4% Pro / 0% Business и Founder** + такса обработка 1,9 % + €0,30 (покрива Stripe) |
| Аналитика | базова, зад платени планове | без бисквитки, без PII |
| Хостинг/GDPR | САЩ | ЕС |
| Модерация | банове без предизвестие, публичен „BANNED“ банер | предизвестие + обжалване, никога публичен банер |
| Цена Pro | $15/мес | €4/мес (+ Founder €49 завинаги) |

Пълното проучване: [`research/link-in-bio/`](../research/link-in-bio/README.md).

## Стартиране

```bash
cp .env.example .env    # попълни DATABASE_URL (PostgreSQL) и Stripe ключовете
npm install
npm run prisma:migrate:dev
npm run dev             # http://localhost:3000
```

Качествени гейтове: `npm run lint && npm run typecheck && npm test && npm run build`.
