# Linketto

**Всичките ти линкове, нанизани на едно място — на всеки език.**

Linketto е многоезичната „link in bio“ платформа на Carbon Stealth VCC:
публична страница `/u/<slug>`, която автоматично говори езика на всеки
посетител. Името е италианското умалително на „link“ — малкото линкче, което побира всичко.

## Защо (срещу Linktree)

Само проверени факти — първоизточник и дата са в `src/lib/comparisons.ts`
(единственият източник за публичните страници `/[locale]/vs/<конкурент>`).
Linktree, проверено на 23.10.2026 (цени в USD, както ги показва страницата им):

| | Linktree | Linketto |
|---|---|---|
| Най-евтин платен план (месечно) | $9 (Starter) | €4 (Pro) |
| Собствен домейн | не (на нито един план) | от Pro |
| Премахване на бранда | от Pro ($17) | от Pro (€4) |
| История на аналитиката (безплатен план) | 28 дни | 90 дни, без бисквитки |

Нашите неща без сравнение (не твърдим нищо за другите): профилни страници с
версии на всички езици + авто-избор по посетителя + hreflang; хостинг в ЕС;
аналитика без бисквитки и без PII; модерация с предизвестие и обжалване, без
публичен „banned“ банер. **Остаряло (вече НЕ го твърдим):** „Linktree е само
на английски“ (от октомври 2026 админът им се превежда постепенно) и „12/9%
при Linktree“ (комисионите им се смениха). Комисиони изобщо не сравняваме: Linketto не продава
през собствен checkout (продуктът води към линка за плащане на създателя).

Пълното проучване: [`research/link-in-bio/`](../research/link-in-bio/README.md).

## Стартиране

```bash
cp .env.example .env    # попълни DATABASE_URL (PostgreSQL); Revolut/Brevo — по избор
npm install
npm run prisma:migrate:dev
npm run dev             # http://localhost:3000
```

Качествени гейтове: `npm run lint && npm run typecheck && npm test && npm run build`.
