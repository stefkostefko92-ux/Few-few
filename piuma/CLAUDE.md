# CLAUDE.md — Piuma

Контент-двигател за Instagram с админ панел: агент/човек пише **чернови**, човек ги **одобрява**
в панела, системата ги **публикува** през официалния Instagram Platform API. Самостоятелен
продукт в монорепото — `cd piuma/` за всичко.

## Стек

Node ≥22 · TypeScript strict (ESM, `NodeNext`) · Express 5 · EJS (сървърно рендиран панел, строг
CSP с nonce) · Prisma 6 + PostgreSQL · BullMQ + Redis · zod на всеки външен вход · pino · Argon2id ·
TOTP (RFC 6238, нула зависимости) · Anthropic SDK (`claude-opus-5`) за черновите.

## Команди (гейтът)

```bash
npm ci
npm run typecheck        # tsc над src + tests
npm run format:check     # prettier
npm test                 # unit (node:test през tsx) — без база
npm run build            # prisma generate + tsc
npm run test:integration # иска жива PostgreSQL през DATABASE_URL (панел + агент + публикуване)
npm run dev              # локален сървър (панел на /admin)
npm run worker           # BullMQ работник (публикуване · токени · сесии · Insights 04:30 · автопилот пн 06:00)
npm run owner:create     # първият собственик — от средата на сървъра, еднократно
```

„Готово" = `typecheck` + `format:check` + `test` + `build` са зелени, а при промяна по
публикуващия/автентикационния път — и `test:integration` срещу истинска база.

Езикът на панела се избира от превключвателя (`?lang=bg|en|it`), пази се в профила
(`User.locale`) и в бисквитка; за гост се чете от `Accept-Language`.

  agent/               signature (HMAC) · nonce-store (Redis, fail-closed) · auth · routes (/agent/v1)
  admin/               маршрути на панела по домейни (auth · dashboard · brands · manage (представяне/автопилот) · accounts · posts · users · keys · audit)

  services/            accounts · posts · publish · insights (синхронизация + представяне) · autopilot — инвариантите живеят тук, не в маршрутите

## Инварианти (не ги заобикаляй)

1. **Акаунтите се създават РЪЧНО от човек.** Meta забранява автоматизирано създаване (Terms of Use).
2. **Публикува се само пост в `APPROVED`/`SCHEDULED`.** Черновата не стига до Instagram отникъде.
3. **Одобрява само човек със сесия и роля ≥ REVIEWER.** За агентски ключ маршрут за одобрение не
   съществува. „Четири очи": човек не одобрява собствената си чернова.
4. **HIGH от линта блокира одобрението.** Не се прескача от маршрут.
5. **Агентските заявки са HMAC-подписани** (timestamp ±300 s + nonce в Redis + метод/път/тяло).
   Тайната не пътува; недостъпен nonce склад = отказ.
6. **Тайните са криптирани в покой** (IG токени, TOTP, агентски ключове) и никога в лог.
7. **Всяко действие е в одита** с актьор (човек/агент/система) и IP.
8. **Сесиите са в базата** (не JWT): отменими веднага, плъзгащи 7 д., абсолютен таван 30 д., `__Host-` бисквитка.
9. **Автопилотът прави само чернови и само от медийната библиотека на бранда.** Не измисля материали,
   не надхвърля `postsPerWeek`, чете Insights, но никога не пише в Instagram.
10. **Подписаният път включва query string-а** (`req.originalUrl`) — CLI-то и сървърът трябва да са в синхрон.
11. **Никакъв `style="…"` в шаблон.** CSP е `style-src 'self'` — атрибутът се блокира мълчаливо и
    оформлението просто не се прилага. Оформлението живее в класове; динамичната ширина на мярката
    е стъпка от 5% (`.meter-fill.p-NN`).
12. **Цветът никога не носи смисъл сам.** Всяко състояние е чип с икона и дума
    (`admin/presenters.ts`); палитрата е мерена за контраст, не подбирана на око.
13. **Нула текст извън речниците.** Шаблоните и съобщенията към човека минават през `t()`;
    българският е източникът, `en`/`it` са пълни огледала. Тестът пада при зашит низ в шаблон
    или в маршрут. Логовете и одитът остават на български — те са за нас, не за екрана.
