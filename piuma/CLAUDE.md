# CLAUDE.md — Piuma

Контент-двигател за Instagram с админ панел: агент/човек пише **чернови**, човек ги **одобрява**
в панела, системата ги **публикува** през официалния Instagram Platform API. Самостоятелен
продукт в монорепото — `cd piuma/` за всичко.

На `/` стои **витрината** (публичната страница, индексируема); панелът е на `/admin` и е
`noindex`. Витрината няма нито ред JavaScript и носи целия слой за откриваемост.

## Стек

Node ≥22 · TypeScript strict (ESM, `NodeNext`) · Express 5 · EJS (сървърно рендиран панел, строг
CSP с nonce) · Prisma 6 + PostgreSQL · BullMQ + Redis · zod на всеки външен вход · pino · Argon2id ·
TOTP (RFC 6238, нула зависимости) · Anthropic SDK (`claude-opus-5`) за черновите.

## Команди (гейтът)

```bash
npm ci
npm run typecheck        # tsc над src + tests
npm run format:check     # prettier
npm test                 # unit (node:test през tsx) — без база
npm run build            # prisma generate + tsc
npm run test:integration # иска жива PostgreSQL (DATABASE_URL) И Redis (REDIS_TEST_URL) — панел + агент + публикуване + опашка
npm run dev              # локален сървър (панел на /admin)
npm run worker           # BullMQ работник (публикуване · токени · сесии · Insights 04:30 · автопилот пн 06:00)
npm run owner:create     # първият собственик — от средата на сървъра, еднократно
```

Витрината носи и три генератора на асети — пускат се **ръчно**, не на всеки билд:

```bash
npm run landing:art -- <лого.png> <перо.png>          # маха черния фон → WebP с алфа
npm run landing:og                                     # изображението за споделяне 1200×630
PIUMA_URL=… PIUMA_PASSWORD=… npm run landing:shots     # снимките на панела, по език
```

`landing:art` взима подадената рисунка на марката. Неонов арт идва върху черно и сложен
така върху аврората стои като правоъгълник; скриптът развива цвета от черното
(unmultiply), вместо да реже по праг — затова ръбът остава цветен, не сив. Гейтът
проверява, че изнесеният WebP наистина носи алфа.

`landing:shots` иска **жив панел с демо данни** (никога продукция — кадрите влизат в
репото) и Chromium за Playwright. Пусни го пак, щом панелът промени вида си: витрината
показва самия продукт, тоест остарее ли снимката, страницата започва да лъже.

„Готово" = `typecheck` + `format:check` + `test` + `build` са зелени, а при промяна по
публикуващия/автентикационния път — и `test:integration` срещу истинска база.

Езикът на панела се избира от превключвателя (`?lang=bg|en|it`), пази се в профила
(`User.locale`) и в бисквитка; за гост се чете от `Accept-Language`.

  config.ts            zod над process.env — процесът не тръгва с полуготов конфиг
  landing/             витрината на `/`: страницата + robots · sitemap · llms.txt · ключът за IndexNow
  icons.ts             чете `public/icons/*.svg` веднъж → един `<symbol>` спрайт (виж ICONS.md)
  i18n.ts              речниците bg/en/it, `t()`, избор по Accept-Language
  crypto.ts            AES-256-GCM за тайни в покой, HMAC подпис на OAuth state
  audit.ts             одит с верига от хешове (подправен стар запис чупи веригата)
  auth/                rbac (7 нива) · password (Argon2id) · totp · sessions (в базата) · guards (login/CSRF/права)
  agent/               signature (HMAC) · nonce-store (Redis, fail-closed) · auth · routes (/agent/v1)
  admin/               маршрути на панела по домейни (auth · dashboard · brands · manage (представяне/автопилот) · accounts · posts · users · keys · audit)

  instagram/           client · oauth · publish (контейнер → публикуване) · insights (метрики на медия/акаунт)
  content/             lint (HIGH блокира) · plan (планът на страницата, zod) · prompt (контекст: план + Insights) · schedule (чиста логика на автопилота) · generate
  services/            accounts · posts · publish · insights (синхронизация + представяне) · autopilot — инвариантите живеят тук, не в маршрутите
  queue/               BullMQ опашка и работник
locales/               bg.json (източник) · en.json · it.json — пълни огледала, гейтвани от теста
views/                 EJS шаблони (partials/shell-*, admin/*, landing/index)
public/                tokens.css (палитра + аврора, обща) · admin.css (панелът) · landing.css (витрината)
                       · admin.js (единственият скрипт, с nonce) · icons/*.svg · favicon.svg
                       · landing/ (перото, снимките на панела, изображението за споделяне)
                       · indexnow-key.txt (публичен знак за собственост, НЕ тайна)
ICONS.md               наборът икони: правила за файла, пълен списък, как се сменя
Dockerfile             многослоен билд; `prisma` CLI-то е ПРОИЗВОДСТВЕНА зависимост (entrypoint мигрира)
docker-entrypoint.sh   чака базата → `prisma migrate deploy` → предава на командата (app и worker)
docker-compose.yml     db · redis · app · worker; app слуша само на 127.0.0.1:${HTTP_PORT:-4310}
deploy/nginx/          конфигът на nginx-а на ХОСТА (TLS) — файл в репото, не ръчно на сървъра
DEPLOY.md              еднократните стъпки, които скрипт не може да направи: тайни · TLS · собственик · агентски ключ

Разгръщането минава през `deploy/autodeploy.sh` на монорепото (`PROJECTS="piuma"`).
Липсва ли `piuma/.env`, скриптът **пропуска** продукта вместо да измисля тайни — Piuma
държи Instagram токени и агентски ключове, тоест полу-вдигнат панел е по-лош изход от
ясен отказ. Скриптът проверява отделно `/health` **и** че работникът тича: панелът може
да е съвсем жив, докато публикуването и Insights са мъртви.

## Инварианти (не ги заобикаляй)

1. **Акаунтите се създават РЪЧНО от човек.** Meta забранява автоматизирано създаване (Terms of Use).
2. **Публикува се само пост в `APPROVED`/`SCHEDULED`.** Черновата не стига до Instagram отникъде.
3. **Одобрява само човек със сесия и роля ≥ REVIEWER.** За агентски ключ маршрут за одобрение не
   съществува. „Четири очи": човек не одобрява собствената си чернова.
4. **HIGH от линта блокира одобрението.** Не се прескача от маршрут.
5. **Агентските заявки са HMAC-подписани** (timestamp ±300 s + nonce в Redis + метод/път/тяло).
   Тайната не пътува; недостъпен nonce склад = отказ.
6. **Тайните са криптирани в покой** (IG токени, TOTP, агентски ключове) и никога в лог.
7. **Всяко действие е в одита** с актьор (човек/агент/система) и IP.
8. **Сесиите са в базата** (не JWT): отменими веднага, плъзгащи 7 д., абсолютен таван 30 д., `__Host-` бисквитка.
9. **Автопилотът прави само чернови и само от медийната библиотека на бранда.** Не измисля материали,
   не надхвърля `postsPerWeek`, чете Insights, но никога не пише в Instagram.
10. **Подписаният път включва query string-а** (`req.originalUrl`) — CLI-то и сървърът трябва да са в синхрон.
11. **Никакъв `style="…"` в шаблон.** CSP е `style-src 'self'` — атрибутът се блокира мълчаливо и
    оформлението просто не се прилага. Оформлението живее в класове; динамичната ширина на мярката
    е стъпка от 5% (`.meter-fill.p-NN`).
12. **Цветът никога не носи смисъл сам.** Всяко състояние е чип с икона и дума
    (`admin/presenters.ts`); палитрата е мерена за контраст, не подбирана на око —
    `tests/contrast.test.ts` е самото мерене и чете стойностите от `admin.css`.
    Повърхностите са стъклени, а под тях аврората се движи: всяка двойка се смята и
    върху спокоен фон, и върху фон под най-силната ѝ точка, и се взима по-лошото.
    Пипнеш ли алфа на петно или тон в `:root`, пусни теста — числото е гейт, не съвет.
13. **Витрината не обещава повече от продукта.** Текстът ѝ минава през същите речници
    и през `tests/landing.test.ts`: всяко изображение носи `alt` + размери (нула CLS),
    адресите идват от `PUBLIC_BASE_URL`, ключовите думи са ≥5 с „Carbon Stealth“, а
    формулировка като „публикува автоматично“ пада гейта — тя противоречи на инвариант 2.
14. **Нула текст извън речниците.** Шаблоните и съобщенията към човека минават през `t()`;
    българският е източникът, `en`/`it` са пълни огледала. Тестът пада при зашит низ в шаблон
    или в маршрут. Логовете и одитът остават на български — те са за нас, не за екрана.
15. **Часовникът на процеса е часовникът на публиката.** Поясите, от които `learn.ts` вади
    „кога работи", и `nextSlots`, който насрочва, четат един и същ локален час. Пусне ли се
    процесът на UTC срещу българска публика, изводът и насрочването се разминават с 2–3 часа
    мълчаливо. Затова `TZ` е конфигурация на разгръщането (`Europe/Sofia` по подразбиране в
    compose), а `learnFrom` връща `timezone` — за да се вижда, вместо да се предполага.
16. **Под прага се мълчи.** Извод за час/формат/тема се дава само при ≥6 публикации в поне
    2 кофи И ≥15% преднина пред медианата на полето; иначе `best` е `null`. Мярката е
    ангажираност/обхват (обхватът расте с акаунта), медиана, не средно (един вирусен пост
    дърпа средното). `tests/learn.test.ts` е самото правило — всеки праг е мутационно проверен.

## Външни зависимости, които остаряват

`IG_GRAPH_VERSION` е конфигурация, не константа. Лимитите и разрешенията се сверяват в
документацията на Meta, не по памет.
