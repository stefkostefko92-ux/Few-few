# Незабравка

**Лични записки с напомняне за iPhone.** Записваш какво да не забравиш, избираш ден и
час — телефонът те подсеща с известие. Толкова.

- ✅ Известията са **локални** — нищо не излиза от телефона. Няма акаунт, няма сървър, няма реклами.
- 🔁 Повторения: еднократно · всеки ден · всеки делник · седмично · месечно · годишно.
- 😴 Отлагане направо от известието („След 10 минути“, „След час“) и от списъка.
- ⭐ „Важно“ — известието се доставя и при включен „Фокус“ (ако разрешиш способността).
- 🔎 Търсене, раздели „Просрочени / Днес / Утре / Предстоящи / Изпълнени“.
- 🇧🇬 Изцяло на български.

## Как да го пуснеш на своя iPhone

Нужен е **Mac с Xcode 16 или по-нов** (единственият начин да се инсталира приложение на iPhone).

1. `open nezabravka/Nezabravka.xcodeproj`
2. Избери таргета **Nezabravka** → раздел **Signing & Capabilities** → сложи своя Apple ID в
   **Team**. Xcode ще смени `PRODUCT_BUNDLE_IDENTIFIER` при нужда (трябва да е уникален).
3. Закачи iPhone с кабел, избери го горе като устройство и натисни ▶︎ (Run).
4. На телефона: **Настройки → Общи → VPN и управление на устройство** → довери се на
   профила си. Приложението стартира и пита за разрешение за известия — разреши го,
   иначе няма да има подсещане.

Дребен шрифт: подписване с **безплатен** Apple ID важи **7 дни** — след това пусни Run
пак от Xcode. С платен акаунт за разработчици (99 $/год.) важи една година.

Ако искаш „Важно“ да пробива режим „Фокус“: **Signing & Capabilities → + Capability →
Time Sensitive Notifications**. Без нея всичко останало работи нормално.

## За разработчици

Ядрото (сметки за повторения, планиране на известията, групиране) е Foundation-only и
се тества **без Mac**:

```bash
cd nezabravka
swift test                                               # 44 теста
swift format lint --strict --recursive Nezabravka Tests
```
