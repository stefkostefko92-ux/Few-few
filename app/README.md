# За Дупница

Граждански дигитален портал за град **Дупница** — важните местни услуги и
телефони, дежурна аптека и помощ на едно достъпно място. Независима инициатива,
насочена особено към възрастните хора.

Проектът стъпва на проучването в `../app/research/dupnitsa-digital-gaps.md` (какво
липсва на града дигитално) и следва архитектурата на съседния портал „За Бобов
дол" (който е само за справка и **не** се променя).

## Технологии

Next.js 15 (App Router) · React 19 · TypeScript · Prisma · PostgreSQL ·
Tailwind CSS. Node ≥ 20.

## Текущо състояние (MVP)

Готови страници: начало, **Услуги и телефони** (`/uslugi`), **Дежурна аптека**
(`/dezhurna-apteka`), **Достъпност** (`/dostapnost`), **За проекта** (`/za-nas`).

MVP страниците рендерират от типизирани, **проверени** данни в `src/data/*`
(всеки факт с източник; непотвърдените телефони са обозначени). Така сайтът се
билдва и работи без база данни. Prisma схемата (`prisma/schema.prisma`) е готова
за следващата фаза — администрация и редактиране от база данни.

## Достъпност

Заложена по подразбиране: лента за уголемяване на текста, висок контраст, тъмен
режим и „по-лесно докосване"; едър базов шрифт; навигация с клавиатура; цел
WCAG 2.1 AA.

## Локална разработка

```bash
npm install
npm run dev            # http://localhost:3000
```

Базата данни не е нужна за MVP. За Prisma/админ фазата:

```bash
cp .env.example .env   # попълнете DATABASE_URL
npx prisma db push     # създава схемата
npm run db:seed        # зарежда услугите и аптеките от src/data
```

## Качество (същите гейтове като CI)

```bash
npm run lint        # ESLint (next/core-web-vitals + typescript)
npm run typecheck   # tsc --noEmit
npm test            # модулни тестове (node:test, без външни зависимости)
npm run build       # продукционен билд
```

## Структура

```
src/
  app/         публични страници + robots/sitemap/manifest
  components/  UI компоненти (хедър, футър, лента за достъпност, икони)
  data/        проверени данни за MVP (услуги, аптеки) с източници
  lib/         логика без UI (site конфигурация, SEO, slug, prisma)
prisma/        схема и seed (следваща фаза)
```

Това е независим проект и не е официалният сайт на община Дупница.
