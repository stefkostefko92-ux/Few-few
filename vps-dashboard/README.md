# Carbon Stealth VPS Dashboard

Пълен контролен панел за VPS сървър с графичен интерфейс — управлявай **всичко** от
един екран. Един и същ панел върви на всеки от твоите VPS-и и ги контролира и двата
през federation.

> Продукт на **Carbon Stealth VCC** — част от монорепото. Нула runtime зависимости
> (само Node ≥20 stdlib). Български интерфейс.

## Какво може
| Секция | Действия |
|--------|----------|
| **Обзор** | CPU / памет / мрежа / диск на живо (SSE + canvas графики), история 1h/6h/24h/7d (на диска), uptime, ОС/ядро |
| **Продукти** | health на всеки продукт от монорепото (живи локални URL-и) |
| **Надеждност** | SLO и **бюджет за грешки** по продукт: колко от 30-дневния бюджет е останал, наличност, p95, „бавно" като отделен показател, и **скорост на изгаряне** (multi-window burn-rate по канона на Google SRE — аларма по скоростта на харчене, не по „има ли грешка сега") |
| **Аларми** | известия на телефона (Telegram / ntfy / webhook / имейл) по **симптом**: натиск върху ресурсите (PSI), steal, OOM убийства, изчерпани inode-и, препълнена опашка за връзки, паднала услуга, продукт DOWN, изтичащ сертификат, провален деплой — плюс **прогноза** „дискът ще се напълни след N дни" |
| **Диагностика** | натиск (PSI), процесор по режими (вкл. **steal** — краде ли ти хостерът), диск I/O (IOPS, закъснение, заетост), TCP връзки и препълване, файлови дескриптори, inode-и, мрежа по интерфейс с изпуснати пакети, прогнози и аномалии |
| **Услуги** | systemd list/филтър, start/stop/restart/reload, статус |
| **Docker** | контейнери + stats + логове, start/stop/restart, образи |
| **Compose** | цели стекове: up / down / pull / restart + логове по проект |
| **Бази** | SQLite (размер, WAL, integrity_check) + Postgres в Docker (размери, връзки); снимки с един бутон + restic |
| **Процеси** | топ по CPU/памет, kill (SIGTERM/SIGKILL) |
| **Логове** | journal tail + следене на живо, филтър по unit/приоритет, **анализ по отпечатък** — 4200 еднакви реда стават една група, а НОВИТЕ грешки (невиждани досега) излизат най-отгоре и вдигат известие |
| **Деплой** | **качване на ZIP направо от браузъра** (+ sha256), пускане на `autodeploy.sh` по избрани проекти с жив изход, **връщане назад към стар release** |
| **Ъпдейти** | apt upgradable, security-only / пълен upgrade като фонова задача |
| **Сигурност** | отворени портове, fail2ban, SSH конфиг, TLS сертификати (дни до изтичане), последни входове |
| **Firewall** | ufw: включване/изключване, добавяне и триене на правила (строга валидация) |
| **Уеб сървър** | Nginx/Caddy: преглед и **редакция на vhost-овете** с валидация преди reload (автоматичен откат), включване/изключване на сайт, `certbot renew` |
| **Бекъпи** | известни бекъп папки + releases за rollback |
| **Крон/таймери** | systemd таймери + crontab-и |
| **Файлове** | браузър, преглед и **редакция** (пази копие `.bak`) |
| **Терминал** | **истински интерактивен PTY** — htop, nano, sudo, цветове, Ctrl+C; всеки ред влиза в одита |
| **Еднократна команда** | бърз `bash -lc` с жив изход, без сесия |
| **Агенти** | флотът от `agents.json` + пускане на агентските инструменти (oversee, secret-scan, deploy-check…) |
| **Задачи** | всички фонови задачи + жив изход + спиране |
| **Одит** | append-only дневник на всяко действие |
| **Настройки** | двуфакторна автентикация (TOTP) |
| **Захранване** | reboot / poweroff |

Панелът е и **PWA** — инсталира се на телефона („добави към началния екран"), а
известията идват през Telegram/ntfy.

Всичко се превключва между възлите (локален + peer-и) от падащото меню горе вляво.

## Бърз старт (локално, dev)
```bash
cd vps-dashboard
npm run dev          # печата еднократна парола; отвори http://127.0.0.1:7700
```

## Инсталация на сървъра
```bash
# 1) Еднократно: създава конфиг (тайни + парола), systemd услуга, вдига панела.
sudo bash deploy/install.sh
#    → админ паролата се записва в /etc/vps-dashboard/initial-admin-credential.txt (mode 600)

# 2) Публикувай зад Nginx + TLS (препоръчително + Basic-auth):
sudo cp deploy/nginx.conf.example /etc/nginx/sites-available/vps-dashboard.conf
#    смени server_name → твоя домейн, после:
sudo ln -s /etc/nginx/sites-available/vps-dashboard.conf /etc/nginx/sites-enabled/
sudo certbot --nginx -d vps1.carbonstealth.eu
#    и в config.json сложи "trustProxy": true
```
Оттам нататък деплоят е автоматичен през канона на репото: `deploy/autodeploy.sh`
разгръща и `vps-dashboard` (rsync + рестарт; конфигът/state оцеляват).

## Двата VPS-а (federation)
На **всеки** сървър инсталирай панела и им дай общ `peerToken`:
```bash
# На VPS №1 в /etc/vps-dashboard/config.json:
{ "peerToken": "<общ-дълъг-таен-низ>",
  "peers": [ { "id": "vps2", "name": "VPS Две", "url": "https://vps2.carbonstealth.eu", "token": "<общ-дълъг-таен-низ>" } ] }
# На VPS №2 — огледално, peer сочи към VPS №1.
```
Сега от единия панел превключваш към другия възел и го управляваш изцяло (вкл. живи
графики и терминал) — заявките се проксират сигурно с Bearer токена.

## Известия на телефона (препоръчително)
Най-бързият път е **ntfy** — без регистрация:
1. Инсталирай приложението ntfy и се абонирай за тайна тема (напр. `csvps-<нещо-случайно>`).
2. В панела → **Аларми** → канал ntfy → въведи темата → **Запази** → **Тестово известие**.

Telegram: направи бот при `@BotFather`, вземи `bot token` и своя `chat id`, попълни ги
там същото. Праговете (диск/CPU/памет/сертификат) също се настройват оттам.

## Сигурност
Панелът управлява целия сървър → третирай го като най-чувствителния вход. Слуша само на
`127.0.0.1`, публично само зад TLS, **включи 2FA** от Настройки. Пълните защити и моделът
на заплахата → [`SECURITY.md`](./SECURITY.md).

## Разработка
`npm run lint && npm test` (нула зависимости, `node --test`). Детайли → [`CLAUDE.md`](./CLAUDE.md).
