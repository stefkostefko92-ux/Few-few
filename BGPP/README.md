# БГ Държавни предприятия (BGPP)

Портал за прозрачност на **държавните предприятия в България**: кои са, кой ги
контролира и **по какъв начин влизат и излизат парите им** — с връзки към
официалните регистри за проверка.

> Независим граждански проект на [Carbon Stealth VCC](https://carbonstealth.eu).
> Не е официален сайт на държавен орган или предприятие.

## Какво отговаря сайтът

- **Кои са** най-значимите държавни предприятия (енергетика, транспорт, отбрана,
  гори, води, здравеопазване, хазарт, IT, индустрия).
- **Кой ги контролира** — ресорният министър (принципал), АППК, регулаторите и
  Сметната палата.
- **Как влизат парите** — приходи от дейност, регулирани такси, субсидии,
  капиталови вноски, заеми, средства от ЕС.
- **Как излизат парите** — оперативни разходи, заплати, инвестиции, данъци и
  такси, **дивидент към държавния бюджет**, обслужване на дълг.

## Технологии

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS. Без база данни —
данните са типизирани TypeScript модули в `src/data/`, а сайтът е изцяло статичен.

## Стартиране

```bash
npm install
npm run dev            # http://localhost:3000
```

## Качество

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## Данни и точност

Моделът описва **структурата** на паричните потоци, която е устойчива —
конкретните годишни суми се проверяват в официалните източници (АППК, Търговски
регистър, Министерство на финансите, СИГМА, Портал за отворени данни). Виж
раздела **Методология** в сайта и `CLAUDE.md` за това как се добавя/поправя
предприятие.
