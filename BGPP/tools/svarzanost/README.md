# Проверка на свързаност — инструмент за сигнали

Помощен скрипт, който съпоставя **имената на органите на държавно предприятие**
с **действителните собственици на фирмите-изпълнители** на неговите поръчки и
маркира съвпаденията като **сигнали за проверка**.

> ⚠️ Инструментът **не доказва роднинство и не обвинява никого**. Съвпадението на
> имена е повод за проверка с първичен документ, не заключение. Не разпространявай
> резултата като твърдение за конкретни хора.

## Защо изобщо работи по имена

Българското име е **Собствено + Бащино + Фамилно**, а бащиното е производно от
собственото име на бащата (Петър → Петров/Петрова). Затова инструментът дава три
типа сигнал:

| Сигнал | Сила | Какво значи |
|---|---|---|
| **СЪЩО ЛИЦЕ** | силен | И трите имена съвпадат — може едно и също лице да е от двете страни (пряка несъвместимост). |
| **БАЩИНО→СОБСТВЕНО** | силен | Бащиното на единия = собственото на другия → възможна връзка родител–дете. |
| **ОБЩА ФАМИЛИЯ** | слаб | Само фамилията съвпада — носят я и много несвързани хора. |

## Откъде се вземат данните (ти ги събираш от официалните регистри)

1. **Изпълнители и суми** по поръчките на дружеството →
   [СИГМА](https://sigma.midt.bg/) и [ЦАИС ЕОП](https://app.eop.bg/).
2. **Действителни собственици** на фирмите-изпълнители →
   Регистър на действителните собственици (по ЗМИП) и
   [Търговски регистър](https://portal.registryagency.bg/).
3. **Органи на държавното предприятие** (директори, СД, прокуристи) →
   [Търговски регистър](https://portal.registryagency.bg/).

## Формат на входа

Два JSON файла (виж примерите `primer-druzhestvo.json` и `primer-izpalniteli.json`):

```jsonc
// лица.json — органите на държавното предприятие
{ "drujestvo": "…", "lica": [ { "ime": "Собствено Бащино Фамилно", "dlanost": "…" } ] }

// изпълнители.json — фирмите-изпълнители и техните действителни собственици
{ "izpalniteli": [
  { "firma": "…", "eik": "…", "porachki": "…",
    "sobstvenici": [ { "ime": "Собствено Бащино Фамилно", "dial": "…" } ] }
] }
```

Имената задавай по възможност **с трите имена** — иначе сигналът „бащино→собствено“
не може да се провери и остава само слабото съвпадение по фамилия.

## Пускане

```bash
node tools/svarzanost/check.mjs                       # примерните (измислени) данни
node tools/svarzanost/check.mjs лица.json изп.json     # твоите данни
```

## След сигнала — доказването

Сигналът е само начало. Роднинството/конфликтът се доказва с **първичен документ**:

- **декларация по ЗПКОНПИ** на длъжностното лице (свързани лица, конфликт на интереси);
- **акт/решение на КПК** (Комисия за противодействие на корупцията);
- **съдебен акт**;
- вписвания и история в **Търговския регистър**.

Правно основание за „свързани лица“: § 1 от ДР на Търговския закон и § 1, т. 15
от ЗПКОНПИ (съпрузи и фактическо съжителство; роднини по права линия; по съребрена
до 4-та степен; по сватовство до 2-ра; икономически свързани лица).

Ако имаш основателно съмнение — подай **сигнал до КПК**; проверката и установяването
са тяхна компетентност, не на този инструмент.
