# Агентски шлюз — Carbon Stealth

Нашите експертни AI агенти, достъпни за сайтовете ни чрез **агентски ключове** — от собствен
сървър в ЕС, с Claude през **Google Vertex AI в ЕС**.

- **Ключ = сайт.** Собственикът решава кой агент в кой сайт е активиран и от кои домейни.
- **Два вида ключове:** `cs_pk_…` за уиджета в браузъра (само от позволените домейни) и
  `cs_sk_…` за сървър-към-сървър.
- **Месечен таван** в USD и лимит заявки/мин на всеки ключ.
- **Без съхранение на разговори**, автоматично маскиране на лични данни, ясно обозначение
  „Разговаряш с AI асистент“.

## API

`POST /v1/chat` — хедър `X-Agent-Key: cs_…` (или `Authorization: Bearer cs_…`), тяло:

```json
{ "agent": "seo", "messages": [{ "role": "user", "content": "Как да подобря SEO на сайта си?" }] }
```

Отговор — `text/event-stream`: `event: delta` (`{"text":"…"}`), по избор `event: refusal`,
накрая `event: done` (`{"stop":"end_turn","truncated":false}`) или `event: error`.

| Код     | Значение                                                                   |
| ------- | -------------------------------------------------------------------------- |
| 400     | невалидна заявка (дължина, брой съобщения, непознато поле)                 |
| 401     | липсващ/невалиден/отменен ключ                                             |
| 402     | достигнат месечен таван на ключа                                           |
| 403     | агентът не е активиран за ключа · непозволен Origin · таен ключ от браузър |
| 413     | тялото е над 128 KB                                                        |
| 429     | лимит заявки/мин (виж `Retry-After`) или натоварен доставчик               |
| 502/503 | AI услугата не отговори / не е конфигурирана                               |

`GET /v1/agents` — позволените за ключа агенти. `GET /widget.js` — уиджетът. `GET /healthz`.

## Уиджет

```html
<script src="https://<шлюз>/widget.js" data-key="cs_pk_…" data-agent="seo" defer></script>
```

По избор: `data-lang="bg|en|it"`, `data-title="…"`, `data-privacy-url="https://…"`.
