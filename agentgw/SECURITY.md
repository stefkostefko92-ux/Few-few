## Модел на заплахите

| Заплаха                                                       | Защита                                                                                                                     |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Кражба на ключ от базата                                      | Пазим само HMAC-SHA256(`KEY_PEPPER`, ключ); pepper-ът е в средата (mode 600), не в базата                                  |
| Публичен ключ, копиран в чужд сайт                            | `cs_pk_` важи само при `Origin` от списъка на ключа; CORS отразява само него                                               |
| Таен ключ в браузър                                           | `cs_sk_` с `Origin` хедър → 403 (не „работи“, за да не остане там)                                                         |
| Налучкване на ключове                                         | 256 бита ентропия; лимит на неуспешни опити по IP (`AUTH_FAIL_PER_MIN`) + `limit_req` в Nginx                              |
| Изгаряне на бюджета                                           | лимит заявки/мин на ключ+IP; месечен таван в USD → 402; `max_tokens`, таван на история/вход; body limit 128 KB             |
| Prompt injection / изтичане на системния промпт (LLM01/LLM07) | защитна доктрина пред профила; профилите не съдържат нищо вътрешно (гейт `check-profiles.mjs`), затова изтичането не вреди |
| Агент с опасни действия                                       | публичните агенти са **нула инструменти** — само текст; уиджетът рисува отговора като `textContent` (без HTML)             |
| Трансфер извън ЕС                                             | Vertex само в `eu`/`europe-*`; `global` и не-ЕС региони спират стартирането                                                |
| Липсващи GCP данни                                            | fail-closed: 503, без резервен доставчик                                                                                   |

## Данни и GDPR

- **Какво пазим:** ключове (хеш, сайт, агенти, origin-и, тавани), месечни броячи на токени/разход,
  одит верига на администраторските действия. **Не пазим разговори**, IP адреси или съдържание.
- **Какво напуска сървъра:** текстът на разговора към Google Cloud Vertex AI (ЕС) — след
  автоматична редакция на имейл, телефон, ЕГН, IBAN и номер на карта. Редакцията е мрежа за
  безопасност, не гаранция; уиджетът изрично казва „не въвеждай лични данни“.
- **Обработващ:** Google Cloud (Cloud Data Processing Addendum, чл. 28 GDPR). Моделът е на
  Anthropic, но се изпълнява в инфраструктурата на Google. Сайтът, който вгражда уиджета, е
  администратор спрямо своите посетители — политиката му трябва да го разкрие (съгласувай с
  Правния Разбирач; това не е правен съвет).
- **AI Act чл. 50** (приложим от 2 авг. 2026): уиджетът постоянно показва „Разговаряш с AI асистент“.
- Уиджетът не ползва бисквитки, localStorage или трети страни; историята живее само в паметта на страницата.

## Тайни

`KEY_PEPPER`, `DATABASE_URL`, JSON на service account — само в `/etc/agentgw/` (mode 600,
собственик `agentgw`). Service account-ът има **само** `roles/aiplatform.user`. Никога в репото,
архива, логовете или чата.

## Ограничения (v1)

- Лимитите са в паметта на един процес — при няколко инстанции трябва споделено хранилище (Redis).
- Таванът се проверява преди заявката; паралелни заявки могат леко да го надхвърлят (с най-много
  една заявка на паралелна връзка).
- Цените в `src/pricing.ts` са list цените на Anthropic × `PRICE_MULTIPLIER`; истинската фактура е
  на Google — сверявай периодично.
