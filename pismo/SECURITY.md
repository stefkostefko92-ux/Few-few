# SECURITY — pismo

Пакетът е асет (шрифтове + генератор), без сървър, без лични данни, без тайни.

- **Входове:** няма външни входове; генераторът чете само собствения си код.
- **Веригата за доставка:** зависимостите са закачени в `requirements.txt` (fontTools, skia-pathops,
  brotli) и се инсталират само в билд/CI среда — в шрифтовете не влиза код.
- **Шрифтовете като атакуема повърхност:** парсерите на шрифтове са исторически уязвими, затова
  таблиците се пишат само с `fontTools` (без ръчни байтове), а гейтът отваря и проверява всеки файл.
- **Витрината** (`specimen/index.html`) е статична: без външни заявки, без бисквитки и проследяване,
  без `innerHTML` от потребителски вход.
- **GDPR:** не се обработват лични данни.

Уязвимост → координирано разкриване по коренния `SECURITY.md`.
