# За Бобов дол

Граждански дигитален портал за град **Бобов дол** — местни услуги и телефони на
едно място, обяснения „Как да…“ за е-услуги стъпка по стъпка, събития, обяви,
взаимопомощ и прозрачност на общинските разходи. Независима инициатива,
насочена особено към възрастните хора.

Продукция: **https://zabobovdol.carbonstealth.eu**

---

## Възможности

**За гражданите**
- Указател с услуги и важни телефони (с филтри по категория).
- „Как да…“ — над 500 ръководства стъпка по стъпка за е-услуги и документи.
- Пенсии и помощи, дежурна аптека, защита от измами, всичко за еврото.
- Прекъсвания на ток/вода, транспорт (такси, влак, автобус, споделено пътуване).
- Обяви, събития, новини, спомени, доброволци, галерия.
- **Прозрачност** — обществените поръчки на общината (данни от СИГМА/МИДТ).
- Сигнали до общината и за нерегламентирани сметища.

**Достъпност** (за хора с увреждания на зрението, слуха и моториката)
- Уголемяване на текста, висок контраст, тъмен режим, режим „по-лесно
  докосване“; връзка с институции без обаждане; достъп до 112 за хора с
  увреден слух.

**Откриваемост (SEO / GEO / AEO)**
- Свързан JSON-LD граф (Organization, WebSite, WebPage, FAQPage, HowTo,
  NewsArticle, Event, LocalBusiness, BreadcrumbList, Dataset) с устойчиви `@id`
  и `speakable` за гласови асистенти; `sitemap.xml`, `robots.txt` (с покана към
  AI обхождачите), `llms.txt`, Open Graph, гео мета тагове, канонични адреси.

**Администрация**
- Конфигурационно-управляван CRUD за всички типове съдържание, роли
  (Администратор/Редактор), одит лог, модерация на подаванията.

## Мобилно приложение (Android)

Има и Android приложение — **обвивка** на сайта (Trusted Web Activity). Показва
живия сайт на цял екран, така че съдържанието винаги е в синхрон със сървъра.
Конфигурацията и стъпките за построяване (с Bubblewrap) и публикуване в Google
Play са в папка **[`android/`](./android/README.md)**. Свързването със сайта
(Digital Asset Links) се управлява от админ панела → **Мобилно приложение**;
сайтът сервира `/.well-known/assetlinks.json` автоматично.

## Качество

Всяка промяна минава през едни и същи гейтове локално и в CI
(`.github/workflows/zabobovdol.yml`):

```bash
npm run lint        # ESLint (next/core-web-vitals + typescript)
npm run typecheck   # tsc --noEmit
npm test            # модулни тестове (node:test, без външни зависимости)
npm run build       # продукционен билд
```

Тестовете покриват чистата логика (slug, SEO граф, екраниране на Markdown/XSS,
парсера на данните от СИГМА) в `src/lib/__tests__`.

## Локална разработка

```bash
npm install
cp .env.example .env          # попълнете DATABASE_URL и тайните
npx prisma db push            # създава схемата
npm run db:seed:all           # начални данни + администратор
npm run dev                   # http://localhost:3000
```

Вход в администрацията: `/admin/login` с данните от `.env`.

## Продукция (почти автоматично)

Виж **[ПРЕДИ-ПУСКАНЕ.md](./ПРЕДИ-ПУСКАНЕ.md)** и **[DEPLOY.md](./DEPLOY.md)**.
Накратко, на VPS-а:

```bash
./scripts/setup-env.sh        # генерира .env с тайните + age ключ за бекъп
./scripts/deploy.sh           # строи, вдига и зарежда базата (само 1-ви път)
./scripts/init-letsencrypt.sh # безплатен HTTPS сертификат
```

Обновяване на данните по график (cron) — новини и прозрачност:

```bash
curl -H "Authorization: Bearer $INGEST_TOKEN" https://.../api/ingest-news
curl -H "Authorization: Bearer $INGEST_TOKEN" https://.../api/ingest-transparency
```

## Структура

```
src/
  app/                публични страници + админ панел + API + robots/sitemap/llms
  components/         UI и админ компоненти
  lib/                логика без UI (auth, prisma, seo, markdown, settings, …)
  lib/admin/          конфигурация на ресурси + сървърни действия
  lib/__tests__/      модулни тестове
prisma/               схема (schema.prisma) и сийд скриптове
scripts/              деплой, HTTPS и криптиран бекъп
```

## Сигурност и поверителност

HTTPS/HSTS, строга CSP, подписани JWT сесии (`HttpOnly`, `SameSite=strict`),
bcrypt пароли, ограничаване на честотата и honeypot по формите, екраниране на
потребителско съдържание, криптирани бекъпи. Виж **[SECURITY.md](./SECURITY.md)**
и страницата за поверителност в сайта. Данните се хостват в ЕС.
