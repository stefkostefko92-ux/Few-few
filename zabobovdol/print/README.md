# Рекламна брошура А5 (за печат)

Двустранна брошура А5 (148 × 210 мм) за град Бобов дол с истински QR код към
сайта и обозначено място за **NFC стикер** („Доближи телефона си").

## Файлове
- **`brochure-a5.pdf`** — готов за печат (2 страници: лице и гръб).
- `brochure-front.png`, `brochure-back.png` — прегледи на двете страни.
- `brochure-a5.html` — самостоятелен HTML (вграден QR + герб). Може да се отвори
  в браузър и да се разпечата директно (Print → Save as PDF, размер A5, без полета,
  с фонове/графики).
- `build-brochure.mjs` / `render-brochure.mjs` — за регенериране.

## Печат
- Печат на **A5**, цветно, без полета (borderless), на по-плътна хартия (250–300 г/м²).
- Двустранно: лице/гръб. Запазете истинските цветове („print background graphics“).

## NFC стикер
На **лицевата** страна, под надписа „Доближи телефона си", има жълто пунктирано
кръгче (Ø ~34 мм) — там се залепя NFC стикерът. Запишете в стикера адреса
`https://zabobovdol.carbonstealth.eu` (с приложение като NFC Tools). Когато човек
допре телефона си, сайтът се отваря автоматично.

## Регенериране
```bash
npm i qrcode playwright          # еднократно
node print/build-brochure.mjs    # сглобява HTML с QR код
node print/render-brochure.mjs   # прави PDF + PNG
```
