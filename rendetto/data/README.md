# data/ — само на сървъра

Тази папка е извън репото (`.gitignore`) и извън Docker образа. В продукция се монтира като volume:
`RENDETTO_DATA` в `.env` е `/opt/few-few/shared/rendetto/data` — `deploy/deploy.sh` не тръгва с друг път
(без `.env` compose взема `./data` — само за локален опит).

| Файл                     | Какво е                                                                                                                                | Откъде                                                                                                                                       |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `catalog.json`           | Каталогът от българските магазини: декори, RAL, дръжки, панти, водачи, обков за легла — с цени и връзки                                | Подава го собственикът ръчно (не е публичен)                                                                                                 |
| `dbip-country-lite.mmdb` | Държава по IP адрес, DB-IP Lite (CC BY 4.0)                                                                                            | В контейнера (`DEPLOY.md`, т. 4): `docker compose exec -T app node dist/scripts/geoip-update.js`; локално: `npm run geoip:update` след build |
| `audit-head.json`        | Котвата на одитната верига: номерът и хешът на последния запис (и началото след изтриване по срок) — хваща изрязан край или подменено начало | Пише я приложението при всеки одитен запис. Не се трие и не се редактира (`DEPLOY.md`, т. 7 и 8)                                             |

Без `catalog.json` продуктът работи с основния каталог (общи дръжки, системите на пантите и водачите
без конкретни артикули). Без GeoIP базата държавата в панела е „—“.

След смяна на `catalog.json` или на GeoIP базата приложението се рестартира — те се четат веднъж при
старт.
