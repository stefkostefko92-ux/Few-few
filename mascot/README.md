# Маскот — желирано телце с очила и академична шапка

Бранд маскотът на **Carbon Stealth**: полупрозрачно неоново-зелено желирано тяло с вътрешни
мехурчета, светещо ядро, дебели черни кръгли очила, папийонка и черна академична шапка със
златен пискюл.

Пакетът е **самостоятелен и без зависимости**: три SVG файла (по едно ниво на детайл), цветови
токени, генериран React компонент и витрина. Нищо тук не се инсталира — копираш това, което
ползваш, в продукта.

```
mascot/
  svg/            ← ИЗТОЧНИКЪТ на истината (геометрия + цвят)
  tokens.json     ← палитрата (единственият списък с HEX стойности)
  tokens.css      ← същата палитра като CSS променливи + микро-анимацията
  react/          ← ГЕНЕРИРАН компонент (не се редактира на ръка)
  build.mjs       ← svg/*.svg + tokens.css → react/JellyMascot.tsx
  check.mjs       ← гейтът
  demo/index.html ← витрина (отвори я в браузър)
```

## Трите нива на детайл

| Ниво | Файл | Съдържа | За какво |
|------|------|---------|----------|
| `full` | `svg/jelly-mascot-full.svg` | градиенти, блурове, ореол, мехурчета, кант | герой-кадър, ≥128 px |
| `medium` | `svg/jelly-mascot-medium.svg` | градиенти, **нула филтри** | среден размер, печат, векторни конвейери |
| `icon` | `svg/jelly-mascot-icon.svg` | плътни цветове, дебели рамки, **нула филтри и градиенти** | ≤32 px, favicon, аватар |

Гейтът налага разликите (`check.mjs`): филтър в `medium`/`icon` или щрих под 12 единици в
иконата пада CI-я. Причината е проста — блурът не оцелява при векторизация и печат, а тънката
линия при 16 px не е линия, а сива каша.

## Употреба

### Next.js / React

Копирай `react/JellyMascot.tsx` в продукта (напр. `src/components/`). Компонентът иска само React.

```tsx
import JellyMascot from "@/components/JellyMascot";

<JellyMascot detail="full" size={280} animated />            // герой
<JellyMascot detail="icon" size={24} title={null} />         // декоративна икона → aria-hidden
<JellyMascot detail="medium" size={160} background="black" /> // с черен герой-фон
```

| Prop | По подразбиране | Бележка |
|------|-----------------|---------|
| `detail` | `"full"` | `full` · `medium` · `icon` |
| `size` | `256` | число (px) или CSS дължина |
| `title` | `"Маскотът на Carbon Stealth"` | `null` → декоративен (`aria-hidden`, без достъпно име) |
| `background` | `"none"` | `"black"` добавя черния герой-фон вътре в SVG-то |
| `animated` | `false` | полюшване, пулс, мигане, пискюл |
| `style` | — | пребоядисване през `--jm-*` |

Всяка инстанция получава свой префикс за `id`-тата (`useId`) — два маскота на една страница не си
крадат градиентите.

### EJS / статичен сайт / Express

Като картинка (най-простото; пребоядисване няма, важат падащите цветове):

```html
<img src="/mascot/jelly-mascot-full.svg" alt="Маскотът на Carbon Stealth" width="256" height="256">
<link rel="icon" href="/mascot/jelly-mascot-icon.svg" type="image/svg+xml">
```

Вграден (позволява пребоядисване и анимация):

```ejs
<div class="jm-scope jm-animated"><%- include('../partials/jelly-mascot-full.svg') %></div>
```

⚠️ При вграждане на **няколко** маскота в една страница преименувай `id`-тата (или ползвай React
компонента) — иначе вторият SVG ще ползва градиентите на първия.

### Пребоядисване

Всеки цвят е `var(--jm-…, #HEX)` с падаща стойност, затова файловете изглеждат правилно и без CSS.
Задай променливите на родителя, за да смениш бранд-цвета:

```css
.brand-teal { --jm-neon: #0db6a8; --jm-olive: #2ae7d8; --jm-bottle: #04737f; --jm-deep: #023a4a; }
```

Работи само при **вграден** SVG. През `<img>` външният CSS не стига до документа на картинката.

## Палитра

Осемте цвята, снети от референцията, плюс изрично отбелязаните разширения (черни аксесоари, златен
пискюл, бяло на окото) — всичко в `tokens.json`. **Нов цвят се добавя там първо**: гейтът пада при
HEX стойност, която я няма в токените.

Две бележки към оригиналната палитра, които си струва да знаеш, преди да ги ползваш по име:
- `#99E72A` е кръстен „Olive Neutral", но по светимост е **глоу** цветът — тук е ядрото и лаймовият кант.
- `#3C3F28` е кръстен „Glow Lime", но е тъмен зелено-сив — **не е** емисия. Стои като неутрал за UI подложки.

## Анимация и достъпност

`.jm-animated` (в `tokens.css`, вградено и в компонента) дава полюшване ~3.6 s, пулс на глоуто
~2.6 s, мигане ~5.2 s и махане на пискюла. Нищо не мига по-бързо от 3 Hz (епилептичен риск няма),
а при `prefers-reduced-motion: reduce` движението е **нула**.

Достъпност: всеки SVG носи `role="img"`, `<title>` и `<desc>`, свързани през `aria-labelledby`.
Когато маскотът е декорация, подай `title={null}` — тогава компонентът излиза `aria-hidden` и
екранният четец мълчи, вместо да чете украса.

## Работен процес

```bash
cd mascot
# 1. Промяната винаги става в svg/*.svg или tokens.css — НЕ в react/.
node build.mjs      # регенерира react/JellyMascot.tsx
npm run gate        # check.mjs + тестове + проверка на витрината
```

`react/JellyMascot.tsx` е **генериран**. Ръчна редакция там пада гейта (`regenerate-and-diff`) —
геометрия, преписана на две места, се разминава при първата поправка.

## Растерни експорти (PNG)

Нямаме зависимости за растеризация в пакета. Когато трябва PNG, ползвай браузъра, който вече е в
средата:

```bash
chromium --headless --screenshot=mascot.png --window-size=1024,1024 \
  --default-background-color=00000000 svg/jelly-mascot-full.svg
```

Изнасяй на 2× или 4× и смалявай после; за герой-кадър слагай **чисто черно**, не тъмносиво —
контрастът е това, което кара глоуто да свети.

## Произход

Дизайнът следва подробен промпт-бриф (анатомия, палитра, материал/светлина, правила за
консистентност). Кондензиран е в [`prompts.md`](prompts.md) — там са и промптовете за генериране
на нови кадри (пози, изражения, ролеви варианти), които трябва да съвпадат с този маскот.
