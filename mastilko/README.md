# Мастилко 🖋️

**Безплатни етикети, визитки и CV — топло, на български, готови за печат.**

https://mastilko.carbonstealth.eu

Мастилко е малко „ателие в браузъра“: попълваш, виждаш на живо върху истински
А4 лист (в милиметри) и принтираш или запазваш PDF. Без регистрация, без
реклами, без бисквитки — данните остават само в браузъра на потребителя.

## Възможности

- 🏷️ **Етикети** — 5 размера/форми (вкл. кръгли и овални), топли цветови теми,
  линии за рязане; пълен лист А4 наведнъж.
- 💼 **Визитки** — стандарт 90 × 54 mm, 6 шаблона, 10 визитки на лист.
- 📄 **CV** — модерен, класически и **Europass** (стандартът на ЕС, вкл.
  майчин език, чужди езици с нива, дигитални умения, категория МПС) шаблон;
  автоматично разпъване на няколко страници.
- ✨ **AI помощ (Google Gemini Flash, безплатен)** — текст за етикет, слоган за
  визитка, професионален профил и подобряване на описания в CV. Работи само
  при изричен клик; без ключ сайтът работи напълно, само без подсказки.

## Разработка

```bash
npm install
cp .env.example .env   # по желание: GEMINI_API_KEY за AI подсказките
npm run dev            # http://localhost:3000
```

Качествена порта преди merge:

```bash
npm run lint && npm run typecheck && npm test && npm run build
```

## Продукция

Node ≥ 20. `npm ci && npm run build && npm start` зад reverse proxy (Nginx +
TLS), по модела на останалите продукти в монорепото. Тайните (`GEMINI_API_KEY`)
живеят само на сървъра (mode 600) — никога в репото.
