# Semki Bot

Discord бот, който следи трайността на семките във FiveM сървъра, показва колко време им остава и
тагва роля в канал, когато партида стигне праг. Малък дашборд на `https://vps2.carbonstealth.eu` с
вход през Discord.

## Какво прави

- Семките започват от 100% и падат с **0,6% на 60 минути** (100% → 0% за 166 ч 40 мин). Скоростта
  се сменя за всеки вид от дашборда.
- Въвеждане с команди — всяка добавя **нова партида**:
  `/amnesia брой дюрейшън` · `/ak …` · `/ogkush …` · `/purple …` · `/skunk …`
  (`брой` 1–100000, `дюрейшън` = текущият % от 0 до 100, напр. 87.4).
- `/infosemki [вид]` — всички партиди по видове, като в „Партиди“: здраве, брой семки, % трайност,
  оставащо време, кога изтичат. Видима за всички.
- `/iztriisemki` — меню с отметки: отметваш партидите (до 25, първо изтичащите) и натискаш
  „Изтрий избраните“. `/iztriisemki вид:Amnesia` — менюто само с този вид, всички отметнати.
  `/iztriisemki партида:12` — само тази партида; `/iztriisemki партида:12 брой:3` — маха 3 семки от нея.
- **Дашборд** — главната страница (`/`): в едно изречение кое изтича първо и кога е следващият таг;
  бързо добавяне на партида (видът, броят и трайността — 100% по подразбиране); за всеки вид плочки по
  една на партида с **3D семена** (three.js), които се виждат свежи или гниещи според процента —
  „Свежа“ (75–100%), „Здрава“ (50–75%), „Остарява“ (25–50%), „Разваля се“ (10–25%), „Гние“ (под 10%),
  „Изтекла“ — и легенда с по едно семе за всяка степен. **Всеки вид изглежда различно** (Amnesia —
  дълго и тънко на тънки ивици, AK — кафяво на широки ивици, OG Kush — закръглено на петна, Purple —
  лилаво, Skunk — сиво на черни точици). Сгъваема прогноза във времето. Опреснява се на 5 минути, но не
  докато пишеш във формата.
- **Партиди** (`/batches`): по видове, с отметки → „Изтрий отметнатите (N)“, „Отметни всички“ и
  „Изтрий всички <вид>“ (с потвърждение), редакция на брой и %; плочка от дашборда отваря своята партида.
- **Снимки в Discord:** под известията и под отговора при добавяне ботът прикача снимка на семената за
  всеки вид в съобщението — в здравето на най-слабата му партида. `/infosemki` показва целия списък (всички
  партиди, %, кога изтичат) и една снимка — на партидата с най-нисък процент. Снимките са в
  `assets/seeds/` (вид × здраве, рисувани от същия 3D код: `npm run render:seeds`). Нужни са права
  **Attach Files** и **Embed Links** в канала; без тях съобщението тръгва само с текст.
- Известия (от дашборда): правило = вид или всички + **праг в %** (при ≤ X%) или **оставащо време**
  (X часа до 0%) + канал + роля. Тагва веднъж или, ако зададеш **повторение** (на всеки X минути, от
  5 до 10080), отново, докато партидата е под прага — до триене или освежаване. По избор — **свое
  съобщение** след тага (до 500 знака) вместо „Семките изтичат“; партидите се изреждат под него.
- **Часови прозорец** (по избор): тагване само между напр. 10:00 и 23:00; минатото през нощта се
  тагва в началото на прозореца.
- Права: дашбордът — ролята от „Настройки“; командите за добавяне/триене — друга роля от „Настройки“.
  Собственикът на сървъра и Administrator имат достъп винаги.

## Настройка в Discord (веднъж)

1. https://discord.com/developers/applications → **New Application**.
2. **Bot** → Reset Token (за `.env`). Привилегировани intents не са нужни.
3. **OAuth2** → Client Secret (за `.env`) и **Redirects**: `https://vps2.carbonstealth.eu/auth/callback`.
4. Покана на бота: **OAuth2 → URL Generator** → scopes `bot` + `applications.commands`; права
   `View Channels`, `Send Messages`, `Attach Files` и `Embed Links` (снимките на семената под
   съобщенията), `Mention Everyone` (за да тагва роли, които не са „mentionable“). Вече поканен бот:
   добави му `Attach Files` и `Embed Links` в канала за известия.
5. Server ID: Discord → Settings → Advanced → Developer Mode, после десен клик върху сървъра → Copy Server ID.

## Разработка

```bash
cd semki
npm ci
cp .env.example .env      # попълни; DATABASE_URL към локален PostgreSQL
npx prisma migrate deploy
npm run dev
npm run check             # гейтът: prettier + typecheck + тестове + build
TEST_DATABASE_URL=postgresql://…/semki_test npm run test:integration
```
