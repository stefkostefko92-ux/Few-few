# Сигурност — LaTuaAuto

- **Табелата е лична данна** (Касация/Garante). Пази се нормализирана +
  `plateHash` (sha256 с `PLATE_PEPPER`, само на сървъра); никога в логове
  (само `maskPlate`), никога в публичен указател, никога „тази табела е
  регистрирана“.
- **Анти-тормоз по дизайн:** непотвърдено владение не получава; първи контакт
  само шаблон; свободен текст след отговор; 5 нови контакта/ден; нишка без
  отговор изтича за 48 ч; блок/сигнал с мотивирано решение (DSA).
- **Нула геолокация, нула телефон.** Само имейл + хеш на парола.
- **Пароли:** bcrypt (12). **Сесии:** httpOnly/secure/lax cookie; в БД само
  sha256 на токена. (Auth слоят е следващ етап — схемата е готова.)
- **Вход:** всеки server action валидира със zod; публичните форми имат
  honeypot; ownership проверки `where: { userId }`.
- **Хедъри:** HSTS, X-Content-Type-Options, X-Frame-Options DENY,
  Referrer-Policy, Permissions-Policy (`next.config.mjs`).
- **JSON-LD** е единствената употреба на `dangerouslySetInnerHTML` — само
  наши данни, `<` се escape-ва.
- **GDPR:** основание чл. 6(1)(b)/(f)/(a); LIA + DPIA преди пускане;
  срокове: нишки 48 ч, IP 90 дни, контактни съобщения 12 мес. Данни в ЕС.
- **Тайни:** само в env файла на сървъра (mode 600); примерният файл в репото
  е без стойности.

  root `SECURITY.md`).
