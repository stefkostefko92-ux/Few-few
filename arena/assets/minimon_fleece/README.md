# Minimon fleece — комплект дрехи за Thraex PVP

Къса худи с цип (`jbib`) и джогър (`lowr`) за женския freemode персонаж (`mp_f_freemode_01`).
Един модел, три цвята: **a** розово `#DDA3A5`, **b** черно `#232125`, **c** виолетово `#714FA0`.
На гърба има надпис „Minimon“ от сребърни кристали и червено кристално сърце.

Тук са изходните файлове. В ресурс за сървъра още не са превърнати: липсват тегла към скелета
и файловете `.ydd`/`.ytd`. Как става — по-долу.

## Съдържание

| Папка | Какво има |
|---|---|
| `blender/minimon_fleece_game.blend` | Моделът за играта: `jbib_000` и `lowr_000`, по 5 584 триъгълника всеки (с вътрешните обвивки при отворите), с UV атлас и материал за преглед. Текстурите са с относителни пътища към `../textures/`. Blender 4.2+ |
| `textures/` | 2048 × 2048 PNG: `*_diff_000_a/b/c_uni.png` (цвят, с изпечени кристали и надпис), `*_normal_000.png` (tangent, OpenGL), `*_spec_000.png` (маска: кристали и метал бели, плат тъмен) |
| `fbx/` | Същите два модела като FBX, без скелет |
| `previews/` | Рендери: детайлният модел в трите цвята, надписът отблизо, моделът за играта с текстурите (`game_*`) |
| `source/` | Скриптовете, с които е направено всичко, и шрифтът на надписа (Pacifico, SIL OFL 1.1) |
| `ATTRIBUTION.txt` | Авторства на активите: копирай го в ресурса |

## Как влиза в сървъра

Тези стъпки искат файлове от GTA V, затова се правят на компютъра със сървъра.

1. **Наместване.** Отвори `blender/minimon_fleece_game.blend`. Манекенът, по който е правен моделът, не е тялото на freemode. Намести дрехата върху `mp_f_freemode_01` в базовата му поза (Shrinkwrap, Lattice или скулптиране) и не пипай UV.
2. **Тегла.** Скелетът на `mp_f_freemode_01` служи само за работа и не влиза в ресурса. Прехвърли теглата от тялото към дрехата (Data Transfer → Vertex Groups). Групите трябва да са с имена `SKEL_*`.
3. **LOD.** high е този модел; medium и low направи с Decimate.
4. **Към играта.** Изнеси `.ydd` (Sollumz или CodeWalker.Core, както е правена банданата). Текстурите отиват в `.ytd`: DXT1/DXT5 с mipmaps, по един файл за всяка буква a, b, c. Normal и spec се вграждат в `.ydd` като `jbib_normal_000` / `jbib_spec_000` (същото за `lowr`). Ако в играта бумповете излязат обърнати, обърни зеления канал на normal map-а.
5. **Гардероб.** Добави комплекта в `bg_arena_clothes` по същия начин като банданата: свой раздел, английски имена в играта, безплатно за всички.
6. **Проверка.** `node tools/fivem/stream-lint.mjs <ресурс>` трябва да даде `0 ERROR`. После влез с женски персонаж и пробвай и трите цвята.

Само за женския персонаж е. За мъжкия трябва отделно наместване върху `mp_m_freemode_01`.

## Как се прави наново

Нужни са Python 3.13 и `bpy` 5.2.3 (`pip install bpy==5.2.3`). Скриптовете се пускат от `source/`:

```bash
export RFS_FONT=$PWD/font/Pacifico-Regular.ttf
python build_rfs.py --out ../out/high --renders all                         # детайлен модел + рендери (розово)
RFS_COLORWAY=black python build_rfs.py --out ../out/black --renders hero,back
RFS_LOD=game python build_rfs.py --out ../out/game --renders none          # модел за играта
python bake_rfs.py --high ../out/high/rose_fleece_set.blend --game ../out/game/fleece_game_lowpoly.blend --out ../out/bake
python compose_tex.py ../out/bake/textures ../out/bake/final
python preview_game.py --work ../out/bake/bake_work.blend --tex ../out/bake/final --high ../out/high/rose_fleece_set.blend --out ../out/preview
```

Изпичането при 2048 px отнема около 15 минути на 4 ядра.

## Известно

- Шевът между ръкава и тялото излиза малко по-тъмен на модела за играта. Прилича на шев, но провери го в играта.
- Гънките са генерирани с формули, не със симулация на плат.

## Правни бележки

- Дрехата е по снимки на чужд продукт, но логото на марката не е пренесено: кристалните мотиви по ръкавите и висулката на ципа са празни слотове. Надписът „Minimon“ е на собственика.
- Меш и текстури са изцяло собствени. В тази папка няма данни от Rockstar.
- Шрифтът Pacifico е под SIL OFL 1.1 (`source/font/OFL.txt`). Вписан е в `ATTRIBUTION.txt`.
- Ако дрехата се продава, това става само през Tebex и след писмено потвърждение от Cfx.re.
