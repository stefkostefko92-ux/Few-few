# ADR — Architecture Decision Records

Кратък запис per значимо архитектурно решение: **контекст → решение → последици**.
Номерирани, immutable — ново решение = нов файл `NNNN-title.md`, не редакция на стар.
Статус: `Proposed` / `Accepted` / `Superseded by NNNN`.

## Индекс
- [0001 — Prisma вместо Next+Sanity](0001-prisma-vs-sanity.md) — Accepted

## Шаблон

```markdown
# NNNN — Заглавие

Статус: Proposed
Дата: YYYY-MM-DD

## Контекст
Какъв е проблемът/силите в игра.

## Решение
Какво решаваме и защо.

## Последици
Какво следва (добро и лошо); какви опции затваряме.
```
