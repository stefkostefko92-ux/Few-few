# Принос към проекта

Благодарим за интереса! Този проект се поддържа от Carbon Stealth VCC в полза на
ФК „Миньор“ Бобов дол.

## Среда за разработка

```bash
npm install
cp .env.example .env
npx prisma db push
npm run db:seed
npm run dev
```

## Стандарти за код

- **TypeScript (strict)**, без `any` освен в единичните, коментирани места за
  динамичен достъп до Prisma делегати.
- Преди commit изпълнете:

  ```bash
  npm run lint
  npm run typecheck
  npm run build
  ```

- Запазвайте съществуващите конвенции: стилизиране с Tailwind, текстове на
  български, достъпен и семантичен HTML.
- Съдържанието (новини, състав, мачове и т.н.) се управлява през админ панела,
  а не чрез промени в кода.
