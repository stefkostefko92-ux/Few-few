# Стартови данни (seed)

Сайтът работи изцяло в браузъра. Ако тук поставиш файл с реалния архив на
тегленията, той се зарежда автоматично при първо отваряне.

Очаквани имена на файлове (по една игра):

- `5x35.json`
- `6x42.json`
- `6x49.json`

Формат — масив от тегления, подредени от най-стар към най-нов:

```json
[
  { "date": "2025-01-03", "numbers": [3, 12, 18, 27, 31] },
  { "date": "2025-01-07", "numbers": [5, 9, 14, 22, 30] }
]
```

Ако няма такъв файл, сайтът зарежда **демо данни** (случайни), за да е
използваем веднага. Реалните данни може да се заредят и през интерфейса
(таб „Данни" → Импорт), без да се пипат файлове.

## Откъде се вземат официалните тегления

Архивът е публичен на сайта на Български спортен тотализатор (toto.bg),
секция с резултати/архив на ТОТО 2. Сайтът е защитен срещу автоматично
изтегляне, затова данните се копират ръчно или се сваля наличният
експорт и се поставя в горния формат.
