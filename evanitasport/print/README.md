# print/ — печатни материали на Evanita Sport

## Брошура А5 (лице + гръб)

- `brochure-a5.pdf` — готовият файл за печатница (148×210 mm, 2 страници,
  фоновете стигат до ръба; ако печатницата иска обрязване (bleed), кажи ѝ да
  добави 3 mm от фоновия цвят — дизайнът няма елементи до самия ръб).
- `brochure-front.png` / `brochure-back.png` — прегледи на двете страни.
- `brochure-a5.html` — генерираният самостоятелен източник (шрифтове, лого и
  QR код са вградени като data URI — отваря се офлайн навсякъде).

## Регенериране (при промяна на график/телефон/текст)

Редактирай `build-brochure.mjs` (данните са в него, взети от сайта), после:

```bash
npm i qrcode playwright           # еднократно, извън репото
node print/build-brochure.mjs     # HTML с вграден QR + лого + шрифтове
PW_PATH=<път до chromium> node print/render-brochure.mjs   # PDF + PNG
```

Данните в брошурата (телефон, адрес, график, часове) са РЕАЛНИ — при промяна
ги сверявай с `index.html` и не измисляй цени (ценообразуването е индивидуално).

## Шрифтове (`fonts/`)

Cormorant Garamond (кирилица + латиница) и Outfit (латиница) — субсети woff2 от
Google Fonts, лиценз SIL OFL. Вграждат се в HTML-а при build.
