# Принос към MedQR

Това е частен проект на CarbonStealth VCC. Външни приноси не се приемат без
предварителна договорка, но същите правила важат за вътрешната работа.

## Работен процес

1. Разработвайте на отделен клон, не директно в основния.
2. Преди commit: `npm run format` и `npm run lint` трябва да минават чисто.
3. `npm test` трябва да е зелено; при промени по passkeys пуснете и
   `npm run test:webauthn` (изисква Playwright + Chromium).
4. Описвайте commit-ите ясно и по същество.

## Стил

- Форматирането се налага от Prettier, а правилата — от ESLint (виж конфигурациите).
- Не вкарвайте тайни в кода или в хранилището; ползвайте променливи на средата
  (виж `.env.example`).
- Чувствителните данни са специална категория по GDPR — внимавайте какво логвате.

## Локално стартиране

npm ci
export ENCRYPTION_KEY=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")
