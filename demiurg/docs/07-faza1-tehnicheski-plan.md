# 07 · Фаза 1 — технически план (истински voxel, single-player MVP)

> Конкретен план за брутално малкия MVP от `06`. Цел: **докажи, че кубичното voxel ядро е
> стабилно И забавно за 1 играч** — преди мултиплейър/дълбочина/UGC.

---

## 0. Изход на Фаза 1 (Definition of Done)

Играем `.exe` (Development билд), в който външен плейтестър: влиза в процедурна японска
долина, копае/строи воксели стабилно, събира и крафтва, строи убежище, оцелява една нощ срещу
1–2 врага, записва/зарежда — при ≥ 60 FPS на среден GPU и без загуба при save. + анкетен
сигнал „искам пак“.

---

## 1. Първо: voxel tech spike (седмица 1–2) — РЕШЕНИЕ ПРЕДИ ВСИЧКО

Истинският кубичен voxel има три пътя; изберѝ с 1–2 седмичен прототип „копай+постави+chunk
streaming“ във всеки кандидат, после заключи:

| Кандидат | Плюс | Минус | Кога |
|---|---|---|---|
| **Собствен C++ chunk engine** (16³/32³, greedy meshing, face culling, Task Graph) | пълен IP контрол, точно кубично, без праг за лиценз | 3–9 мес. само за база | ако искаме контрол и имаме силен C++ |
| **Easy Voxels: Cubic** (Marketplace) | точно Minecraft-стил, greedy meshing, LOD, готово | по-тесен, зависимост | **вероятен старт за MVP** |
| **Voxel Plugin 2** ($349) | зряло, мощно, разрушаемо | по-скоро smooth/SDF, не чисто кубично; **custom лиценз при бюджет >$100k** | ако решим да смесим smooth/cubic |

**Препоръка:** започни spike с **Easy Voxels: Cubic** (най-бърз път до кубично ядро) + паралелно
малък собствен greedy-mesh прототип като резервен вариант/учебен. Заключи tech до края на
седмица 2. Критерии: стабилен re-mesh < 100 ms, collision, save-friendly данни за chunk.

> ✅ **Собственият C++ chunk прототип вече е заложен в репото** → [`../game/`](../game/)
> (`Source/Demiurg/Voxel/`): `VoxelChunk` (chunk данни + face-culling meshing през
> `ProceduralMeshComponent`), `VoxelWorld` (спавн на мрежа chunk-ове + `EditBlockAtWorld`
> копай/постави), `VoxelTypes` (блокове/константи). Отвори в UE 5.6, компилирай и оцени —
> инструкции в [`../game/README.md`](../game/README.md). Това покрива „собствен engine“
> кандидата на спайка; сравни го с Easy Voxels: Cubic, преди да заключиш.

## 2. UE5 setup (седмица 1)

- **UE 5.6**, C++ проект (не blueprint-only) — voxel ядрото е C++, геймплей итерация в Blueprints.
- **Конфигурация:** World Partition ON; Lumen ON (software fallback за low-end); Nanite само за
  статичен далечен декор (не за voxel chunks — виж `03` §1).
- **Контрол на версиите (важно!):** UE проектът носи големи бинарни асети. Кореновият
  `.gitignore` пази само `node_modules/`+`.DS_Store` — за `demiurg/` трябва:
  - собствен `demiurg/.gitignore` (UE стандарт: `Binaries/ Intermediate/ DerivedDataCache/
    Saved/ .vs/`),
  - **Git LFS** за `*.uasset *.umap` (или отделен Perforce/Git LFS remote), иначе репото ще
    се надуе. **Заложи това в първия ден на разработка**, не после.
- CI: добави path-filtered workflow, който при промени в `demiurg/` прави поне compile check.

## 4. Задачи по система (Фаза 1)

- **Voxel core:** chunk data структура · greedy meshing · face culling · re-mesh on edit ·
  collision mesh · streaming около играча · serialize промени за save.
- **Свят:** PCG/шум за heightmap · слоеве материали · размяна биом-декор (бамбук/дървета/скали) ·
  спавн точка.
- **Играч:** движение/камера (first или third person — реши рано) · копаене/поставяне raycast ·
  inventory · крафт UI · глад/здраве.
- **Оцеляване/бой:** ден/нощ таймер · спавн на врагове нощем · меле combat · щети/смърт/респаун.
- **Систем:** save/load (свят делти + играч) · настройки/графика · pause/menu.
- **Арт/аудио:** блок текстури/материали · декоративни меш (тории/покриви/фенери) · осветление/
  мъгла · ambient звук/музика.

## 5. Специфични рискове за истински voxel + мерки

| Риск | Мярка |
|---|---|
| Re-mesh hitch при бързо копаене | greedy meshing + async re-mesh (Task Graph); ограничи chunk размер |
| Nanite/Lumen конфликт с динамични chunks | chunks = не-Nanite; Lumen с разумни настройки; Nanite само статичен декор |
| Памет при много активни chunks | streaming по view distance; освобождавай далечните |
| Collision/physics cost | генерирай collision само за близки chunks |
| Save размер/скорост | записвай само **делти** спрямо seed, не суров свят |
| Voxel Plugin >$100k лиценз | ако тръгнем с него — договаряй рано; иначе Easy Voxels/собствен |
| Обхват пълзи | всеки extra фийчър извън списъка в §3 → post-MVP backlog (виж `02` §6) |
