# Промо клипът на Фактурист

Презентационен клип за YouTube на български: 1:40 (100,6 s), 1920×1080, 30 кадъра/s, H.264 + AAC.
Всичко е наше: кадрите са от истинското приложение, анимацията се рисува в Chromium, музиката е
синтезирана с numpy (без семпли и чужди права). Готовите файлове не се пазят в репото (`dist/` е в
`.gitignore`) — правят се наново с командите по-долу.

Клиповете са замразени (правило на собственика от 15.10.2026): нов рендер — само по изрична заявка.

## Как се прави

```bash
cd fakturist
npm ci && npm run build

# 1. Кадрите от приложението: вдига Фактурист върху тестова база (името завършва на _test — таблиците се
#    трият), зарежда примерни фирми и снима страниците. Датите в полетата излизат на български само с
#    българска локализация на Chromium.
LANG=bg_BG.UTF-8 LANGUAGE=bg TEST_DATABASE_URL=postgresql://…/fakturist_audit_test npx tsx promo/capture.ts

# 2. Клипът кадър по кадър + музиката → dist/promo/fakturist-promo-bg.mp4 и корицата
node promo/render.mjs
node promo/render.mjs --stills 3,12.5,40   # само кадри за преглед → dist/promo/stills/
node promo/render.mjs --step 6             # бърз преглед: всеки 6-и кадър, без музика
```

Нужни: PostgreSQL 16, Playwright с Chromium от средата, ffmpeg, `pdftoppm` (poppler), python3 + numpy.

| Файл                        | Какво е                                                                                  |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| `capture.ts`                | живите кадри (компютър 1440×900 @2x, телефон 390×844 @3x), PDF и XML на примерна фактура |
| `film.html` · `film-lib.js` | сцената и помощниците (време, плавност, текст, прозорец с камера, курсор)                |
| `film.js` · `film-end.js`   | сцените 1–5 и 6–12                                                                       |
| `music.py`                  | музиката: 104 BPM, 43 такта; всеки преход в картината пада на удар                       |
| `render.mjs`                | рендерът кадър по кадър и сглобяването с ffmpeg                                          |
| `youtube.md`                | заглавие, описание, глави и тагове за качването                                          |

## Какво не се променя без проверка

- **Датата 01.07.2028** е по законопроект № 52-602-01-60 — на екрана пише „Според внесения законопроект“.
  Ако законът излезе с друга дата, клипът е остарял.
- **Peppol и отчитането към НАП** са „предстои“ (`status: 'planned'` в `src/features.ts`) — клипът никога
  не ги показва като налични. Никъде „одобрен от НАП“ или „сертифициран“.
- **Цените** са от началните планове (`src/billing/plans.ts`) и са без ДДС. Смяна на цена → нов рендер.
- **ЕИК-ите на екрана** са явно примерни поредици (`eiks` в `capture.ts`, напр. 123456786) — фирмите са измислени.
- Сила на звука: около −13 LUFS, пик −1 dBFS (YouTube я сваля сам до своята норма).
