# GUI за Ubuntu VPS (XFCE + xRDP)

Скриптове за инсталиране на графична десктоп среда на Ubuntu VPS с
отдалечен достъп през **RDP** (Remote Desktop Protocol).

- **XFCE** — лека и бърза десктоп среда, идеална за VPS с ограничена RAM
  (работи добре дори с 1–2 GB).
- **xRDP** — позволява връзка с вградения Remote Desktop клиент на
  Windows, без да инсталираш нищо допълнително на компютъра си.

Поддържани версии: **Ubuntu 20.04 / 22.04 / 24.04**

## Инсталация

Влез в VPS-а през SSH и изпълни:

```bash
git clone https://github.com/stefkostefko92-ux/Few-few.git
cd Few-few
sudo bash install-gui.sh
```

Скриптът:

1. Инсталира XFCE и xRDP.
2. Настройва XFCE като сесия по подразбиране за твоя потребител
   (ако скриптът е пуснат от root, ще те попита за потребителско име и
   ще го създаде, ако не съществува).
3. Поправя известния polkit popup проблем при RDP сесии.
4. Отваря порт 3389 в UFW (ако UFW е активен).
5. Стартира xrdp услугата.

## Свързване

| Откъде | Как |
|---|---|
| Windows | Старт → **Remote Desktop Connection** (`mstsc`) → въведи IP-то на VPS-а |
| macOS | **Windows App** от App Store → Add PC → IP-то на VPS-а |
| Linux | **Remmina** (протокол RDP) → IP-то на VPS-а |

Влез с потребителското име и паролата от системата (не с root).

## Сигурност (важно!)

Порт 3389 се сканира постоянно от ботове. Препоръки:

- Използвай **силна парола** за потребителя.
- Инсталирай fail2ban: `sudo apt install fail2ban`
- Най-сигурният вариант — затвори порт 3389 за външния свят и ползвай
  **SSH тунел**:

  ```bash
  # на твоя компютър:
  ssh -L 3389:localhost:3389 потребител@IP-на-VPS-а
  ```

  След това се свържи с RDP клиента към `localhost:3389`. Така RDP
  трафикът минава криптиран през SSH и портът не е публично достъпен:

  ```bash
  # на VPS-а:
  sudo ufw delete allow 3389/tcp
  ```

## Премахване

```bash
sudo bash uninstall-gui.sh
```

## Чести проблеми

- **Черен екран след вход** — увери се, че НЕ си влязъл едновременно през
  конзолата (напр. VNC на доставчика) със същия потребител, и рестартирай
  xrdp: `sudo systemctl restart xrdp`.
- **Връзката се разпада веднага** — провери дали порт 3389 е отворен и в
  firewall-а на доставчика на VPS-а (някои имат отделен firewall в
  контролния си панел).
- **Бавна/насечена картина** — в настройките на RDP клиента намали
  качеството на цветовете (16 bit) и резолюцията.
