# MedQR — спешен клиничен профил с QR код

Система, която помага на хора със слухови проблеми и на всеки с хронично
заболяване: създава защитен **спешен медицински профил**, достъпен чрез сканиране
на **QR код** или докосване на **NFC таг**. При злополука или влошаване спешен
екип отваря кода и вижда кръвна група, алергии, заболявания, медикаменти и контакт
на близък — а профилът **изрично отбелязва слухов статус, възможност за говор и
жестов език**, така че екипът да знае, че лицето може да не реагира на говор, и как
да общува с него.

Подробното проучване (контекст, архитектура, GDPR, достъпност, пътна карта) е в
[`docs/ПРОУЧВАНЕ.md`](docs/ПРОУЧВАНЕ.md).

## Какво прави

- Регистрация и вход (имейл + парола) с **изрично съгласие** при регистрация;
  „остани вписан" (дълготрайна сесия с плъзгащо подновяване).
- **Потвърждение на имейл** и **възстановяване на забравена парола** по имейл.
- Редакция на медицински профил: име, дата на раждане, кръвна група, алергии,
  заболявания, медикаменти, слухов статус, възможност за говор, жестов език,
  контакт на жестов преводач, начин на комуникация, език, спешен контакт, бележки.
- Личен **QR код** в **5 размера** (стикер → постер), самообяснителен двуезичен
  **медицински етикет** (SVG), **карта за портфейл** за печат и **NFC** запис.
- **Спешен изглед** само за четене, достъпен публично чрез дълъг непредвидим токен.

### Достъпност за глухи и неми хора (отличителното)

- **Интерактивен помощник за общуване** в спешния изглед: двупосочни докосваеми
  карти (отговори от пациента и въпроси от екипа), писане с **четене на глас**
  (дава „глас" на неговорещ човек), голям дисплей и **карта на тялото** за
  посочване къде боли, плюс визуална скала на болката 0–10.
- Режим **„Спешна помощ (SOS)"**, задействан от самия потребител, когато е сам и
  още не е намерен: екран за минувач с **обаждане до 112 с едно докосване**,
  **сирена + мигащ екран + вибрация** за привличане на внимание и **SOS до
  близките** (готов SMS + имейл с местоположение).
- **Двуезичен интерфейс (BG/EN)** с превключвател; четенето на глас е на езика
  на страницата — за чужд екип или българин в чужбина.

### Сигурност (максимална защита)

- **Криптиране в покой** (AES-256-GCM) на всички чувствителни медицински полета.
- **HTTPS пренасочване, HSTS и Secure бисквитки** в продукция; строга **CSP**
  с nonce (без `unsafe-inline`).
- **CSRF защита** на всички форми (synchronizer token + header).
- **Двуфакторна автентикация (TOTP)** с еднократни **резервни кодове**.
- **Паскейове (WebAuthn/passkeys)** — вход без парола, устойчив на фишинг.
- **Argon2id** хеширане на пароли/PIN (с прозрачна миграция от стари bcrypt хешове).
- **Активни сесии** с „изход от всички устройства" и tamper-evident одит лог.
- **Заключване след неуспешни опити** (brute-force) + rate limiting.
- Незадължителен **PIN** за спешния изглед и **обезсилване на изгубен код**.
- При активирано известяване — **авто-уведомяване на близкия** при сканиране
  (имейл без медицински данни) и **споделяне на местоположение** с висока точност.

### Офлайн и мобилни приложения

- **PWA service worker**: ключовите екрани (SOS, спешен изглед, табло) и ресурсите
  работят и **без интернет**, с индикатор за офлайн режим; личният кеш се чисти при изход.
- **Android и iOS приложения** чрез Capacitor — в `mobile/` (всяка платформа в
  своя папка). Нативната обвивка пази сесията (без парола след първи вход), с
  опционално **биометрично заключване** (Face ID / пръстов отпечатък).

### SEO / GEO / AEO

- Per-page `<title>`, meta description, canonical, `robots`, Open Graph/Twitter,
  GEO meta тагове и **двуезични** мета данни.
- JSON-LD: Organization, WebSite, SoftwareApplication, FAQPage, BreadcrumbList
  (с CSP nonce), валидни и на двата езика.
- `robots.txt`, `sitemap.xml`, `manifest.webmanifest`, `llms.txt`, `security.txt`.

### GDPR / права на потребителя

- Екран за **изрично съгласие** (чл. 9 GDPR), със запис на момента и версията.
- **Износ на данните** (JSON) и **изтриване на профила** (право на забравяне).
- **Политика за поверителност**, **Бисквитки** и **Общи условия** (двуезични;
  администратор: CarbonStealth VCC). Само строго необходими бисквитки — без банер.

## Архитектура

Node.js (Express) + SQLite (better-sqlite3) + EJS. QR/NFC сочат към хостван адрес
(`/e/<token>`), а данните стоят криптирани в базата — така профилът се обновява без
нов код, а достъпът се контролира и одитира.

## Стартиране

```bash
npm install

# Генерирайте ключ за криптиране (32 байта hex):
export ENCRYPTION_KEY=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")

npm start            # http://localhost:3000
```

За разработка: `npm run dev` (auto-reload). Без `ENCRYPTION_KEY` извън продукция се
ползва дев ключ (с предупреждение). За продукция вижте `.env.example` — задължителни
са `NODE_ENV=production`, `ENCRYPTION_KEY`, `PUBLIC_BASE_URL` (HTTPS).

## Разгръщане

- **Бързо демо:** Render Blueprint (`render.yaml`) — виж [`docs/render-deploy.md`](docs/render-deploy.md).
- **Продукция (Hetzner, ЕС):** процесът зад **reverse proxy** (nginx/Caddy) с TLS;
  `trust proxy` е включен. Пазете `ENCRYPTION_KEY` извън хранилището (systemd
  `EnvironmentFile`, права 600). Криптирани архиви на `data/`. Виж [`deploy/`](deploy/).
- **Мобилни приложения:** виж [`mobile/README.md`](mobile/README.md).

## Тестове и качество

```bash
npm test              # 24 end-to-end проверки (smoke)
npm run lint          # ESLint (flat config)
npm run format        # Prettier
```

`test/smoke.test.js` минава през целия поток: CSRF, регистрация със съгласие,
криптиране в покой, SOS + известия, спешен достъп и споделяне на локация, износ на
данни, 2FA (вкл. „остани вписан" през 2FA), одит верига и защита на маршрутите. За
паскейовете има отделен e2e тест с виртуален authenticator: `npm run test:webauthn`.
CI проверява lint, тестове, `npm audit` и SBOM.
