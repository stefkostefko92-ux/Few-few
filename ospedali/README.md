# Ospedali Trasparenti — финансите на публичните болници в Италия

Автоматизиран ETL пайплайн, който извлича **официални open data** за приходите и
разходите на всички публични здравни структури в Италия (ASL, Aziende
Ospedaliere, AOU, IRCCS) и генерира **подробен Markdown отчет за всяка структура**
плюс агрегиран индекс и машинно-четим CSV.

## Източници (без ключове, публични)

| Източник | Какво дава | Достъп |
|---|---|---|
| [BDAP Open Data](https://bdap-opendata.rgs.mef.gov.it) (RGS/MEF) | Модели **CE** (отчет за приходите и разходите) и **SP** (баланс) на всички структури от SSN, по години (2012–днес) | CKAN API + CSV dump |
| [dati.salute.gov.it](https://www.dati.salute.gov.it) (Мин. на здравеопазването) | Анаграфика на болничните структури: легла, персонал, лекари, приеми, леглодни (модел HSP) | CSV |
| [OpenBDAP](https://openbdap.rgs.mef.gov.it/it/SSN/Analizza) | Референтен визуален портал за същите данни | — |

## Употреба

```bash
npm run fetch:catalogo    # каталог на CE/SP/LA датасетите от CKAN (кешира се инкрементално)
npm run fetch:anagrafica  # анаграфика на болниците от dati.salute.gov.it
npm run fetch:finanze     # годишните CE/SP CSV файлове за годините от config.json
npm run report            # генерира reports/ — отчет за всяка структура + index + CSV

npm run all               # всичко наведнъж
```

- Всички сваляния са **идемпотентни** (кеш в `data/raw/`, не се теглят повторно).
- Първото пускане на `fetch:catalogo` тегли метаданните на целия CKAN каталог
  (~3800 датасета, ~30 мин); следващите пускания са инкрементални (секунди).
- `config.json` определя обхвата: `{ "anni": { "da": 2012, "a": 2024 } }`.

## Изход

- `reports/index.md` — всички структури по региони с ключови числа и линкове;
- `reports/<регион>/<код>-<име>.md` — подробен отчет за структура: оперативен
  профил (легла/персонал/приеми), финансови показатели по години, пълен отчет
  за приходите и разходите за последната година, баланс;
- `reports/dati-chiave.csv` — плоска таблица (структура × година × показатели)
  за по-нататъшен анализ.

## Бележки по данните

- Финансовите данни са на ниво **ente SSN** (юридическото лице): самостоятелните
  болници (AO/AOU/IRCCS) имат собствен отчет; болниците-президии на ASL се
  отчитат във финансите на своята ASL и са изброени в нейния отчет.
- Кодовете `000` (GSA — централизирано регионално управление) и `999`
  (консолидиран регионален отчет) се пропускат — не са болници.
- Сумите са в евро по годишните консолидирани отчети (consuntivo).
- WAF-ът на dati.salute.gov.it отхвърля Node `fetch` (TLS фингърпринт) — за този
  портал пайплайнът минава през системния `curl`.
