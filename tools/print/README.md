# tools/print — „ръце" на Принтаджията (v2.0)

```bash
node tools/print/printability.mjs model.stl     # печатаемост за Creality K2 Plus
```

- **printability.mjs** — чете **binary STL** (без външни зависимости) и проверява:
  bounding box спрямо обема **350×350×350 mm**, единици (флагва вероятно cm/inch/m),
  брой триъгълници, **watertight/manifold** (гранични + non-manifold ръбове), изродени
  триъгълници, и предлага ориентация (товарът в XY, не през слоевете). Връща exit **1**
  при критично (non-manifold или над обема). ASCII STL → казва да преекспортираш binary.

## Граница
- Геометрична проверка — НЕ доказва толеранси/здравина. **Толерансите се доказват с тест-печат**
  (хлабина 0.3 mm/страна, пресова 0.1–0.2 — калибрирай за материала).
- 3MF (zip с цвят/единици/per-object) е препоръчан формат за K2 Plus/CFS, но този инструмент чете STL;
  за 3MF ползвай слайсера (Creality Print / OrcaSlicer auto-repair).
- Камерни температури по материал, OrcaSlicer версия с K2 Plus профил, обем Z (350 vs 360),
  CFS-C — **провери на живо** преди да гарантираш.
