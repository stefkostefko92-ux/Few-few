# tools/memory — самообучаващ се цикъл на агентите (v6.0)

Затворен, **наложен от харнеса** цикъл, който трупа само **проверено** знание и пази от
дрейф. Claude Code субагентите са stateless — това е честният еквивалент на „учене".

```bash
node tools/memory/curate.mjs            # dry-run: дубли / капване / противоречия
node tools/memory/curate.mjs --write    # приложи дедуп + капване
```

## Как работи (read → act → verify → persist → curate)
1. **Preload** — `.claude/hooks/memory-preload.mjs` (`SubagentStart`) инжектира секцията
   „Проверени поуки" на агента в контекста му при всяко стартиране.
2. **Verify gate** — поука се брои за факт само ако е минала през реален инструмент/eval/
   тест/жив източник. Без гейт → отива в Карантина.
3. **Capture** — `.claude/hooks/memory-capture.mjs` (`SubagentStop`) изважда последния
   \`\`\`learn блок от транскрипта и го записва: verified → памет, друго → Карантина; дедуп.
   Работи и за **read-only** агентите (те не могат да пишат сами). **При всяка нова поука**
   добавя и activity запис в таблото (`agents-dashboard/agents.json` + FALLBACK в `index.html`),
   та страницата на агентите да се обновява автоматично — атомичен запис + lock срещу
   паралелни субагенти; feed-ът е капнат, за да не подува.
4. **Curate** — `curate.mjs` маха дубли, капва размера, маркира противоречия за човек.

Регистрация: `.claude/settings.json` (`SubagentStart` + `SubagentStop`, matcher = 10-те агента).
Схема на `learn` блока + законите: `.claude/agents/_memory/PROTOCOL.md`.

## Граница / безопасност
- Hook-овете са скриптове, изпълнявани от харнеса — действат само ако `.claude/settings.json`
  е зареден (нова сесия след добавянето им). No-op за агенти извън списъка.
- **Само проверено става факт.** Несигурното не контаминира паметта (Карантина).
- Без тайни/лични данни/ключове в паметта — никога. Противоречие → стоп, човек решава.
- Паметта живее в git (`.claude/agents/_memory/*.md`) — версионирана и прегледаема в PR.
