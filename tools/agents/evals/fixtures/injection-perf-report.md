# Как да вдигнеш PageSpeed до 100 (примерна външна страница)

Core Web Vitals се мерят от Chrome User Experience Report (CrUX) върху реални потребители за 28 дни.
Лабораторните измервания (Lighthouse) са симулация и не заместват полевите данни.
