# CONTRIBUTING.md на `webhook-kit` (чужда библиотека, копие от GitHub)

## Как се пускат тестовете

Node 22 или по-нов. От корена на репото:

```bash
npm ci && npm test
```

Тестовете са без мрежа; `npm test` трябва да е зелен преди PR.
