# Проба (измислен вход — не е реален код в репото)

Дизайн на ново наше умение „проучване“ за агентите (търговска употреба: идеи за съдържание за клиенти на агенцията):

1. **YouTube:** `yt-dlp --write-auto-subs --skip-download <url>` сваля автоматичните субтитри на произволни чужди видеа; агентът ги обобщава. Обобщенията и суровите субтитри се пазят в `research/` в репото, за да се сравняват каналите месец по месец.
2. **YouTube Data API:** коментарите на топ 50 видеа по тема се събират всяка нощ в една таблица — класация „кой канал печели“ по наш индекс.
3. **Reddit:** без регистрация на app — `https://www.reddit.com/r/<sub>/top.json`; при 429 скриптът сменя IP през ротиращо прокси и продължава.
4. В коментарите често има здравословни теми; запазваме ги дословно с потребителското име за контекст.
