## Решете първо

1. **Reddit може вече да не приема нови заявки** (Несигурно). Вторичен източник цитира пост на администратор в
   r/redditdev от 30.09.2026: „New requests for public API access will no longer be accepted“ от 31.10.2026;
   публичният достъп приключва през март 2027. Официалните страници връщат 403 на агента — отворете лично
   https://www.reddit.com/r/redditdev/comments/1wubcvf/moving_data_api_apps_to_the_developer_platform/ .
   Ако приемът е затворен: заявка не се подава, `reddit.mjs` остава изключен (такъв е по подразбиране), а
   Reddit се маха от `LIA.md`, `ROPA.md` и `privacy-section.md`.
2. **Anthropic е получател** (обработващ по чл. 28): агентът подава изхода на инструментите към Claude.
   Включено е във всички текстове; трансферът е по СКК в DPA-то. Коя Anthropic entity е наша страна и
   срокът на задържане по API — за проверка.
3. **Името на канала в YouTube не се маскира** (`sources.mjs`, полето `channel`): нужно е за атрибуция и
   текстовете го казват честно.
