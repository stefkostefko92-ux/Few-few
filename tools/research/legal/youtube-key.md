# `YOUTUBE_API_KEY`: стъпки, какво приемаме, одит

Ключът се създава от [отговорно лице], което има право да поема задължения от името на дружеството, **след прочит на условията** по-долу. Датата се вписва в регистъра (`ROPA.md`).

## Стъпки

1. **Проект в Google Cloud** — точно един за този API клиент, без други клиенти в него (Developer Policies III.D.1.c). Име, например `carbonstealth-research`.
2. **Включете YouTube Data API v3** в проекта — без това ограничението в т. 4 не може да се зададе.
3. **Credentials → Create credentials → API key.**
4. **API restrictions → Restrict key → само „YouTube Data API v3“ → Save.**
5. **Application restrictions → IP addresses:** статичният IP на сървъра, ако инструментът тича там (IPv4/IPv6/CIDR; localhost не се поддържа). Google препоръчва двата вида ограничение („Unrestricted API keys are insecure“). На лаптоп с динамичен IP остава само ограничението по API.
6. **Съхранение:** `YOUTUBE_API_KEY` само в env на машината или сървъра (файл с mode 600, извън git). Никога в репото, лог, чат или commit. Кодът го праща в заглавка, не в адреса.
7. **Квоти:** вижте по-долу; проследявайте в Cloud Console → APIs & Services → Quotas.
8. **Таксуване:** нужна ли е платежна сметка за безплатната квота — [за проверка].

Източници (прочетени на 2.11.2026): https://docs.cloud.google.com/docs/authentication/api-keys · https://developers.google.com/youtube/terms/developer-policies

## Квоти

Официално: „default quota allocation of **100 `search.list` calls**, 100 `videos.insert` calls, and **10,000 units per day** combined for all other endpoints“ (https://developers.google.com/youtube/v3/guides/quota_and_compliance_audits, прочетено на 2.11.2026). Тоест 100 търсения дневно са отделен лимит, а `videos.list` и `commentThreads.list` се броят в 10 000-те единици; цената им в единици — [за проверка в калкулатора за квоти].

## Задължителен ли е одит

- **При квотата по подразбиране — не предварително.** Одитът е условие за увеличение на квотата („to get more quota… you must first complete an audit“). Формуляр: https://support.google.com/youtube/contact/yt_api_form
- **Одит може да има по всяко време** (ToS §6, Policies III.H), включително периодичен.
- **При промяна на случая на ползване** след одобрено увеличение одитът се подава наново (III.D.3).
- При описания вътрешен обем (няколко търсения на сесия) увеличение не се очаква.
